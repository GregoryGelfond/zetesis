# Complete pair exclusions

During ordinary materialized constraint grounding, a positive atomic body can
become exactly two distinct atoms after already-certified explicit facts are
removed. The compiler retains those exact interned atom-node pairs until the
whole original constraint join completes. Scalar filters, assignments, source
atom validation and validation of rejected rows keep their existing execution.
Bodies with default negation, projections, aggregates or conditional literals
use the original route. Self exclusions remain ordinary unary constraints;
empty, singleton and wider bodies also retain ordinary emission.

Each authored constraint delimits one opportunity. Its origins alone establish
nothing about pair coverage. Within its complete pair population, the compiler
finds connected components and counts distinct unordered edges. A component of
n distinct atoms is accepted only if it has exactly n(n−1)/2 edges. Duplicates
and reversed pairs count once. There are no other endpoints and every edge is
between distinct members, so this equality certifies every unordered pair.
Components of fewer than three atoms keep ordinary pair emission. The compiler
never mixes automatically generated coherence edges with these source groups.

For each certified component, all its pair exclusions are replaced by one
native unit-weight threshold at two, with false as the implication's head.
Pair conjunction and implication nodes were deferred, so accepted components
leave no dead pair nodes in the arena or its indexes. Declined components keep
every source pair occurrence. The root's provenance is the original constraint's
complete origin vector. Atom naming order, explicit fact roots and producer
metadata are unchanged; a false-headed native constraint supplies no producer.

For an interpretation M, all pair exclusions hold exactly when at most one
member is true. This is exactly the negated unit threshold's truth. A negative
constraint that M satisfies has a tautological frozen reduct for every J;
a violated constraint freezes to false. Equal original constraint truth
therefore gives equal frozen truth for every M and J, with no subset premise,
and preserves answer sets in every surrounding theory.

`proofs/Zetesis/PairwiseExclusions.lean` states this law for duplicate-free
indices, arbitrary condition formulas, and a complete edge population that may
repeat or reverse pairs. Its coverage premises remain Rust obligations. The
executable planner is checked against all simple graphs on four vertices with
reversed duplicate edges; small programs compare all original and arbitrary
frozen interpretations with the ordinary emitter. Native row storage and
propagation retain their separate qualification boundary.

The temporary certificate uses O(R) leased capacity and O(R log R) work for R
pair occurrences. In-place sorting, weighted union-find, searches, copies and
native-row publication remain metered and interruptible. Resource refusal never
publishes a successful theory or a partially certified group. Formula node,
operand, root and origin ceilings apply to the representation actually emitted.
Ordinary source failures keep their original statement location; resource work
and its interruption point can change with the representation.

Hybrid capture feeds the same collector during its existing complete admission
join. It publishes native groups only if every passing row is a pair and every
component is certified. Any nonpair, missing edge, component too small to replace,
or empty selected population keeps the original whole template streamed. Decline
publishes no speculative pair or threshold root, and capture still exhausts every
source row and its original validation. There is no second complete enumeration.

After all support/query/domain borrows end, exact original rule positions record
which templates were fully materialized. Existing in-place item/rule compaction
removes only those templates before the ordinary schedule decides which source
relations and rules to retain. This leased numeric disposition is local to the
one emission and retires before publication; no IR payload, source identity map
or cross-candidate cache is duplicated. Surviving streams retain their original
rule ownership, relative order and diagnostics. Streamed-instance counts include
only the surviving templates; source work remains cumulative. Retained hybrid
owners use the same disposition while preserving their open catalog.
