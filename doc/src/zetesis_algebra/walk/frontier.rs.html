1//! Shared work-stealing frontier and termination protocols.
2//!
3//! A frontier is one deque of regions per worker and the termination record
4//! that carries the count of unresolved regions and the gate idle workers
5//! wait at. The CPU walker and the GPU-route producers share every protocol
6//! here: taking a worker's own newest region, stealing a peer's oldest,
7//! publishing a split's children, and the idle back-off that waits for work
8//! or the end of the walk.
9//!
10//! Each deque has its own mutex: local removal locks only that deque, a split
11//! publication locks that deque and then, after releasing it and only while a
12//! worker is idle, the idle gate to wake one, and a thief skips a busy peer.
13//! Region preparation and evaluation hold no deque lock. Entry capacity grows
14//! fallibly and before any child is published. An atomic counter of unresolved
15//! regions carries termination: a split raises it before pushing its children,
16//! a resolved region lowers it once, and an unsuccessful thief stops only once
17//! that counter has reached zero. An atomic closed flag, set on the first stop
18//! or when the walk's consumer stops listening, halts the others at their next
19//! region. Idle workers wait at a gate that the last resolution and every
20//! close open, and that a publication opens for one waiter, so none sleeps
21//! out its timed wait after the walk has ended or while a region it could
22//! take is published. A publication reads the number of idle workers without
23//! the gate and takes the gate only when one is counted, so busy workers
24//! never contend for it. The timed wait bounds how late an idle worker sees a
25//! cancellation, and how late it finds a region left in a deque that was busy
26//! when it last looked.
27

40/// Allocation metadata of one frontier entry, beyond its inline representation.
41///
42/// The frontier accounts for `size_of::<Self>()` through deque capacity. Return
43/// only allocations owned by this entry, including unused capacity and excluding
44/// shared owners, the inline entry/header bytes, temporary storage and allocator
45/// metadata. The value must remain stable while the entry is queued. Actual
46/// owned allocations fit the host address range; a larger reported value is
47/// clamped to `usize::MAX`, preserving the frontier's host-counter conversion.
48/// This capability supplies no narrowing or membership decision.
49pub trait Payload {
50    /// Bytes of allocations owned by the entry, excluding the inline entry.
51    fn allocated_bytes(&self) -> u128;
52}

54impl<S: Payload> Payload for crate::region::Entry<S> {
55    fn allocated_bytes(&self) -> u128 {
56        self.region.retained_bytes() - size_of::<crate::region::Region>() as u128
57            + self.state.allocated_bytes()
58    }
59}

65/// Grow entry capacity before publication, preserving the prior deque on refusal.
66///
67/// # Errors
68/// Returns `R::from(Stop::Allocation)` when the requested capacity cannot be
69/// reserved. No entry is published by this operation.
70pub fn reserve_entries<E, R: From<Stop>>(
71    queue: &mut VecDeque<E>,
72    additional: usize,
73) -> Result<(), R> {
74    queue
75        .try_reserve(additional)
76        .map_err(|_| R::from(Stop::Allocation))
77}

79/// What ends the walk — every region resolved, or a close — and the gate idle
80/// workers wait at for either.
81///
82/// The count and the flag are atomics because the region loop reads them for
83/// every region. Every transition that ends the walk changes its atomic first
84/// and then takes the gate to wake the waiters, and an idle worker takes the
85/// gate and re-checks both conditions, and the peers' deques, before it waits.
86/// Whichever reaches the gate first, no idle worker waits past the end of the
87/// walk: a worker that takes the gate after the ending transition sees it, and
88/// one that took the gate before is already waiting when the wake comes.
89///
90/// The number of idle waiters is an atomic changed only while the gate is
91/// held, and a publication reads it without the gate. A waiter registers
92/// itself, issues a sequentially consistent fence, and only then re-checks
93/// the deques; a publication pushes its children, releases its deque, issues
94/// a sequentially consistent fence, and only then reads the count, taking the
95/// gate to wake one waiter when it is not zero. The two fences are totally
96/// ordered. If the publication's comes first, the waiter's re-check observes
97/// the released deque and so the pushed child; if the waiter's comes first,
98/// the publication reads its registration and takes the gate, which the waiter
99/// holds until it is waiting, so the wake reaches it. Either the waiter sees
100/// the child or the publication sees the waiter. Zero is terminal, since a
101/// region in hand counts until it is resolved. Every wait stays bounded by its
102/// timeout, so correctness never rests on a wake: the timeout is how an idle
103/// worker sees a cancellation, or a region left in a deque its re-check found
104/// busy.
105///
106/// The first case rests on a premise about the platform's mutex: releasing it
107/// and `try_lock` are atomic operations on its lock word, as they are in std's
108/// own futex mutex (Linux, Windows) and in the pthread mutex std uses on
109/// macOS, so the fences order them as they order any atomic access. A re-check
110/// after the publication's fence therefore finds the deque released, or locked
111/// again by a later holder, which costs the waiter a bounded wait. Were the
112/// premise to fail, a waiter could also find the publication still holding the
113/// deque, and would find the child after its bounded wait.
114pub struct Termination {
115    /// Created-but-unresolved regions across every worker's deque and region
116    /// in hand: a split adds one (before pushing its children), a refuted or
117    /// decided region subtracts one. It starts at one for the root and reaches
118    /// zero exactly when the whole frontier is resolved; a read of zero is a
119    /// true zero, so a worker that finds every deque empty and reads zero is
120    /// done.
121    outstanding: AtomicUsize,
122    /// A stop was raised (error or cancellation) or the walk's consumer
123    /// stopped listening; workers check it before each region and while idle,
124    /// and exit. Normal termination is `outstanding` reaching zero.
125    closed: AtomicBool,
126    /// Held to register and re-check before an idle wait, to wake one waiter
127    /// after a publication that counted one, and to wake every waiter after
128    /// the walk ends.
129    pub gate: Mutex<()>,
130    /// The number of idle workers waiting on `idle`: changed only while
131    /// `gate` is held, read by a publication without it.
132    pub idle_waiters: AtomicUsize,
133    /// Idle workers wait here for a published region or the end of the walk.
134    idle: Condvar,
135}
136
137impl Termination {
138    /// The root is the one outstanding region until it is split.
139    fn new() -> Self {
140        Self::resuming(1)
141    }
142
143    /// A walk that continues `unresolved` regions left by an earlier joined
144    /// one, which no worker holds: the count is carried, the walk is open and
145    /// nobody waits.
146    #[must_use]
147    pub fn resuming(unresolved: usize) -> Self {
148        Self {
149            outstanding: AtomicUsize::new(unresolved),
150            closed: AtomicBool::new(false),
151            gate: Mutex::new(()),
152            idle_waiters: AtomicUsize::new(0),
153            idle: Condvar::new(),
154        }
155    }
156
157    /// A split replaces its parent by two children: count the net gain of one
158    /// before either child becomes visible.
159    pub fn grow(&self) {
160        self.outstanding.fetch_add(1, Ordering::AcqRel);
161    }
162
163    /// A refuted or decided region leaves the frontier. The last one ends the
164    /// walk and wakes every idle worker.
165    pub fn resolve(&self) {
166        let previous = self.outstanding.fetch_sub(1, Ordering::AcqRel);
167        debug_assert_ne!(previous, 0, "a region was resolved twice");
168        if previous == 1 {
169            self.wake_idle();
170        }
171    }
172
173    /// Close the walk: workers take no further region, and idle workers wake.
174    pub fn close(&self) {
175        self.closed.store(true, Ordering::Release);
176        self.wake_idle();
177    }
178
179    /// The created-but-unresolved regions, as the workers read them.
180    #[must_use]
181    pub fn unresolved(&self) -> usize {
182        self.outstanding.load(Ordering::Acquire)
183    }
184
185    /// Whether every created entry has been resolved.
186    #[must_use]
187    pub fn is_resolved(&self) -> bool {
188        self.unresolved() == 0
189    }
190
191    /// Whether a caller closed the walk.
192    #[must_use]
193    pub fn is_closed(&self) -> bool {
194        self.closed.load(Ordering::Acquire)
195    }
196
197    /// Whether the walk is closed or has no unresolved entry.
198    #[must_use]
199    pub fn has_ended(&self) -> bool {
200        self.is_closed() || self.is_resolved()
201    }
202
203    /// Wake one idle worker, if any is counted, after a publication released
204    /// its deque. The fence orders the publication before the count's read;
205    /// see the type's documentation for why no waiter is missed.
206    pub fn wake_one(&self) {
207        fence(Ordering::SeqCst);
208        if self.idle_waiters.load(Ordering::Relaxed) != 0 {
209            let _gate = self.gate.lock().unwrap_or_else(PoisonError::into_inner);
210            self.idle.notify_one();
211        }
212    }
213
214    /// Wake every idle worker, after the transition that ended the walk.
215    fn wake_idle(&self) {
216        let _gate = self.gate.lock().unwrap_or_else(PoisonError::into_inner);
217        self.idle.notify_all();
218    }
219}

221/// Where an attempt to take a region runs. Outside the gate a worker may wait
222/// for its own deque's lock; under the gate only `try_lock` is used, so a
223/// waiter never waits for a deque lock while it holds the gate.
224#[derive(Clone, Copy, Debug, PartialEq, Eq)]
225pub enum Attempt {
226    /// Outside the idle gate; local removal may wait for its deque.
227    Outside,
228    /// While holding the idle gate; only nonblocking deque attempts are permitted.
229    UnderGate,
230}

237/// One counter of queued storage and the maximum it has held.
238struct Counter {
239    current: AtomicUsize,
240    peak: AtomicUsize,
241}
242
243impl Counter {
244    fn starting_at(value: usize) -> Self {
245        Self {
246            current: AtomicUsize::new(value),
247            peak: AtomicUsize::new(value),
248        }
249    }
250
251    /// Raise the counter and fold its new value into the peak.
252    fn add(&self, amount: usize) {
253        if amount != 0 {
254            let previous = self.current.fetch_add(amount, Ordering::Relaxed);
255            self.peak
256                .fetch_max(previous.saturating_add(amount), Ordering::Relaxed);
257        }
258    }
259
260    fn subtract(&self, amount: usize) {
261        self.current.fetch_sub(amount, Ordering::Relaxed);
262    }
263
264    fn set(&self, value: usize) {
265        self.current.store(value, Ordering::Relaxed);
266    }
267
268    fn current(&self) -> usize {
269        self.current.load(Ordering::Relaxed)
270    }
271
272    fn peak(&self) -> usize {
273        self.peak.load(Ordering::Relaxed)
274    }
275}

277/// Exact receipts of a frontier's queued regions and their storage.
278///
279/// Each counter changes by a relaxed read-modify-write under the deque lock of
280/// the change that causes it, and an increase folds its result into the
281/// counter's peak. Updates to one counter are totally ordered by its
282/// modification order, and each is applied while its deque's change is held,
283/// so the counter's history is a linearization of the deques' changes and its
284/// peak the exact maximum of that history. Counters of different kinds are
285/// separate histories, so their peaks need not occur together. They are read
286/// once no party can change the frontier.
287struct Accounting {
288    regions: Counter,
289    capacity: Counter,
290    /// The deque vector's header and its deques' headers, every deque's entry
291    /// capacity times the entry size, and every queued entry's owned payload.
292    retained_bytes: Counter,
293    /// The headers' share of `retained_bytes`, constant for a frontier.
294    headers: usize,
295}

297/// An entry's owned payload as a count of host bytes. The payload measures
298/// actual allocations, so it fits the host's address range.
299fn payload_bytes<E: Payload>(entry: &E) -> usize {
300    usize::try_from(entry.allocated_bytes()).unwrap_or(usize::MAX)
301}

303/// Owned storage of queued, inactive entries in the frontier's deques, at frontier mutations.
304///
305/// Bytes include the deque vector's and each deque's header, the deques'
306/// allocated entry capacity, used or not, and each queued entry's owned allocations
307/// reported by [`Payload`]. They exclude the regions producers
308/// hold, temporary split copies, shared owners, output batches,
309/// measurement bookkeeping, thread stacks and allocator/driver storage. This
310/// observation is neither total search memory nor a byte admission limit. Each
311/// count changes under the lock of the deque whose change causes it, so its
312/// peak is the maximum of a linearization of the deques' changes; peaks need
313/// not occur at the same mutation, and an empty frontier can retain entry
314/// capacity.
315#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
316pub struct Statistics {
317    /// Currently queued inactive entries; the historical receipt field is `regions`.
318    pub regions: usize,
319    /// Current entry capacity of the deques: the regions their storage can
320    /// queue without growing, used or not.
321    pub capacity: usize,
322    /// Current logical retained bytes in the stated ownership scope.
323    pub retained_bytes: u128,
324    /// Maximum number of simultaneously queued regions.
325    pub peak_regions: usize,
326    /// Maximum allocated entry capacity.
327    pub peak_capacity: usize,
328    /// Maximum logical retained bytes at a frontier mutation.
329    pub peak_retained_bytes: u128,
330}

332/// One deque of entries per worker and the walk's termination record.
333///
334/// An owner pops its newest region and thieves take the oldest. At most one
335/// deque lock is held at a time, and none while the gate is waited for. A
336/// measured frontier keeps exact receipts of its queued regions; its deques
337/// are then changed only through these operations.
338pub struct Frontier<E, R> {
339    /// Worker deques. Measured mutations must use the frontier's operations;
340    /// direct mutation would bypass its ownership receipts.
341    pub queues: Vec<Mutex<VecDeque<E>>>,
342    /// Whether the walk has ended, and where idle workers wait for its end.
343    pub termination: Termination,
344    accounting: Option<Accounting>,
345    refusal: PhantomData<fn() -> R>,
346}
347
348impl<E: Payload, R: From<Stop>> Frontier<E, R> {
349    /// Deque 0 holds `root`; the others start empty. Storage for the deques
350    /// and the root's entry is reserved fallibly. The frontier keeps no
351    /// receipts. As in the existing protocol, callers supply at least one worker.
352    ///
353    /// # Errors
354    /// Returns the caller's allocation refusal if either reservation fails.
355    pub fn new(workers: usize, root: E) -> Result<Self, R> {
356        let mut queues = Vec::new();
357        queues
358            .try_reserve_exact(workers)
359            .map_err(|_| R::from(Stop::Allocation))?;
360        let mut first = VecDeque::new();
361        reserve_entries::<E, R>(&mut first, 1)?;
362        first.push_back(root);
363        queues.push(Mutex::new(first));
364        for _ in 1..workers {
365            queues.push(Mutex::new(VecDeque::new()));
366        }
367        Ok(Self {
368            queues,
369            termination: Termination::new(),
370            accounting: None,
371            refusal: PhantomData,
372        })
373    }
374
375    /// [`Self::new`], keeping exact receipts of the queued regions and their
376    /// storage from the root onward. Payload measurement precedes reservation,
377    /// and the counter scope excludes this record's measurement bookkeeping.
378    ///
379    /// # Errors
380    /// Returns the same typed allocation refusal as [`Self::new`].
381    pub fn measured(workers: usize, root: E) -> Result<Self, R> {
382        let payload = payload_bytes(&root);
383        let mut frontier = Self::new(workers, root)?;
384        let headers = size_of::<Vec<Mutex<VecDeque<E>>>>()
385            + frontier.queues.capacity() * size_of::<Mutex<VecDeque<E>>>();
386        let capacity = frontier.queue(0).capacity();
387        frontier.accounting = Some(Accounting {
388            regions: Counter::starting_at(1),
389            capacity: Counter::starting_at(capacity),
390            retained_bytes: Counter::starting_at(headers + capacity * size_of::<E>() + payload),
391            headers,
392        });
393        Ok(frontier)
394    }
395
396    /// The frontier's receipts, when it keeps them.
397    #[must_use]
398    pub fn statistics(&self) -> Option<Statistics> {
399        let accounting = self.accounting.as_ref()?;
400        Some(Statistics {
401            regions: accounting.regions.current(),
402            capacity: accounting.capacity.current(),
403            retained_bytes: accounting.retained_bytes.current() as u128,
404            peak_regions: accounting.regions.peak(),
405            peak_capacity: accounting.capacity.peak(),
406            peak_retained_bytes: accounting.retained_bytes.peak() as u128,
407        })
408    }
409
410    /// Record a removal from a deque whose lock the caller holds.
411    fn removed(&self, entry: &E) {
412        if let Some(accounting) = &self.accounting {
413            accounting.regions.subtract(1);
414            accounting.retained_bytes.subtract(payload_bytes(entry));
415        }
416    }
417
418    /// Record an insertion into a deque whose lock the caller holds.
419    fn inserted(&self, entry: &E) {
420        if let Some(accounting) = &self.accounting {
421            accounting.regions.add(1);
422            accounting.retained_bytes.add(payload_bytes(entry));
423        }
424    }
425
426    /// Record a capacity change of a deque whose lock the caller holds.
427    fn resized(&self, before: usize, after: usize) {
428        if let Some(accounting) = &self.accounting
429            && after > before
430        {
431            let grown = after - before;
432            accounting.capacity.add(grown);
433            accounting.retained_bytes.add(grown * size_of::<E>());
434        }
435    }

437    /// Lock a worker deque, recovering its contents if an earlier holder panicked.
438    /// Measured mutations must use the frontier operations, not this raw guard.
439    ///
440    /// # Panics
441    /// Panics if `index` is outside the worker deques.
442    pub fn queue(&self, index: usize) -> MutexGuard<'_, VecDeque<E>> {
443        self.queues[index]
444            .lock()
445            .unwrap_or_else(PoisonError::into_inner)
446    }
447
448    /// Worker `index`'s newest entry.
449    ///
450    /// # Panics
451    /// Panics if `index` is outside the worker deques.
452    pub fn take_local(&self, index: usize) -> Option<E> {
453        let mut queue = self.queue(index);
454        let entry = queue.pop_back()?;
455        self.removed(&entry);
456        Some(entry)
457    }

459    /// Worker `index`'s newest region without waiting for its deque's lock:
460    /// the gate's form of [`Self::take_local`]. `Ok(None)` means the deque was
461    /// empty, and [`Busy`] that another worker held it, which says nothing of
462    /// its contents.
463    ///
464    /// # Errors
465    /// Returns [`Busy`] when another holder has the deque lock.
466    ///
467    /// # Panics
468    /// Panics if `index` is outside the worker deques.
469    pub fn try_take_local(&self, index: usize) -> Result<Option<E>, Busy> {
470        let mut queue = match self.queues[index].try_lock() {
471            Ok(queue) => queue,
472            Err(TryLockError::Poisoned(error)) => error.into_inner(),
473            Err(TryLockError::WouldBlock) => return Err(Busy),
474        };
475        let entry = queue.pop_back();
476        if let Some(entry) = &entry {
477            self.removed(entry);
478        }
479        Ok(entry)
480    }

482    /// Return a region to worker `index`'s deque without changing the count:
483    /// a region taken but neither resolved nor split goes back. The injected
484    /// reservation is the sole fallible storage effect, as in
485    /// [`Self::publish_split_with`]. Refusal returns the still-owned entry
486    /// beside the exact error. The caller retains unresolved coverage until
487    /// it records a terminal stop; only then may it abandon that entry.
488    ///
489    /// # Errors
490    /// Returns the reservation refusal and unchanged entry, without publication.
491    ///
492    /// # Panics
493    /// Panics if `index` is outside the worker deques.
494    pub fn requeue(
495        &self,
496        index: usize,
497        entry: E,
498        reserve: impl FnOnce(&mut VecDeque<E>, usize) -> Result<(), R>,
499    ) -> Result<(), (R, E)> {
500        let mut queue = self.queue(index);
501        let before = queue.capacity();
502        if let Err(error) = reserve(&mut queue, 1) {
503            return Err((error, entry));
504        }
505        self.resized(before, queue.capacity());
506        self.inserted(&entry);
507        queue.push_back(entry);
508        Ok(())
509    }

511    /// Take the oldest region of a peer's deque, trying peers in round-robin
512    /// order and skipping a busy one, so one owner's growth cannot block
513    /// stealing from the others. No two queue locks overlap, and none is
514    /// waited for.
515    pub fn steal(&self, index: usize) -> Option<E> {
516        let workers = self.queues.len();
517        for offset in 1..workers {
518            let mut queue = match self.queues[(index + offset) % workers].try_lock() {
519                Ok(queue) => queue,
520                Err(TryLockError::Poisoned(error)) => error.into_inner(),
521                Err(TryLockError::WouldBlock) => continue,
522            };
523            if let Some(entry) = queue.pop_front() {
524                self.removed(&entry);
525                return Some(entry);
526            }
527        }
528        None
529    }

531    /// Wait at the gate for a published region or the end of the walk, for at
532    /// most `timeout`. Under the gate the waiter registers, fences, and then
533    /// re-checks the walk's end and `try_take`; a region found then is returned
534    /// at once. `None` does not mean the walk ended: the caller re-checks.
535    /// What a region is, a frontier entry or another deque's item taken beside
536    /// it, is `try_take`'s.
537    pub fn wait_for_work<T>(
538        &self,
539        timeout: Duration,
540        mut try_take: impl FnMut(Attempt) -> Option<T>,
541    ) -> Option<T> {
542        let termination = &self.termination;
543        let gate = termination
544            .gate
545            .lock()
546            .unwrap_or_else(PoisonError::into_inner);
547        termination.idle_waiters.fetch_add(1, Ordering::Relaxed);
548        // Pairs with the publication's fence: see `Termination`.
549        fence(Ordering::SeqCst);
550        let ended = termination.has_ended();
551        let found = if ended {
552            None
553        } else {
554            try_take(Attempt::UnderGate)
555        };
556        if ended || found.is_some() {
557            termination.idle_waiters.fetch_sub(1, Ordering::Relaxed);
558            return found;
559        }
560        let _gate = termination
561            .idle
562            .wait_timeout(gate, timeout)
563            .unwrap_or_else(PoisonError::into_inner);
564        termination.idle_waiters.fetch_sub(1, Ordering::Relaxed);
565        None
566    }

568    /// Reserve publication storage while retaining the unsplit parent, then
569    /// construct and publish its children on worker `index`'s deque.
570    ///
571    /// The injected reservation must admit `N` entries, as [`reserve_entries`]
572    /// does. `children` runs only after success, under the same deque lock, so
573    /// no other publisher can consume the admitted capacity. Prepare expensive
574    /// lineage copies before calling; move them in `children` without copying
575    /// again. The parent remains owned on every reservation refusal.
576    ///
577    /// A binary split grows the unresolved count by one, even when `N` is one
578    /// and the returned value retains the other child in hand. Children are
579    /// pushed in array order. The deque is released before waking an idle worker.
580    /// No polling or semantic decision is performed by this boundary.
581    ///
582    /// # Errors
583    /// Returns the exact reservation refusal and parent without invoking
584    /// `children`, publishing an entry or changing the unresolved count.
585    ///
586    /// # Panics
587    /// Panics if `index` is outside the worker deques. A panic or process-level
588    /// allocation abort in `children` is outside the fallible reservation
589    /// contract; callers retain their existing panic/abort handling.
590    pub fn publish_split_with<const N: usize, H>(
591        &self,
592        index: usize,
593        parent: E,
594        reserve: impl FnOnce(&mut VecDeque<E>, usize) -> Result<(), R>,
595        children: impl FnOnce(E) -> ([E; N], H),
596    ) -> Result<H, (R, E)> {
597        const {
598            assert!(
599                N > 0 && N <= 2,
600                "a binary split publishes one or two children"
601            );
602        };
603        let mut queue = self.queue(index);
604        let before = queue.capacity();
605        if let Err(error) = reserve(&mut queue, N) {
606            return Err((error, parent));
607        }
608        self.resized(before, queue.capacity());
609        let (children, held) = children(parent);
610        // The parent is still outstanding. Count its net gain before making
611        // any child visible; the reserved pushes cannot allocate.
612        self.termination.grow();
613        for child in children {
614            self.inserted(&child);
615            queue.push_back(child);
616        }
617        // Release the deque before taking the gate: a waiter holds the gate
618        // while it tries the deques, and never waits for a queue lock.
619        drop(queue);
620        self.termination.wake_one();
621        Ok(held)
622    }
623
624    /// Look for a region, waiting while any remains. `None` when the whole
625    /// frontier is resolved or the walk closed; a cancellation observed while
626    /// idle is reported through `on_stop` first. `try_take` makes one attempt
627    /// and is told where it runs. Every idle round makes one attempt outside
628    /// the gate; of every sixteen rounds, the first fifteen then yield and the
629    /// last waits at the gate, where it attempts once more, and then polls
630    /// cancellation. `idle_wait` bounds that wait; a publication or the end of
631    /// the walk ends it at once.
632    pub fn find_work<T>(
633        &self,
634        idle_wait: Duration,
635        cancellation: &Cancellation,
636        mut try_take: impl FnMut(Attempt) -> Option<T>,
637        on_stop: impl FnOnce(R),
638    ) -> Option<T> {
639        let mut idle_rounds = 0u32;
640        loop {
641            if self.termination.is_closed() {
642                return None;
643            }
644            if let Some(entry) = try_take(Attempt::Outside) {
645                return Some(entry);
646            }
647            // No attempt succeeded. Even with busy queues, zero means every
648            // created region was resolved; a split counts its children before
649            // publishing.
650            if self.termination.is_resolved() {
651                return None;
652            }
653            // Busy queues and empty queues share the backoff, so lock
654            // contention cannot postpone cooperative control checks
655            // indefinitely.
656            idle_rounds += 1;
657            if idle_rounds < SPIN_ROUNDS_BEFORE_WAIT {
658                std::thread::yield_now();
659            } else {
660                if let Some(entry) = self.wait_for_work(idle_wait, &mut try_take) {
661                    return Some(entry);
662                }
663                if let Err(error) = cancellation.poll() {
664                    on_stop(error.into());
665                    return None;
666                }
667                idle_rounds = 0;
668            }
669        }
670    }
671
672    /// Release every deque's payloads and capacity, once no party can still
673    /// own or publish work. A measured frontier's current receipts become its
674    /// headers alone; its peaks remain.
675    pub fn release(&self) {
676        for index in 0..self.queues.len() {
677            drop(std::mem::take(&mut *self.queue(index)));
678        }
679        if let Some(accounting) = &self.accounting {
680            accounting.regions.set(0);
681            accounting.capacity.set(0);
682            accounting.retained_bytes.set(accounting.headers);
683        }
684    }
