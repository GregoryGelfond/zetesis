1//! Source loading, presentation and command-line adapters for zetesis.
2//!
3//! [`Session`] is re-exported from the canonical `zetesis-solve` library.
4//! [`run_finalized`] consumes that library and retains semantic evidence separately
5//! from publication in [`PublicationOutcome`] or [`PublicationFailure`].
6//! [`run`] accepts source and an injected output sink. Parsing, exact oracles,
7//! and candidate enumeration remain reusable libraries. [`entry`] adapts these
8//! operations to process arguments, standard streams, and exit codes.
9//! [`publish_prepared`] and [`AnswerRenderer`] provide a replaceable typed view
10//! without argument parsing or complete-family buffering. [`HumanRenderer`] and
11//! [`JsonRenderer`] use that same contract; semantic evidence stays independent
12//! of the renderer's acknowledgement.
