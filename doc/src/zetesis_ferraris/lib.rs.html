1//! Finite formula reducts and exact subset-minimality checking.
2//!
3//! This general kernel complements the Horn closure specialization. It does not
4//! parse source or ground rules. Its finite scalar aggregate constructor accepts
5//! already coalesced tuple eligibility formulas. Its topological
6//! Boolean transforms implement the definitions in `Zetesis.Ferraris` in the
7//! repository's Lean specification; this Rust implementation is not verified by
8//! those proofs. The CPU dependency supplies cancellation and deadline control.
9
