1//! Possible founded atoms of an original candidate region.
2//!
3//! Complete `Producers` coverage is mandatory. Relax a body by keeping its
4//! positive atoms and Boolean chains, replacing nodes already known false by
5//! falsum, and replacing other implications and aggregates by truth. Exact
6//! positive dependency components identify cyclic heads. Conceptually seed every
7//! other uncut atom, then derive cyclic heads to closure. A boundary Atom node
8//! reads that seed directly; no outside atom or its unrelated postings is queued.
9//! Held cyclic atoms are not seeds. Disjunctive producers never exclude a head
10//! because another head is held.
11//!
12//! Let P be the completed closure and M a stable interpretation compatible with
13//! the original knowledge. For J = M intersect P, body reduct truth in J implies
14//! relaxed body truth in P. Each enabled ordinary producer therefore puts all
15//! its uncut heads in P, including a head true in M; its reduct holds in J.
16//! A selected atomic choice works identically; an unselected choice's negative
17//! alternative is true. Constraints satisfied by M have tautological reducts.
18//! Thus J models the full reduct, and stability forces J = M. Consequently an
19//! atom outside P is absent from every stable completion. This argument needs
20//! complete roots and an upper relaxation, not head-cycle freedom or shifting.
21//! The representation and executable refinement remain proof obligations.
22//!
23//! Each worker prepares the immutable full positive incidence graph through the
24//! existing postings, ignoring region false masks. Iterative reverse/forward DFS
25//! retains only a cyclic-atom mask, then selects complete bodies of every producer
26//! with a cyclic head. Omitted nodes cannot affect a cyclic-head body; ordinary
27//! support still propagates along acyclic paths. Opaque bodies remain leaves.
28//! Node states, atom cursors, queue and body-node IDs supply the temporary DFS
29//! storage; the component pass retains no graph or component map. Body-node IDs
30//! temporarily hold at most A+B finishing entries, where B is the full body cone.
31//! Their actual capacity remains charged after selecting the smaller cone. Owner
32//! publication authenticates the cyclic mask, selected cone and any completed
33//! incidence indexes. The first pass keeps original parent and producer rows. A later preparation
34//! for the same exact owner builds the filtered rows, so one-use scratch pays no
35//! incidence-index construction. A refused build clears owner authority; retry
36//! conservatively repeats body preparation before another attempt. Reused preparation
37//! also records each selected node's immutable initial role. Counters precede
38//! relaxed seeds in the full-replay plan: reset all counters, then initialize each seed and
39//! immediately replay its outgoing rows without enqueueing the seed itself.
40//! This retains the same closure; seeds have no incoming relaxed dependency.
41//! Newly derived nodes and atoms still use the ordinary queue. Full replay applies
42//! current node/atom masks to those roles; no prior closure truth is reused.
43//! Below inherited completed knowledge, the first invalidated pass may instead
44//! recompute affected heads with every incoming producer body and unaffected
45//! boundary seeds. `local` states the selection, initialization and failure
46//! obligations; both routes use the same event engine and publish a complete mask.
47//!
48//! One pass reuses the original atom/node and producer body/head rows. Once
49//! prepared, its parent rows retain only included, nonabsorbed Boolean destinations,
50//! in original occurrence order and multiplicity. Outside destinations never change;
51//! included opaque destinations are initialized True or Inactive and cannot
52//! consume a parent event. No region-dependent state filters this index.
53//! Body-to-head rows flatten the original producer rows and retain exactly their
54//! cyclic head occurrences; noncyclic heads were already ignored by activation.
55//! One additional row holds the selected facts' heads in the same occurrence order.
56//! Neither projection consults region knowledge or changes producer information.
57//! Each atom/node activates at most once. For A atoms, N nodes, E indexed Boolean
58//! incidences, R producers, H head occurrences and P retained parent occurrences,
59//! preparation takes O(A + N + E + R + H) work and O(A + N + P + H) exclusive storage.
60//! Each incidence construction also temporarily holds at most N+1 row cursors.
61//! Original parent and producer postings are scanned only for selected body nodes;
62//! empty offset rows and fact-row inspections remain initialized and charged. A later pass resets only selected body nodes/fact
63//! rows and atom-mask words; only cyclic atom postings, the chosen parent rows
64//! and projected cyclic-head incidences are read after preparation. Publication reads cyclic
65//! mask words and missing uncut cyclic heads. All actual reads are charged; cuts are
66//! published together before ordinary propagation resumes. A later pass can
67//! exploit newly false bodies; no pass installs a rule or changes the reduct.
68//! Successfully closed region knowledge can omit a later pass while no projected
69//! body input has become false. A completed exact-owner projection
70//! distinguishes an outside node from an included but blocked node. Its outside
71//! cells never change during closure; unknown or foreign preparation invalidates
72//! conservatively. This includes held decisions that indirectly falsify bodies.
73//! The completion authority belongs to inherited knowledge under its same-original
74//! subject contract, never worker scratch. An atom with no positive occurrence
75//! in the projection can only remove itself from the completed upper closure:
76//! no projected body reads it, so all remaining uncut atoms stay included. Every
77//! included occurrence still invalidates, even when already blocked. Newly false
78//! opaque bodies invalidate separately after ordinary propagation. With unknown
79//! preparation every false atom invalidates. These rules preserve closedness and
80//! coverage of all uncut atoms, even when the operator loses an output-only head.
81//!
82//! A restricted pass may be weaker than the global least closure: a conceptual
83//! acyclic seed can temporarily support a downstream cycle. Ordinary propagation
84//! and foundedness therefore still alternate to saturation. At that fixed point,
85//! every uncut acyclic head has a nonfalse producer. Boolean saturation makes a
86//! relaxed-false body known false; opaque nonfalse leaves read true. Induction on
87//! the actual SCC condensation order then puts each acyclic head and each cyclic
88//! component into the global least closure. A boundary dependency must come from
89//! an earlier component, or a return path would put it in that cyclic component.
90//! Thus the saturated restriction matches global closure, even when passes differ.
91//! This executable correspondence remains a proof obligation, tested against the
92//! same event engine with every atom forced to be a closure head.
93//!
94//! A cached Kahn pass over the relaxed positive dependencies skips all later
95//! foundedness work when they are acyclic. Local support already suffices there:
96//! every nonfalse atom has a possible producer, whose positive inputs have lower
97//! dependency order and therefore enter P. The cycle test reuses exactly these
98//! immutable incidences and adds no graph. Its O(A + N + E + R + H) work is charged
99//! to the original narrowing that completes it; concurrent first users may each
100//! perform a charged test. Only a completed Boolean result is shared.

161        self.local.retained_bytes()
162            + self.states.capacity() as u128 * size_of::<State>() as u128
163            + (self.atoms.capacity() + self.cyclic_atoms.capacity()) as u128

216    /// An acyclic positive projection cannot strengthen ordinary support. The
217    /// existing subject contract binds both inventories to this exact original.
218    pub(super) fn needed<Q: Quota + ?Sized>(
219        &mut self,
220        theory: &Theory,
221        index: &Narrower,
222        producers: &Producers,
223        work: &mut Meter<'_, Q>,
224    ) -> Result<bool, Failure<Q::Error>> {
225        if let Some(&cyclic) = producers.founded_cycles.get() {
226            return Ok(cyclic);
227        }
228        let cyclic = self.cyclic(theory, index, producers, work)?;
229        // Another worker may have completed the same immutable test. Failed
230        // tests never reach publication, and no work or scratch is shared.
231        Ok(*producers.founded_cycles.get_or_init(|| cyclic))
232    }

234    fn cyclic<Q: Quota + ?Sized>(
235        &mut self,
236        theory: &Theory,
237        index: &Narrower,
238        producers: &Producers,
239        work: &mut Meter<'_, Q>,
240    ) -> Result<bool, Failure<Q::Error>> {
241        // Cycle preparation uses the same state cells as body preparation.
242        // Even an interrupted cycle pass invalidates their previous authority.
243        self.owner = None;
244        self.states.clear();
245        self.queue.clear();
246        self.dependencies.clear();
247        let atoms = theory.atom_count();
248        let vertices = atoms
249            .checked_add(theory.nodes().len())
250            .ok_or(Stop::Allocation)?;
251        reserve(&mut self.states, theory.nodes().len())?;
252        reserve(&mut self.dependencies, atoms)?;
253        reserve(&mut self.queue, vertices)?;
254        for _ in 0..atoms {
255            work.tick()?;
256            self.dependencies.push(0);
257        }
258        let nodes = theory.view();
259        for node in 0..nodes.len() {
260            work.tick()?;
261            let degree = match nodes.node(node).map_err(|_| Stop::InvalidProgram)? {
262                NodeView::Atom(_) => 1,
263                NodeView::And(_) | NodeView::Or(_) if !index.absorbed[node] => {
264                    let chain = index.chain_of[node].ok_or(Stop::InvalidProgram)?;
265                    index.chains[chain_position(chain)]
266                        .leaves(&index.extrema)
267                        .len()
268                }
269                _ => 0,
270            };
271            self.states.push(State::Awaiting(degree));
272        }
273        for producer in &producers.rules {
274            work.tick()?;
275            if producer.body.is_some() {
276                for &head in &producer.heads {
277                    work.tick()?;
278                    self.dependencies[head] = self.dependencies[head]
279                        .checked_add(1)
280                        .ok_or(Stop::Allocation)?;
281                }
282            }
283        }
284        for atom in 0..atoms {
285            work.tick()?;
286            if self.dependencies[atom] == 0 {
287                self.queue.push(atom);
288            }
289        }
290        for node in 0..nodes.len() {
291            work.tick()?;
292            if matches!(self.states[node], State::Awaiting(0)) {
293                self.activate_node(node, atoms, work)?;
294            }
295        }
296        let mut next = 0;
297        while let Some(&vertex) = self.queue.get(next) {
298            work.tick()?;
299            next += 1;
300            if vertex < atoms {
301                for &node in &index.atom_nodes[vertex] {
302                    work.tick()?;
303                    self.remove_dependency(node, atoms, work)?;
304                }
305                continue;
306            }
307            let node = vertex - atoms;
308            for &parent in &index.parents[node] {
309                work.tick()?;
310                if matches!(
311                    nodes.node(parent).map_err(|_| Stop::InvalidProgram)?,
312                    NodeView::And(_) | NodeView::Or(_)
313                ) {
314                    self.remove_dependency(parent, atoms, work)?;
315                }
316            }
317            for &producer in &producers.by_body[node] {
318                work.tick()?;
319                for &head in &producers.rules[producer].heads {
320                    work.tick()?;
321                    self.dependencies[head] = self.dependencies[head]
322                        .checked_sub(1)
323                        .ok_or(Stop::InvalidProgram)?;
324                    if self.dependencies[head] == 0 {
325                        self.queue.push(head);
326                    }
327                }
328            }
329        }
330        Ok(next != vertices)
331    }

333    fn remove_dependency<Q: Quota + ?Sized>(
334        &mut self,
335        node: usize,
336        atoms: usize,
337        work: &mut Meter<'_, Q>,
338    ) -> Result<(), Failure<Q::Error>> {
339        match self.states[node] {
340            State::Awaiting(1) => self.activate_node(node, atoms, work),
341            State::Awaiting(remaining) if remaining > 1 => {
342                self.states[node] = State::Awaiting(remaining - 1);
343                Ok(())
344            }
345            _ => Err(Failure::Stopped(Stop::InvalidProgram)),
346        }
347    }

349    /// Complete the upper closure before its caller may cut any atom. No state
350    /// from an earlier theory, region or interrupted prefix is authoritative.
351    pub(super) fn complete<Q: Quota + ?Sized>(
352        &mut self,
353        theory: &Theory,
354        index: &Narrower,
355        producers: &Producers,
356        never: &[u64],
357        atom_never: &[u64],
358        work: &mut Meter<'_, Q>,
359    ) -> Result<(), Failure<Q::Error>> {
360        #[cfg(test)]
361        {
362            self.passes += 1;
363        }
364        if self.complete_local(theory, index, producers, never, atom_never, work)? {
365            return Ok(());
366        }
367        self.local.clear(work)?;
368        self.prepare_bodies(theory, index, producers, work)?;
369        self.initialize(theory, index, never, atom_never, work)?;
370        if let Some(projected) = &self.projected {
371            for &head in projected.fact_heads() {
372                work.tick()?;
373                activate_atom(
374                    &mut self.atoms,
375                    &self.cyclic_atoms,
376                    &mut self.queue,
377                    head,
378                    atom_never,
379                    work,
380                )?;
381            }
382        } else {
383            for position in 0..self.fact_rows.len() {
384                work.tick()?;
385                let producer = &producers.rules[self.fact_rows[position]];
386                for &head in &producer.heads {
387                    work.tick()?;
388                    self.activate_atom(head, atom_never, work)?;
389                }
390            }
391        }
392        let atoms = theory.atom_count();
393        if let Some(seed_start) = self.projected.as_ref().map(|plan| plan.seed_start) {
394            // All mutable counters were reset before any seed can reach them.
395            // No seed has an incoming relaxed edge; queued consequences are not
396            // processed until every seed has received its current mask state.
397            for position in seed_start..self.body_nodes.len() {
398                work.tick()?;
399                let node = self.body_nodes[position];
400                let initial = self
401                    .projected
402                    .as_ref()
403                    .expect("prepared seed suffix")
404                    .initial[position];
405                debug_assert!(initial.is_seed());
406                let state = if bit(never, node) {
407                    State::Inactive
408                } else {
409                    initial.state(atom_never)
410                };
411                if matches!(state, State::True | State::Awaiting(0)) {
412                    self.states[node] = State::True;
413                    self.propagate_node::<false, Q>(
414                        index, producers, node, atoms, atom_never, work,
415                    )?;
416                } else {
417                    self.states[node] = state;
418                }
419            }
420        }
421        let mut next = 0;
422        while let Some(&vertex) = self.queue.get(next) {
423            work.tick()?;
424            next += 1;
425            if vertex < atoms {
426                for &node in &index.atom_nodes[vertex] {
427                    work.tick()?;
428                    if matches!(self.states[node], State::Awaiting(_)) {
429                        self.activate_node(node, atoms, work)?;
430                    }
431                }
432                continue;
433            }
434            self.propagate_node::<false, Q>(
435                index,
436                producers,
437                vertex - atoms,
438                atoms,
439                atom_never,
440                work,
441            )?;
442        }
443        Ok(())
444    }

446    /// Replay the same original or projected incidences for a newly true node,
447    /// whether it came from a seed or from the ordinary closure queue.
448    fn propagate_node<const LOCAL: bool, Q: Quota + ?Sized>(
449        &mut self,
450        index: &Narrower,
451        producers: &Producers,
452        node: usize,
453        atoms: usize,
454        atom_never: &[u64],
455        work: &mut Meter<'_, Q>,
456    ) -> Result<(), Failure<Q::Error>> {
457        let parents = self
458            .projected
459            .as_ref()
460            .map_or(&index.parents, |projected| &projected.parents);
461        for &parent in &parents[node] {
462            work.tick()?;
463            if LOCAL && !self.local.body(parent) {
464                continue;
465            }
466            match self.states[parent] {
467                State::Awaiting(1) => {
468                    activate_node(&mut self.states, &mut self.queue, parent, atoms, work)?;
469                }
470                State::Awaiting(remaining) => {
471                    self.states[parent] = State::Awaiting(remaining - 1);
472                }
473                State::Outside | State::Inactive | State::True => {}
474                State::Visiting(_) => return Err(Failure::Stopped(Stop::InvalidProgram)),
475            }
476        }
477        if let Some(projected) = &self.projected {
478            for &head in &projected.heads[node] {
479                work.tick()?;
480                if LOCAL && !self.local.head(head) {
481                    continue;
482                }
483                activate_atom(
484                    &mut self.atoms,
485                    &self.cyclic_atoms,
486                    &mut self.queue,
487                    head,
488                    atom_never,
489                    work,
490                )?;
491            }
492        } else {
493            if LOCAL {
494                return Err(Failure::Stopped(Stop::InvalidProgram));
495            }
496            for &producer in &producers.by_body[node] {
497                work.tick()?;
498                for &head in &producers.rules[producer].heads {
499                    work.tick()?;
500                    self.activate_atom(head, atom_never, work)?;
501                }
502            }
503        }
504        Ok(())
505    }

507    /// Prepare exact cyclic heads, then complete bodies feeding those heads.
508    /// Boolean paths use the same flattened chain leaves as runtime propagation;
509    /// opaque implications/aggregates are leaves, just as in the relaxation.
510    /// Roots without heads and head-only subformulas cannot contribute to P.
511    /// Existing state cells mark discovery; only cyclic head membership adds a mask.
512    /// Prepare incidence rows only when the same exact body projection is reused.
513    fn prepare_bodies<Q: Quota + ?Sized>(
514        &mut self,
515        theory: &Theory,
516        index: &Narrower,
517        producers: &Producers,
518        work: &mut Meter<'_, Q>,
519    ) -> Result<(), Failure<Q::Error>> {
520        if self
521            .owner
522            .as_ref()
523            .is_some_and(|owner| owner.same_instance(theory))
524        {
525            if self.projected.is_none() {
526                // No partial construction may retain body-projection authority.
527                self.owner = None;
528                let projected = Projection::prepare(theory, index, producers, self, work)?;
529                // Publish all owner-bound buffers together. A refused build
530                // leaves every previously retained capacity unchanged. During
531                // construction both old membership and this fresh membership
532                // coexist, just as local incidence buffers do before commit.
533                let mut local = local::Replay::default();
534                local.prepare(
535                    theory.atom_count(),
536                    theory.nodes().len(),
537                    self.body_nodes.len(),
538                    &self.cyclic_atoms,
539                    work,
540                )?;
541                reserve(&mut self.queue, self.body_nodes.len())?;
542                self.local = local;
543                self.projected = Some(projected);
544                self.owner = Some(theory.clone());
545            }
546            return Ok(());
547        }
548        self.owner = None;
549        self.prepare_cone(theory, index, producers, false, work)?;
550        self.prepare_components(theory, index, producers, work)?;
551        self.prepare_cone(theory, index, producers, true, work)?;
552        // Publish the completed bodies; the first pass uses original parent rows.
553        // A failed phase cannot authorize classification or inherited reuse.
554        self.owner = Some(theory.clone());
555        Ok(())
556    }

558    fn prepare_cone<Q: Quota + ?Sized>(
559        &mut self,
560        theory: &Theory,
561        index: &Narrower,
562        producers: &Producers,
563        cyclic_only: bool,
564        work: &mut Meter<'_, Q>,
565    ) -> Result<(), Failure<Q::Error>> {
566        // No incidence row may survive replacement of its included body set.
567        self.projected = None;
568        self.body_nodes.clear();
569        self.fact_rows.clear();
570        self.states.clear();
571        reserve(&mut self.states, theory.nodes().len())?;
572        // This complete initialization occurs once per worker/owner. Subsequent
573        // regions reset only body_nodes; omitted cells remain Outside forever.
574        for _ in 0..theory.nodes().len() {
575            work.tick()?;
576            self.states.push(State::Outside);
577        }
578        for (row, producer) in producers.rules.iter().enumerate() {
579            work.tick()?;
580            let mut selected = false;
581            for &head in &producer.heads {
582                work.tick()?;
583                selected |= !cyclic_only || self.cyclic_atoms.contains(head);
584            }
585            if !selected {
586                continue;
587            }
588            if let Some(body) = producer.body {
589                self.include_body(body, work)?;
590            } else {
591                self.fact_rows
592                    .try_reserve(1)
593                    .map_err(|_| Stop::Allocation)?;
594                self.fact_rows.push(row);
595            }
596        }
597        let nodes = theory.view();
598        let mut next = 0;
599        while let Some(&node) = self.body_nodes.get(next) {
600            work.tick()?;
601            next += 1;
602            if matches!(
603                nodes.node(node).map_err(|_| Stop::InvalidProgram)?,
604                NodeView::And(_) | NodeView::Or(_)
605            ) {
606                // A body root has an implication parent; a flattened chain leaf
607                // is never absorbed. Both are active original index positions.
608                if index.absorbed[node] {
609                    return Err(Failure::Stopped(Stop::InvalidProgram));
610                }
611                let chain = index.chain_of[node].ok_or(Stop::InvalidProgram)?;
612                for &child in index.chains[chain_position(chain)].leaves(&index.extrema) {
613                    self.include_body(child, work)?;
614                }
615            }
616        }
617        Ok(())
618    }

620    fn include_body<Q: Quota + ?Sized>(
621        &mut self,
622        node: usize,
623        work: &mut Meter<'_, Q>,
624    ) -> Result<(), Failure<Q::Error>> {
625        work.tick()?;
626        if matches!(self.states[node], State::Outside) {
627            self.body_nodes
628                .try_reserve(1)
629                .map_err(|_| Stop::Allocation)?;
630            self.body_nodes.push(node);
631            self.states[node] = State::Awaiting(0);
632        }
633        Ok(())
634    }
635
636    fn initialize<Q: Quota + ?Sized>(
637        &mut self,
638        theory: &Theory,
639        index: &Narrower,
640        never: &[u64],
641        atom_never: &[u64],
642        work: &mut Meter<'_, Q>,
643    ) -> Result<(), Failure<Q::Error>> {
644        self.atoms.storage_mut().clear();
645        self.queue.clear();
646        let vertices = theory
647            .atom_count()
648            .checked_add(self.body_nodes.len())
649            .ok_or(Stop::Allocation)?;
650        reserve(self.atoms.storage_mut(), flag_words(theory.atom_count()))?;
651        reserve(&mut self.queue, vertices)?;
652        for _ in 0..flag_words(theory.atom_count()) {
653            work.tick()?;
654            self.atoms.storage_mut().push(0);
655        }
656        let reset = self
657            .projected
658            .as_ref()
659            .map_or(self.body_nodes.len(), |plan| plan.seed_start);
660        for (position, &node) in self.body_nodes[..reset].iter().enumerate() {
661            work.tick()?;
662            let state = if bit(never, node) {
663                State::Inactive
664            } else {
665                let initial = if let Some(plan) = &self.projected {
666                    plan.initial[position]
667                } else {
668                    Initial::read(theory, index, &self.cyclic_atoms, node)?
669                };
670                initial.state(atom_never)
671            };
672            self.states[node] = state;
673            if matches!(state, State::True | State::Awaiting(0)) {
674                // The seed is recorded explicitly; subsequent incidences cannot
675                // publish it again, including empty conjunctions.
676                work.tick()?;
677                self.states[node] = State::True;
678                self.queue.push(theory.atom_count() + node);
679            }
680        }
681        Ok(())
682    }
683
684    fn activate_node<Q: Quota + ?Sized>(
685        &mut self,
686        node: usize,
687        atoms: usize,
688        work: &mut Meter<'_, Q>,
689    ) -> Result<(), Failure<Q::Error>> {
690        activate_node(&mut self.states, &mut self.queue, node, atoms, work)
691    }
692
693    fn activate_atom<Q: Quota + ?Sized>(
694        &mut self,
695        atom: usize,
696        atom_never: &[u64],
697        work: &mut Meter<'_, Q>,
698    ) -> Result<(), Failure<Q::Error>> {
699        activate_atom(
700            &mut self.atoms,
701            &self.cyclic_atoms,
702            &mut self.queue,
703            atom,
704            atom_never,
705            work,
706        )
707    }
708}

710/// Split atom/worklist borrows retain one immutable projected-head row while
711/// applying the same activation as the original producer traversal.
712fn activate_atom<Q: Quota + ?Sized>(
713    atoms: &mut Words<u64>,
714    cyclic_atoms: &Words<u64>,
715    queue: &mut Vec<usize>,
716    atom: usize,
717    atom_never: &[u64],
718    work: &mut Meter<'_, Q>,
719) -> Result<(), Failure<Q::Error>> {
720    if cyclic_atoms.contains(atom) && !bit(atom_never, atom) && !atoms.contains(atom) {
721        work.tick()?;
722        atoms.insert(atom);
723        queue.push(atom);
724    }
725    Ok(())
726}
727
728/// Split state/worklist borrows let a closure keep one immutable parent-row
729/// borrow throughout traversal. This is the same activation used in preparation.
730fn activate_node<Q: Quota + ?Sized>(
731    states: &mut [State],
732    queue: &mut Vec<usize>,
733    node: usize,
734    atoms: usize,
735    work: &mut Meter<'_, Q>,
736) -> Result<(), Failure<Q::Error>> {
737    if matches!(states[node], State::Outside) {
738        return Err(Failure::Stopped(Stop::InvalidProgram));
739    }
740    if !matches!(states[node], State::True) {
741        work.tick()?;
742        states[node] = State::True;
743        queue.push(atoms + node);
744    }
745    Ok(())
746}

748fn reserve<T>(values: &mut Vec<T>, count: usize) -> Result<(), Stop> {
749    values
750        .try_reserve_exact(count.saturating_sub(values.len()))
751        .map_err(|_| Stop::Allocation)
