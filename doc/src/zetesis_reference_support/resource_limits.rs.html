1//! The limit each typed resource is counted against, set by resource, for the
2//! limits an admission takes and for those of three other operations whose
3//! tests span crates.
4//!
5//! A refusal at a limit reports the resource it met. The view holds a family
6//! of limits when a `zetesis-themelios` admission takes it, directly or nested
7//! in the limits it takes: the admission of a source, of a bundle or of a
8//! logical program, formula preparation and expansion included. Those are the
9//! formula and expansion resources; the input limits of a source or a bundle;
10//! the core admission resources of a source or a logical program, and the
11//! logical program resources; the observation and objective admission
12//! resources; and the aggregate ceilings an aggregate error kind reports.
13//! Formula admission counts template variables and predicate arity against the
14//! core admission limits, so those two formula resources are set through
15//! [`admission_formula`].
16//!
17//! The view also holds the limits of three operations other than admission,
18//! because the tests of more than one crate set them one at a time: loading a
19//! bundle ([`bundle_loading`]), building an objective plan
20//! ([`objective_plan`]), and evaluating an admitted program's observations
21//! ([`observation_evaluation`]). Evaluation counts `Nodes`, `Depth` and `Bytes`
22//! per constructed symbol against fields of its own, while [`observation()`]
23//! pairs those three resources with their admission fields and refuses the
24//! resources counted only while observations are evaluated.
25//!
26//! The limits of operations that only one crate's tests set are paired in that
27//! crate's `tests/integration/support`. In `zetesis-themelios` these are
28//! compiling a program's metadata through its own door
29//! (`metadata_resources`), planning counts (`count_plan_resources`), bounding
30//! an objective (`objective_bound_resources`, which sets its aggregate ceilings
31//! through [`aggregate`]), and constructing observation symbols
32//! (`observation_construction`).
33//!
34//! The view stands above `zetesis-themelios`, so it serves the tests that use
35//! that crate as a dependency, its own integration tests among them. A unit
36//! test of `zetesis-themelios` would link a second copy of the crate, and a
37//! test of a crate below it would make that crate depend on its own
38//! dependents, so the tests of the crates that define these limits (the unit
39//! tests of `zetesis-themelios`, and the tests of `zetesis-core`,
40//! `zetesis-ferraris` and `zetesis-objective`) name the fields they set
41//! themselves. The view's own tests check that each resource it names has a
42//! field of its own; that the field is the one a refusal reports is checked
43//! only where a test the view serves meets that refusal.
44//!
45//! A test the view serves that sets one such limit, leaving the others at
46//! their defaults, names the resource; the field holding that limit is named
47//! here, once. A test that sets several limits at once, or varies one limit of
48//! a configuration that already sets others, names the fields, and its code
49//! shows why. A test that sets a field of these limits that no typed resource
50//! reports, such as the formula limits' key-analysis work, says why where it
51//! sets it. Formula and expansion limits are also read by resource, so a
52//! threshold search over one of them starts from its default. Limits are read
53//! and set as `u64` whatever the field's width.
54

64/// A limit field, at the width its limits declare.
65enum Field<'a> {
66    Count(&'a mut u64),
67    Size(&'a mut usize),
68    Narrow(&'a mut u32),
69}
70
71impl Field<'_> {
72    /// Bounds the field by `limit`.
73    ///
74    /// # Panics
75    /// Panics if `limit` does not fit the field's width.
76    fn set(self, limit: u64) {
77        match self {
78            Self::Count(field) => *field = limit,
79            Self::Size(field) => *field = usize::try_from(limit).expect("a limit within usize"),
80            Self::Narrow(field) => *field = u32::try_from(limit).expect("a limit within u32"),
81        }
82    }
83
84    /// The field's limit.
85    ///
86    /// # Panics
87    /// Panics if the limit does not fit in `u64`, which cannot happen where
88    /// `usize` is at most 64 bits.
89    fn get(self) -> u64 {
90        match self {
91            Self::Count(field) => *field,
92            Self::Size(field) => u64::try_from(*field).expect("a limit within u64"),
93            Self::Narrow(field) => u64::from(*field),
94        }
95    }
96}

98/// The field of `limits` that bounds `resource`.
99///
100/// # Panics
101/// Panics for a resource that no field of the formula limits bounds: a fixed
102/// capacity of binding analysis, or a resource counted against the core
103/// admission limits.
104fn formula_field(limits: &mut FormulaLimits, resource: FormulaResource) -> Field<'_> {
105    match resource {
106        FormulaResource::ProjectAtoms => Field::Size(&mut limits.max_project_atoms),
107        FormulaResource::ProjectBytes => Field::Size(&mut limits.max_project_bytes),
108        FormulaResource::ObjectivePresenceEntries => {
109            Field::Size(&mut limits.max_objective_presence_entries)
110        }
111        FormulaResource::DomainValues => Field::Size(&mut limits.max_domain_values),
112        FormulaResource::AssignmentValues => Field::Size(&mut limits.max_assignment_values),
113        FormulaResource::GeneratedValues => Field::Size(&mut limits.max_generated_values),
114        FormulaResource::SupportIndexEntries => Field::Size(&mut limits.max_support_index_entries),
115        FormulaResource::SupportBytes => Field::Size(&mut limits.max_support_bytes),
116        FormulaResource::AggregateCacheRows => Field::Size(&mut limits.max_aggregate_cache_rows),
117        FormulaResource::DisjunctionElements => Field::Size(&mut limits.max_disjunction_elements),
118        FormulaResource::AggregateCacheKeys => {
119            Field::Size(&mut limits.max_aggregate_cache_key_bytes)
120        }
121        FormulaResource::AggregateCacheElements => {
122            Field::Size(&mut limits.max_aggregate_cache_elements)
123        }
124        FormulaResource::AggregateCacheRoots => Field::Size(&mut limits.max_aggregate_cache_roots),
125        FormulaResource::AnalysisNodes => Field::Size(&mut limits.max_analysis_nodes),
126        FormulaResource::AnalysisEdges => Field::Size(&mut limits.max_analysis_edges),
127        FormulaResource::Substitutions => Field::Count(&mut limits.max_substitutions),
128        FormulaResource::Work => Field::Count(&mut limits.max_work),
129        FormulaResource::AggregateElements => Field::Size(&mut limits.aggregate.max_elements),
130        FormulaResource::ObjectiveElements => Field::Size(&mut limits.objective.max_templates),
131        FormulaResource::SupportRounds => Field::Count(&mut limits.max_support_rounds),
132        FormulaResource::ObjectiveFormulaAtoms => {
133            Field::Size(&mut limits.max_objective_formula_atoms)
134        }
135        FormulaResource::ObjectiveFormulaNodes => {
136            Field::Size(&mut limits.max_objective_formula_nodes)
137        }
138        FormulaResource::ObjectiveFormulaOperands => {
139            Field::Size(&mut limits.max_objective_formula_operands)
140        }
141        FormulaResource::AtomStorageBytes => Field::Size(&mut limits.max_atom_storage_bytes),
142        FormulaResource::Atoms => Field::Size(&mut limits.theory.max_atoms),
143        FormulaResource::Nodes => Field::Size(&mut limits.theory.max_nodes),
144        FormulaResource::Operands => Field::Size(&mut limits.theory.max_operands),
145        FormulaResource::Roots => Field::Size(&mut limits.theory.max_roots),
146        FormulaResource::Origins => Field::Size(&mut limits.max_origin_locations),
147        FormulaResource::Warnings => Field::Size(&mut limits.max_warnings),
148        FormulaResource::BindingCoefficientBits | FormulaResource::BindingBoundBits => {
149            panic!("{resource:?} is a fixed capacity of binding analysis, not a formula limit")
150        }
151        FormulaResource::Variables | FormulaResource::Arity => {
152            panic!(
153                "{resource:?} is counted against the core admission limits: see admission_formula"
154            )
155        }
156    }
157}

159/// The field of `limits` that bounds the formula `resource`, among the core
160/// admission limits that formula admission also checks.
161///
162/// # Panics
163/// Panics for a formula resource that the formula limits bound, or a fixed
164/// capacity of binding analysis.
165fn formula_core_field(
166    limits: &mut zetesis_core::AdmissionLimits,
167    resource: FormulaResource,
168) -> Field<'_> {
169    match resource {
170        FormulaResource::Variables => {
171            core_field(limits, zetesis_core::AdmissionResource::Variables)
172        }
173        FormulaResource::Arity => {
174            core_field(limits, zetesis_core::AdmissionResource::PredicateArity)
175        }
176        _ => panic!("{resource:?} is not counted against the core admission limits"),
177    }
178}

376/// The field of `limits` whose ceiling an aggregate refusal of `kind` reports.
377///
378/// # Panics
379/// Panics for a kind that reports no ceiling of the aggregate limits: a guard
380/// count, a control stop, a malformed input, an allocation failure or an
381/// arithmetic overflow.
382fn aggregate_field(limits: &mut AggregateLimits, kind: AggregateErrorKind) -> Field<'_> {
383    match kind {
384        AggregateErrorKind::ElementLimit => Field::Size(&mut limits.max_elements),
385        AggregateErrorKind::NodeLimit => Field::Size(&mut limits.max_nodes),
386        AggregateErrorKind::OperandLimit => Field::Size(&mut limits.max_operands),
387        AggregateErrorKind::WorkLimit => Field::Count(&mut limits.max_work),
388        AggregateErrorKind::StateLimit => Field::Size(&mut limits.max_states),
389        AggregateErrorKind::SubsetLimit => Field::Count(&mut limits.max_subsets),
390        AggregateErrorKind::GuardLimit
391        | AggregateErrorKind::Control(_)
392        | AggregateErrorKind::InvalidPrefix { .. }
393        | AggregateErrorKind::InvalidCondition { .. }
394        | AggregateErrorKind::Allocation
395        | AggregateErrorKind::ArithmeticOverflow => {
396            panic!("{kind:?} reports no ceiling of the aggregate limits")
397        }
398    }
399}
