1//! Composed answer-set solving through the reduct.
2//!
3//! Sessions consume coherent admitted inputs and expose checked answer sets,
4//! complete world views, bounded execution and typed observations. Source loading,
5//! argument parsing and answer publication belong to their consumers.
6//!
7//! # Begin with a coherent input
8//!
9//! Use [`PreparedInput::admitted`] for a source-admitted relational program,
10//! [`PreparedInput::formula`] for its finite formula counterpart, or
11//! [`PreparedInput::program`] for a native relational program. The input borrows
12//! one owner; atom indexes, objectives and the original subject cannot be mixed
13//! across unrelated admissions. Preparing this borrow performs no execution.
14//!
15//! ```
16//! use zetesis_cpu::Cancellation;
17//! use zetesis_solve::{Backend, PreparedInput, Session, SolveConfig, WorldViewLimits};
18//! use zetesis_themelios::{AdmissionOptions, admit};
19//!
20//! let admitted = admit("a :- not b. b :- not a.".into(), AdmissionOptions::default())?;
21//! let config = SolveConfig { backend: Backend::Cpu, models: 0, ..Default::default() };
22//! let family = Session::builder(
23//!     PreparedInput::admitted(&admitted), config, Cancellation::default(),
24//! ).collect(WorldViewLimits::default())?;
25//! assert_eq!(family.len(), 2);
26//! # Ok::<(), Box<dyn std::error::Error>>(())
27//! ```
28//!
29//! # Choose the question and retain its evidence
30//!
31//! [`Session::new`] selects objective incumbents when an objective exists.
32//! [`Session::enumerate`] streams all original answer sets with their scores.
33//! Both yield privately constructed [`AnswerSet`] values. Their full atoms and
34//! [`Subject`] identity are independent of a source's displayed projection.
35//! [`Session::progress`] records current evidence; [`Session::outcome`] becomes
36//! available when search finishes, stops or fails. Completion can remain absent
37//! after failure. Neither successful iteration
38//! nor a score alone establishes exhaustive coverage or proved optimality.
39//!
40//! [`SessionBuilder::collect`] starts unrestricted enumeration and returns a
41//! [`WorldView`] only after complete capture within [`WorldViewLimits`]. A failed
42//! collection retains a checked prefix in [`WorldViewFailure`]. A complete empty
43//! family establishes inconsistency; a stopped empty prefix does not.
44//!
45//! # Compose execution effects
46//!
47//! [`SolveConfig`] controls execution and named resource budgets. The GPU feature
48//! enables wgpu and is on by default; CPU execution remains available without it.
49//! [`SessionBuilder`] optionally takes [`ExecutionResources`] and
50//! [`SolveMeasurements`]. Shared device infrastructure can retain an exact
51//! compiled formula profile, while every session owns fresh search, residency,
52//! budgets and results. No global device or pipeline cache is installed.
53//!
54//! Membership is always decided by zetesis's own reduct check, on the CPU or on
55//! a qualified GPU route; the session owns candidate coverage, exact residual
56//! completion and objectives.
57//!
58//! [`ExecutionObserver`] borrows typed facts during setup or a pull. Callback
59//! failures are distinct from device faults and cannot request backend fallback.
60//! [`SolveFailure`] preserves the original cause and available semantic evidence;
61//! [`SolveFailure::into_parts`] transfers them into a consumer's error type.
62//! Output publication belongs to that consumer and cannot strengthen the solve's
63//! evidence. Host measurements are optional attempted-work records, not proofs.
64//!
65//! Normal programs require agreement with the reduct's least consequence set
66//! and its constraints. General formulas require original satisfaction and no
67//! proper-subset model of the frozen reduct. The lower libraries implement these
68//! checks; this crate composes them with candidate enumeration and honest bounded
69//! outcomes. Lean semantic laws do not yet certify the complete Rust/WGSL path.
