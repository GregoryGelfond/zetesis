1//! Parallel production of classical candidates, with membership left to the caller.
2//!
3//! The frontier contains disjoint regions of the original candidate space, in
4//! one deque per producer, retained between slates. A producer takes a region,
5//! applies the same readings as the scalar traversal, then refutes it, splits
6//! it, or emits its classical leaf. No producer checks answer-set membership.
7//!
8//! A slate is the candidates the stream proposes together for one membership
9//! check and commit, filled by one bounded run of the producers. A producer
10//! holds a region only in one of the slate's hands, as many as the slate
11//! admits candidates and never more than there are producers. A step that
12//! reaches a leaf reserves an output slot for its candidate, so the emitted
13//! candidates never exceed the slate's allowance and the output never
14//! reallocates. A slate of at least as many candidates as producers therefore
15//! keeps every producer working until its last candidate is found. Were each
16//! region in hand to hold an
17//! output slot, every emission near the end would retire its producer, and the
18//! slate's last candidates would be sought by the producers whose regions
19//! yield none.
20//!
21//! A producer works depth first: a split publishes the older child on its own
22//! deque, where an idle peer can steal it, and keeps the newer child in the
23//! same hand. After a refutation or an emission it keeps the hand while it
24//! finds another region at once, its own newest or, with an empty deque, a
25//! peer's oldest; otherwise it releases the hand. The emission that fills the
26//! slate closes it. Once every output slot is reserved the output is spoken
27//! for, and the slate is about to close. A producer reads the output after
28//! reserving its hand, and once it has read it spoken for it takes no region
29//! and begins no step. A producer that has not yet read it holds one of the
30//! slate's other hands, and its step ends as a step under way does. A leaf
31//! step that finds the output spoken for defers its leaf: the region returns
32//! unresolved for a later slate, and its producer leaves. A producer steals
33//! only with an empty deque: under the idle gate, where its own deque is only
34//! tried, a busy deque ends the attempt instead. The deques, the count of
35//! unresolved regions, the idle gate and the idle back-off are the frontier
36//! protocols the CPU walker shares (`region_frontier`).
37//!
38//! That is the order for an enumeration, which visits every region whatever the
39//! order: producers work apart and steal rarely. A caller that tightens
40//! candidate bounds as it commits answers declares so, and its producers then
41//! share one deque instead: every producer publishes there and takes the region
42//! any producer published most recently. Production stays where the latest
43//! splits are, so a slate fills from the area that is yielding leaves, and
44//! older, shallower regions wait for the tighter bounds that refute them near
45//! the root. Kept apart, producers would each descend a large subtree under the
46//! bound in force when they took it, or under none before the first. The shared
47//! deque gives up the per-deque bound on retained regions: a schedule in which
48//! producers keep leaving their paths for a newer region can queue far more
49//! than `w` paths' siblings, bounded only by the tree, as in the single stack
50//! the producers had before they kept deques.
51//!
52//! A slate ends full, stopped or with every region resolved, after finitely
53//! many steps. Each step consumes the one region it took: it refutes it, emits
54//! its leaf, or splits it on an atom the region leaves open. The exception is
55//! a deferred leaf, which only a step begun before its producer read the
56//! output spoken for can produce. Such steps hold hands other than the last
57//! reserver's, so a slate defers fewer leaves than it has hands. A deferred
58//! region returns to a deque only after its producer has read the output
59//! spoken for, and the deque's lock makes any producer that takes it again
60//! read that too and return it unstepped. So no region is stepped twice in a
61//! slate, the regions of `n` atoms form a tree of at most
62//! `2^(n+1) - 1` regions, and a step that fails stops the slate. Idle
63//! producers then leave within one bounded wait. A deferred leaf is stepped
64//! again by a later slate, under the conditions then in force; every slate
65//! before the last ends full, and each candidate is a leaf emitted once.
66//!
67//! All producers join before the next stage runs. Each holds one work lease
68//! for the slate, settled before it steals, before it waits and at its exit,
69//! so the coordinator's cumulative budget receives every charge, including
70//! failed attempts. A stop closes the slate before the stopping producer
71//! returns its region to a deque, and every producer checks for the close
72//! after it takes a region and before it steps it. So a region returned after
73//! a stop, a failed region included, is never stepped again. Every region in
74//! hand but a panicking producer's returns to a deque. A return refused entry
75//! capacity drops its region and records an allocation stop, unless a stop is
76//! already recorded, so a lost region always leaves the run incomplete. A stop
77//! never establishes coverage. A cancellation or deadline that a producer
78//! observes once the slate is full is left to the next slate's first poll,
79//! which observes it again, so no polled stop follows the emission that fills
80//! a slate. In a slate of more than one candidate, a step under way when that
81//! emission comes finishes after it, and the regions in hand return after it.
82//! A step that fails, or a return refused entry capacity, then records its
83//! stop beside the full output; the batch keeps that output and reports the
84//! stop after it. A slate of one candidate has one hand, which a peer wins
85//! only after the holder's emission, and then finds the output spoken for, so
86//! no peer takes, returns or stops after that emission. A producer leaves with
87//! its hand still reserved: it leaves only once the slate is closed, resolved
88//! or spoken for, and each of these ends every other producer's search for a
89//! region.
90//!
91//! Each producer retains its checker and worklists between slates. These are
92//! scratch for the same immutable source, not knowledge about a candidate: the
93//! latter travels with its frontier region. Candidate order depends on
94//! scheduling, while identity and coverage do not.

187        opened: regions::Opened,

248    /// A slate's boundary is each producer's tier boundary: before the slate
249    /// runs every tier draws the store's rows retained since it last did, and
250    /// after its producers join every tier delivers and will draw again. The
251    /// calling thread does both, charging the stream's budget.
252    fn share_at_join(&mut self, start: bool, budget: &mut Budget<'_>) -> Result<(), Incomplete> {
253        let Self {
254            parts,
255            workers,
256            statistics,
257            pool,
258            ..
259        } = self;
260        workers.with_dependent_mut(|_, workspaces| {
261            if workspaces.is_empty() {
262                let count = pool.current_num_threads();
263                workspaces
264                    .try_reserve_exact(count)
265                    .map_err(|_| Incomplete::Allocation)?;
266                workspaces.resize_with(count, Workspace::default);
267            }
268            for workspace in workspaces.iter_mut() {
269                let (tier, scratch) = (&mut workspace.tier, &mut workspace.scratch);
270                if start {
271                    parts.seed_tier(tier, scratch, budget, &mut statistics.counts)?;
272                } else {
273                    parts.deliver_tier(tier, scratch, budget, &mut statistics.counts)?;
274                    tier.reseed();
275                }
276            }
277            Ok(())
278        })
279    }

287    /// No producer runs outside a joined slate. Discard its retained scratch
288    /// on completion or stop, preserving factory receipts and pending regions.
289    pub(super) fn finish(&mut self) -> Result<(), Incomplete> {
290        self.workers.with_dependent_mut(|_, workspaces| {
291            let mut stopped = None;
292            // Isolate each callback destructor, as the per-slate producer
293            // catch did before retention. Clearing the whole vector inside one
294            // catch could abort if a second destructor panicked during
295            // unwinding.
296            while let Some(workspace) = workspaces.pop() {
297                if std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| drop(workspace)))
298                    .is_err()
299                {
300                    stopped.get_or_insert(Incomplete::WorkerPanicked);
301                }
302            }
303            stopped.map_or(Ok(()), Err)
304        })
305    }

324    pub(crate) fn restrict(
325        &mut self,
326        restriction: &Theory,
327        budget: &mut Budget<'_>,
328    ) -> Result<(), Incomplete> {
329        self.restrictions
330            .permanent
331            .try_reserve(1)
332            .map_err(|_| Incomplete::Allocation)?;
333        let narrower = super::original_index::prepare(
334            restriction,
335            self.native_byte_limit,
336            budget.cancellation,
337        )?;
338        budget.charge(narrower.work())?;
339        self.statistics.counts.work = self
340            .statistics
341            .counts
342            .work
343            .checked_add(narrower.work())
344            .ok_or(Incomplete::CounterOverflow)?;
345        self.restrictions
346            .permanent
347            .push((restriction.clone(), narrower));
348        Ok(())
349    }

386    /// Fill pre-admitted output slots without evaluating a reduct. The output
387    /// is empty on entry; its allocation remains the caller's batch ownership.
388    /// A zero remaining candidate allowance still permits coverage work until
389    /// either the frontier is refuted or another classical leaf is encountered.
390    /// The slate reads the original theory through `subject`, the
391    /// enumeration's one shared index, authenticated by the caller.
392    pub(crate) fn fill(
393        &mut self,
394        (theory, narrower): (&Theory, &Narrower),
395        maximum: usize,
396        remaining: u64,
397        budget: &mut Budget<'_>,
398        output: &mut Vec<Interpretation>,
399        timed: bool,
400    ) -> Produced {
401        debug_assert!(output.is_empty());
402        debug_assert!(maximum > 0 && output.capacity() >= maximum);
403        if let Err(error) = self.share_at_join(true, budget) {
404            return self.abandon(error);
405        }
406        let allowance = SharedBudget::new(budget.limits, budget.statistics);
407        // No producer runs between slates, so the count is carried exactly.
408        self.frontier.termination = Termination::resuming(self.frontier.termination.unresolved());
409        let joined = self.workers.with_dependent_mut(|filter, workspaces| {
410            if workspaces.is_empty() {
411                let count = self.pool.current_num_threads();
412                workspaces
413                    .try_reserve_exact(count)
414                    .map_err(|_| Incomplete::Allocation)?;
415                workspaces.resize_with(count, Workspace::default);
416            }
417            for workspace in workspaces.iter_mut() {
418                workspace.counts = RegionCounts::default();
419                workspace.timings = timed.then(SearchPhaseTimings::default);
420            }
421            let maximum = maximum.min(usize::try_from(remaining).unwrap_or(usize::MAX).max(1));
422            let slate = SlateFill {
423                theory,
424                filter: filter.as_ref(),
425                parts: &self.parts,
426                narrower,
427                restrictions: &self.restrictions,
428                allowance: &allowance,
429                limits: budget.limits,
430                cancellation: budget.cancellation,
431                frontier: &self.frontier,
432                maximum,
433                remaining,
434                hand_limit: slate_hands(maximum, workspaces.len()),
435                hands: AtomicUsize::new(0),
436                output_slots: AtomicUsize::new(0),
437                outcome: Mutex::new(Outcome {
438                    candidates: std::mem::take(output),
439                    stopped: None,
440                }),
441                order: self.order,
442            };
443            self.pool.install(|| {
444                workspaces
445                    .par_iter_mut()
446                    .enumerate()
447                    .for_each(|(index, workspace)| {
448                        if std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
449                            slate.produce(index, workspace);
450                        }))
451                        .is_err()
452                        {
453                            slate.stop(Incomplete::WorkerPanicked);
454                        }
455                    });
456            });
457            let Outcome {
458                candidates,
459                mut stopped,
460            } = slate
461                .outcome
462                .into_inner()
463                .unwrap_or_else(PoisonError::into_inner);
464            let mut counts = RegionCounts::default();
465            let mut original_validation = crate::PhaseMeasurement::default();
466            for workspace in workspaces.iter() {
467                if let Err(error) = counts.add(workspace.counts) {
468                    stopped.get_or_insert(error);
469                }
470                if let Some(timings) = &workspace.timings {
471                    original_validation.merge(timings.original_validation);
472                }
473            }
474            Ok((candidates, stopped, counts, original_validation))
475        });
476        allowance.record(&mut budget.statistics);
477        let (produced, mut stopped, counts, original_validation) = match joined {
478            Ok(joined) => joined,
479            Err(error) => return self.abandon(error),
480        };
481        *output = produced;
482        if let Err(error) = self.statistics.counts.add(counts) {
483            stopped.get_or_insert(error);
484        }
485        if stopped.is_none()
486            && let Err(error) = self.share_at_join(false, budget)
487        {
488            stopped = Some(error);
489        }
490        let resolved = self.frontier.termination.is_resolved();
491        if (stopped.is_some() || resolved)
492            && let Err(error) = self.finish()
493        {
494            stopped.get_or_insert(error);
495        }
496        Produced {
497            exhausted: stopped.is_none() && resolved,
498            stopped,
499            original_validation,
500        }
501    }
502}

515/// The hands of a slate of `maximum` candidates filled by `producers`: as many
516/// as it admits candidates, and never more than there are producers.
517fn slate_hands(maximum: usize, producers: usize) -> usize {
518    maximum.min(producers)
519}

521/// What a slate has produced: its emitted candidates and its first stop. One
522/// lock guards both, so a stop that polling control observed is recorded only
523/// while the slate is not yet full.
524struct Outcome {
525    candidates: Vec<Interpretation>,
526    stopped: Option<Incomplete>,
527}

529/// One slate's shared state: its hands, its allowance of output slots and its
530/// outcome.
531struct SlateFill<'a, 'filter> {
532    theory: &'a Theory,
533    filter: Option<&'filter crate::region_filter::Filter>,
534    parts: &'a regions::OriginalParts,
535    narrower: &'a Narrower,
536    restrictions: &'a Conditions<(Theory, Narrower)>,
537    allowance: &'a SharedBudget,
538    limits: SearchLimits,
539    cancellation: &'a Cancellation,
540    frontier: &'a RegionFrontier,
541    maximum: usize,
542    remaining: u64,
543    /// The slate's hands, the regions producers may hold at once: `maximum`,
544    /// or the number of producers if smaller. One hand makes a slate of one
545    /// candidate a single walk, which no peer's step follows after its
546    /// emission, and under the shared order the hands bound the regions held
547    /// at once.
548    hand_limit: usize,
549    /// Hands reserved, never more than `hand_limit`.
550    hands: AtomicUsize,
551    /// Output slots reserved by steps that reached a leaf, never more than
552    /// `maximum`. Each becomes its candidate's at once. Once every slot is
553    /// reserved the output is spoken for.
554    output_slots: AtomicUsize,
555    /// A leaf lock: the slate closes only after it is released.
556    outcome: Mutex<Outcome>,
557    order: FrontierOrder,
558}

564    /// A leaf that found the output spoken for: unresolved, its region waits

567}

569impl<'filter> SlateFill<'_, 'filter> {
570    /// The deque producer `index` publishes to, takes from first and returns
571    /// regions to: its own, or the one deque all producers share.
572    fn home(&self, index: usize) -> usize {
573        match self.order {
574            FrontierOrder::PerProducer => index,
575            FrontierOrder::Shared => 0,
576        }
577    }
578
579    fn outcome(&self) -> MutexGuard<'_, Outcome> {
580        self.outcome.lock().unwrap_or_else(PoisonError::into_inner)
581    }
582
583    /// Record the first stop and close the slate: producers take no further
584    /// region, return the regions they hold and leave.
585    fn stop(&self, error: Incomplete) {
586        self.outcome().stopped.get_or_insert(error);
587        self.frontier.termination.close();
588    }
589
590    /// Record a stop that polling control observed, unless the slate is
591    /// already full, and close the slate. The emission that fills the slate
592    /// ends it without a stop, and a requested stop stays requested, so the
593    /// next slate's first poll observes it. The check and the record share the
594    /// lock the emission takes, so no such stop follows the filling emission.
595    fn stop_unless_full(&self, error: Incomplete) {
596        let recorded = {
597            let mut outcome = self.outcome();
598            let open = outcome.candidates.len() < self.maximum;
599            if open {
600                outcome.stopped.get_or_insert(error);
601            }
602            open
603        };
604        if recorded {
605            self.frontier.termination.close();
606        }
607    }
608
609    /// Reserve one hand, if the slate has one left.
610    fn reserve_hand(&self) -> bool {
611        self.hands
612            .fetch_update(Ordering::AcqRel, Ordering::Acquire, |reserved| {
613                (reserved < self.hand_limit).then_some(reserved + 1)
614            })
615            .is_ok()
616    }
617
618    /// Return a hand that found no region. It wakes nobody: a producer waiting
619    /// for a hand sees it within its bounded wait.
620    fn release_hand(&self) {
621        self.hands.fetch_sub(1, Ordering::AcqRel);
622    }
623
624    /// Reserve the output slot of a leaf's candidate, if the slate has one
625    /// left. A reserved slot is never returned: its candidate is emitted at
626    /// once, or its producer's failure stops the slate.
627    fn reserve_output_slot(&self) -> bool {
628        self.output_slots
629            .fetch_update(Ordering::AcqRel, Ordering::Acquire, |reserved| {
630                (reserved < self.maximum).then_some(reserved + 1)
631            })
632            .is_ok()
633    }

635    /// Whether the output is spoken for, every output slot reserved: each
636    /// reservation's emission or stop then closes the slate at once, so the
637    /// slate can use no further step. The load acquires, so a read after a
638    /// hand's reservation sees every slot reserved before the hand's last
639    /// release (see [`Self::admit`]).
640    fn spoken_for(&self) -> bool {
641        self.output_slots.load(Ordering::Acquire) == self.maximum
642    }

644    /// One attempt to take a region in a newly reserved hand: the newest region
645    /// of the producer's home deque, or, with that deque empty, another deque's
646    /// oldest. Nothing is taken once the output is spoken for. Under the gate
647    /// only `try_lock` is used, and a home deque found busy ends the attempt
648    /// without a steal: another producer holds it, and it may still hold
649    /// regions, which the next attempt outside the gate waits for. Every failed
650    /// attempt settles the lease, so the back-off never waits holding work
651    /// permits.
652    ///
653    /// The output is read once the hand is reserved, never before. A slate of
654    /// one candidate has one hand, which a peer reserves only by reading its
655    /// holder's release, and the holder reserved its output slot before that
656    /// release. Both are acquire-release read-modify-writes, so the peer's read
657    /// finds the output spoken for, and no peer takes a region after the
658    /// slate's emission. With more hands, a producer whose reservation did not
659    /// read the last reserver's release can take, and step, a region before it
660    /// reads the output spoken for. It holds one of the other `k - 1` hands, so
661    /// no more than that many such steps, and deferred leaves, follow the last
662    /// reservation. No sequential test tells this order from the reverse; the
663    /// argument is what keeps it.
664    fn admit(&self, index: usize, attempt: Attempt, lease: &WorkLease<'_>) -> Option<Entry> {
665        if !self.reserve_hand() {
666            lease.settle();
667            return None;
668        }
669        if self.spoken_for() {
670            self.release_hand();
671            lease.settle();
672            return None;
673        }
674        let home = self.home(index);
675        let local = match attempt {
676            Attempt::Outside => Ok(self.frontier.take_local(home)),
677            Attempt::UnderGate => self.frontier.try_take_local(home),
678        };
679        let entry = match local {
680            Ok(Some(entry)) => Some(entry),
681            Ok(None) => {
682                lease.settle();
683                self.frontier.steal(home)
684            }
685            Err(Busy) => {
686                lease.settle();
687                None
688            }
689        };
690        if entry.is_none() {
691            self.release_hand();
692        }
693        entry
694    }

696    /// A region in a reserved hand, waiting while any remains; `None` when the
697    /// slate ended.
698    fn acquire(&self, index: usize, lease: &WorkLease<'_>) -> Option<Entry> {
699        self.frontier.find_work(
700            CONTROL_WAIT,
701            self.cancellation,
702            |attempt| self.admit(index, attempt, lease),
703            |error| self.stop_unless_full(error),
704        )
705    }

707    /// Publish the older child and retain the newer in the same hand. The
708    /// metered lineage copy has completed before entry; the parent is consumed
709    /// only after deque storage is admitted. Success empties the occupied
710    /// caller slot and returns held; refusal restores the exact parent before
711    /// returning its original typed error.
712    fn hand_over(
713        &self,
714        index: usize,
715        pending: &mut Option<Entry>,
716        atom: usize,
717        cut_knowledge: CandidateKnowledge,
718        reserve: impl FnOnce(&mut VecDeque<Entry>, usize) -> Result<(), Incomplete>,
719    ) -> Result<Entry, Incomplete> {
720        let parent = pending.take().expect("publication has a pending parent");
721        match self
722            .frontier
723            .publish_split_with(self.home(index), parent, reserve, |parent| {
724                let (cut, held) = parent.split_with(atom, |knowledge| (cut_knowledge, knowledge));
725                ([cut], held)
726            }) {
727            Ok(held) => Ok(held),
728            Err((error, parent)) => {
729                *pending = Some(parent);
730                Err(error)
731            }
732        }
733    }

735    /// Account one child copy before publishing it. Both refusal boundaries
736    /// leave the parent in its caller-owned slot until the caller records stop.
737    fn split(
738        &self,
739        index: usize,
740        pending: &mut Option<Entry>,
741        atom: usize,
742        counts: &mut RegionCounts,
743        budget: &mut Budget<'_, WorkLease<'_>>,
744    ) -> Result<Entry, Incomplete> {
745        let copied = regions::copy_knowledge(
746            &pending.as_ref().expect("split has a pending parent").state,
747            None,
748            budget,
749        );
750        counts.add(copied.counts)?;
751        self.hand_over(index, pending, atom, copied.result?, reserve_regions)
752    }

754    /// Stop the slate on `error`, then return `entry`, a region producer
755    /// `index` could not resolve, to its home deque when storage permits. The
756    /// order is the guarantee: the stop closes the slate before the region
757    /// becomes visible, so a producer that takes it acquires the deque after
758    /// the close, sees the close in [`Self::ready`] and returns it unstepped.
759    /// The recorded stop keeps the run incomplete whether or not the region is
760    /// retained; a refused return records its own stop, which this first stop
761    /// precedes.
762    fn fail(&self, index: usize, entry: Entry, error: Incomplete) {
763        self.stop(error);
764        self.give_back(index, entry, reserve_regions);
765    }

767    /// Return `entry` to producer `index`'s home deque, reserving its entry
768    /// capacity through `reserve`. A refused return keeps its owner until the
769    /// typed stop closes this non-resumable production; only then is the entry
770    /// deliberately abandoned, without resolving its outstanding region.
771    fn give_back(
772        &self,
773        index: usize,
774        entry: Entry,
775        reserve: impl FnOnce(&mut VecDeque<Entry>, usize) -> Result<(), Incomplete>,
776    ) {
777        if let Err((error, entry)) = self.frontier.requeue(self.home(index), entry, reserve) {
778            self.stop(error);
779            // Terminal abandonment, not a resolution or a failed restoration.
780            drop(entry);
781        }
782    }

784    /// Whether `entry`, a region the producer has just taken, may be stepped.
785    /// Not once the slate has closed: the close is read after the take, so a
786    /// region a stopping producer returned is never stepped again. Nor once
787    /// the output is spoken for, since the slate is then about to close and a
788    /// leaf could not be emitted; so a deferred leaf is not stepped again in
789    /// this slate. Nor when control requests a stop, which is recorded. A
790    /// refused region comes back for the producer to return to its deque.
791    fn ready(&self, entry: Entry) -> ControlFlow<Entry, Entry> {
792        if self.frontier.termination.is_closed() || self.spoken_for() {
793            return ControlFlow::Break(entry);
794        }
795        if let Err(error) = self.cancellation.poll() {
796            self.stop_unless_full(error.into());
797            return ControlFlow::Break(entry);
798        }
799        ControlFlow::Continue(entry)
800    }

802    /// After a refutation or an emission the producer keeps its hand when it
803    /// finds another region at once: its home deque's newest, or, with that
804    /// deque empty, another deque's oldest after settling its lease. It takes
805    /// nothing once the output is spoken for, the filling emission's case
806    /// included. Otherwise the hand is released.
807    fn after_resolution(&self, index: usize, lease: &WorkLease<'_>) -> Option<Entry> {
808        let home = self.home(index);
809        let next = if self.spoken_for() {
810            None
811        } else {
812            self.frontier.take_local(home).or_else(|| {
813                lease.settle();
814                self.frontier.steal(home)
815            })
816        };
817        if next.is_none() {
818            self.release_hand();
819        }
820        next
821    }

823    /// The leaf's region is resolved and the output slot its step reserved
824    /// becomes its candidate's. The emission that fills the slate closes it, a
825    /// normal end with no stop, after the outcome lock is released.
826    fn emit(&self, candidate: Interpretation) {
827        self.frontier.termination.resolve();
828        let full = {
829            let mut outcome = self.outcome();
830            outcome.candidates.push(candidate);
831            outcome.candidates.len() == self.maximum
832        };
833        if full {
834            self.frontier.termination.close();
835        }
836    }

838    /// Leaving the slate, producer `index` returns the region it holds, if
839    /// any, to its home deque, so the region stays queued for the next slate;
840    /// a refused return records an allocation stop. Its hand stays reserved:
841    /// a producer leaves only once the slate is closed, resolved or spoken
842    /// for, and none of these lets another producer take a region.
843    /// [`Self::produce`] leaves through this one transition on every exit.
844    fn leave(&self, index: usize, hand: Option<Entry>) {
845        if let Some(entry) = hand {
846            self.give_back(index, entry, reserve_regions);
847        }
848    }

850    /// Producer `index`'s part of the slate. It holds one lease throughout,
851    /// checks the slate and polls control after it takes each region and
852    /// before it steps it, keeps the newer child of each split in hand, and
853    /// leaves through [`Self::leave`] when the slate ends or its leaf is
854    /// deferred.
855    fn produce(&self, index: usize, workspace: &mut Workspace<'filter>) {
856        let mut lease = self.allowance.lease(self.cancellation);
857        let mut search = SearchStatistics::default();
858        let mut hand: Option<Entry> = None;
859        loop {
860            let taken = match hand.take() {
861                Some(entry) => entry,
862                None => match self.acquire(index, &lease) {
863                    Some(entry) => entry,
864                    None => break,
865                },
866            };
867            let mut entry = match self.ready(taken) {
868                ControlFlow::Continue(entry) => entry,
869                ControlFlow::Break(entry) => {
870                    hand = Some(entry);
871                    break;
872                }
873            };
874            let mut counts = RegionCounts {
875                regions: 1,
876                ..Default::default()
877            };
878            let result = {
879                let mut budget = Budget {
880                    quota: lease,
881                    limits: self.limits,
882                    cancellation: self.cancellation,
883                    statistics: search,
884                };
885                let result = self.step(&mut entry, workspace, &mut budget, &mut counts);
886                search = budget.statistics;
887                lease = budget.quota;
888                result
889            };
890            let overflow = workspace.counts.add(counts).err();
891            match result {
892                Ok(Step::Refuted) => {
893                    self.frontier.termination.resolve();
894                    hand = self.after_resolution(index, &lease);
895                }
896                Ok(Step::Split(atom)) => {
897                    // Continue the same lease after the step receipt, before
898                    // locking or consuming the unresolved parent.
899                    let mut pending = Some(entry);
900                    let published = {
901                        let mut budget = Budget {
902                            quota: lease,
903                            limits: self.limits,
904                            cancellation: self.cancellation,
905                            statistics: search,
906                        };
907                        let published = self.split(
908                            index,
909                            &mut pending,
910                            atom,
911                            &mut workspace.counts,
912                            &mut budget,
913                        );
914                        search = budget.statistics;
915                        lease = budget.quota;
916                        published
917                    };
918                    match published {
919                        Ok(held) => hand = Some(held),
920                        Err(error) => {
921                            // The whole narrowed parent remains owned until
922                            // production becomes terminal. No restoration
923                            // allocation or child publication follows refusal.
924                            self.stop(error);
925                            drop(pending);
926                            break;
927                        }
928                    }
929                }
930                Ok(Step::Candidate(candidate)) => {
931                    self.emit(candidate);
932                    hand = self.after_resolution(index, &lease);
933                }
934                Ok(Step::Deferred) => {
935                    // The output stays spoken for, so `ready` refuses the
936                    // unresolved leaf and the producer returns it as it leaves.
937                    hand = Some(entry);
938                }
939                Err(error) => {
940                    // This region remains unresolved.
941                    self.fail(index, entry, error);
942                    break;
943                }
944            }
945            if let Some(error) = overflow {
946                self.stop(error);
947                break;
948            }
949        }
950        self.leave(index, hand);
951    }

953    fn step<'a>(
954        &'a self,
955        entry: &mut Entry,
956        workspace: &mut Workspace<'filter>,
957        budget: &mut Budget<'a, WorkLease<'a>>,
958        counts: &mut RegionCounts,
959    ) -> Result<Step, Incomplete> {
960        let mut check = self.filter.map(|factory| crate::region_filter::Check {
961            filter: factory,
962            worker: &mut workspace.filter,
963            timings: &mut workspace.timings,
964        });
965        let narrowing = regions::narrow(
966            self.parts.reading(self.theory, self.narrower)?,
967            self.restrictions,
968            entry,
969            &mut workspace.scratch,
970            budget,
971            counts,
972            check.as_mut(),
973        )?;
974        // Between regions, the producer's tier may reach its publication
975        // trigger.
976        self.parts
977            .visited(&mut workspace.tier, &mut workspace.scratch, budget, counts)?;
978        match walk::inspect(entry, narrowing, Counting::Never, false) {
979            walk::Step::Refuted => {
980                counts.refuted = 1;
981                return Ok(Step::Refuted);
982            }
983            walk::Step::Split(atom) => {
984                budget.decide()?;
985                return Ok(Step::Split(atom));
986            }
987            walk::Step::Leaf => {}
988            walk::Step::Counted => unreachable!("Counting::Never cannot count a region"),
989        }
990        if self.remaining == 0 {
991            return Err(Incomplete::CandidateLimit);
992        }
993        if !self.reserve_output_slot() {
994            return Ok(Step::Deferred);
995        }
996        let candidate = regions::leaf_interpretation(self.theory, &entry.region)?;
997        counts.leaves = 1;
998        Ok(Step::Candidate(candidate))
999    }
