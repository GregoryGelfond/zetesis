1//! Decide a default-negated flat atom of a rule's body where the completed
2//! support does.
3//!
4//! Emission reads the completed support, and that support decides two kinds
5//! of atom in every answer set.
6//!
7//! A supported atom that is an explicit fact or belongs to a certain
8//! predicate holds in all of them (`fixed_facts`). The retained roots force
9//! it into every model of the theory and of its reduct, so reading it as true
10//! under a negation preserves both evaluations exactly as at a positive
11//! occurrence, and the same check on the emitted theory covers it
12//! ([`Builder::fixed_atoms_are_derived`]): the atom is recorded as read
13//! through its fixing at either sign.
14//!
15//! An atom outside the completed support holds in none. Every emitted
16//! instance takes its head from that support, and so does every fact, so the
17//! theory has no producer for the atom: it occurs in no head. Removing such
18//! an atom from an interpretation leaves every implication of the frozen
19//! reduct satisfied, since no consequent reads it, so an interpretation that
20//! holds it has a proper subset satisfying its reduct and is no answer set.
21//! Reading the atom as false therefore changes neither evaluation at an
22//! interpretation without it, and no answer set has it
23//! (`DecidedNegation.absent_false`, `absent_stable`).
24//!
25//! `not a` is then false for a fixed `a` and true for an absent one, and
26//! `not not a` the reverse. A false literal makes its body false, and the
27//! instance is not emitted: it has no root and is no producer of its head.
28//! A true literal leaves the body. In neither case does the occurrence add
29//! the atom to the theory: an absent atom is never interned, and a fixed one
30//! is, to read its fixing, but has a root of its own already. A supported
31//! atom that is not fixed keeps its literal.
32//!
33//! What is decided depends on whose body it is ([`Decide`]):
34//!
35//! - A producer's body decides both kinds, on every route that emits it: the
36//!   complete join, its components and its continuations. Support completion
37//!   derives a head from exactly the rows whose decided negated atoms hold
38//!   (`formula_support::decided_negations_hold`), and this drops those
39//!   instances and any other whose negated atom the completed support
40//!   decides, so no emitted head lies outside the support.
41//! - A constraint's body decides a fixed atom alone. An atom outside the
42//!   support keeps its literal there, and so stays named, and a constraint
43//!   dropped for a fixed atom still names the atoms of its other literals:
44//!   a constraint that is streamed instead of emitted names every atom its
45//!   rows read, and both routes publish the same atoms.
46//! - A local scope decides nothing: a conditional literal's parts, a
47//!   projection, an aggregate's or a choice's element condition and a head
48//!   are emitted as written.
49//!
50//! Only the theory's builder emits a rule's own body. An objective's
51//! condition and a discarded validation body are lowered as scopes, and keep
52//! every literal.
53//!
54//! One unit for the decision, with the pattern's key and the support lookup
55//! charging their own.

69/// Which default-negated flat atoms the emission of one body decides.
70#[derive(Clone, Copy, Debug, PartialEq, Eq)]
71pub(super) enum Decide {
72    /// A local scope: every literal is emitted as written.
73    Nothing,
74    /// A constraint's body: an atom that is fixed.
75    Fixed,
76    /// A producer's body: an atom that is fixed or outside the support.
77    Supported,
78}
79
80impl Decide {
81    /// What the own body of `rule` decides: a constraint's or a producer's.
82    pub(super) fn of(rule: &RuleIr) -> Self {
83        if matches!(rule.head, HeadIr::Normal(None)) {
84            Self::Fixed
85        } else {
86            Self::Supported
87        }
88    }
89}
90
91/// What the emission of one default-negated body atom found.
92#[derive(Clone, Copy, Debug, PartialEq, Eq)]
93pub(super) enum Negated {
94    /// The completed support decides the literal: its value.
95    Decided(usize),
96    /// The atom is supported and not fixed, so its literal stays: the atom's
97    /// node, named by the lookup that found it supported.
98    Named(usize),
99    /// Nothing was read, or an absent atom keeps its literal: the caller
100    /// names the atom as written.
101    Written,
102}
103
104impl Builder<'_, '_, '_> {
105    /// What `decide` and the completed support make of the body occurrence
106    /// `negation pattern` under `assignment`, as the module header states.
107    /// `negation` is `Not` or `NotNot`. One lookup serves the support test
108    /// and names a supported atom.
109    pub(super) fn decided_negation(
110        &mut self,
111        decide: Decide,
112        negation: DefaultNegation,
113        pattern: AtomPattern,
114        assignment: &Binding,
115        location: ProgramSite,
116    ) -> Result<Negated, FormulaFailure> {
117        debug_assert_ne!(negation, DefaultNegation::None);
118        if decide == Decide::Nothing || certain::negation_left_out() {
119            return Ok(Negated::Written);
120        }
121        // A rule's own body is emitted by the theory's builder alone.
122        debug_assert!(matches!(self.purpose, Purpose::Theory));
123        self.work(location)?;
124        let prepared =
125            self.computation
126                .static_pattern(pattern, self.limits, self.counters, location)?;
127        let supported = self.computation.supported_atom(
128            prepared,
129            assignment,
130            self.limits,
131            self.counters,
132            location,
133        )?;
134        let Some(source) = supported else {
135            return Ok(if decide == Decide::Supported {
136                Negated::Decided(boolean(negation != DefaultNegation::NotNot))
137            } else {
138                Negated::Written
139            });
140        };
141        let atom = self.atom_identity(&source, location)?;
142        if self.fixed_body_atom(atom, location)? != VERUM {
143            return Ok(Negated::Named(atom));
144        }
145        Ok(Negated::Decided(boolean(
146            negation == DefaultNegation::NotNot,
147        )))
148    }
149}
