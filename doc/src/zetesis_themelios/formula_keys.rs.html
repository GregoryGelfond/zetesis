1//! Constraints over a keyed value, asked as the one atom the key admits.
2//!
3//! A keyed relation holds exactly one value per key ([`zetesis_domain::keys`]).
4//! A constraint that reads that value only to compare it therefore forbids
5//! exactly the answer sets in which the key's one value is not the demanded
6//! one, and can ask for the demanded atom instead of reading every value:
7//! the product of the demanded value with every value the key admits is
8//! never formed. Two patterns are read; each carries its meaning argument.
9//!
10//! *One value.* `:- G, p(k, Y), Y != t.`, with `Y` read nowhere else, `t`
11//! free of `Y` and no anonymous variable in the key `k`, becomes `:- G, b(k), not p(k, t).`, where `b` is the key's
12//! body. Whenever `b(k)` holds, exactly one `p(k, y)` holds; the written
13//! constraint fires iff that `y` differs from `t`, iff `p(k, t)` is absent,
14//! iff the asked constraint fires. Whenever `b(k)` does not hold, no `p(k, _)`
15//! holds and neither constraint fires.
16//!
17//! *A digit and a carry.* `:- G, p(k, Y), q(j, C), s != Y + c*C.`, with `Y`
18//! and `C` read nowhere else, `s` free of both, `c ≥ 2`, every value `p`
19//! admits in `0..c-1` and every value `q` admits a natural number, becomes
20//! `:- G, b(k), b'(j), not p(k, s \ c).` and `:- G, b(k), b'(j), not q(j, s / c).`
21//! For `s ≥ 0` the equation `s = y + c·C` over those ranges has the one
22//! solution `y = s \ c`, `C = s / c`; the written constraint fires iff the
23//! chosen pair is not that solution, iff one of the two asked atoms is
24//! absent. For `s < 0` no pair in range solves it and the written constraint
25//! fires; `s \ c` is then negative or zero with `s / c` negative, so an asked
26//! atom is absent and an asked constraint fires. Division by `c ≥ 2` is
27//! defined, and `s` is evaluated where the written constraint evaluated it.
28//! The values `p` admits are those of its choice's condition, and the
29//! condition's are read from the facts of a literal binding the value when
30//! facts are all that produces it ([`zetesis_domain::FactIndex`], read once
31//! per analysis): what the facts
32//! admit is exactly what the relation admits. A condition produced otherwise
33//! bounds nothing, and the constraint is left as written.
34//!
35//! Both patterns also require a checked-evaluation certificate for every
36//! term of the original constraint. Independent fact bounds must establish
37//! numeric operands and an `i32` range at every arithmetic intermediate;
38//! comparisons supply no such bounds. This includes the retained body, since
39//! replacing a comparison by a negative gate changes which substitutions
40//! are excluded. The digit-and-carry pattern additionally requires `s` to be
41//! numeric. Unproved safety leaves the constraint written, preserving its
42//! reached failures, exclusions and diagnostics. The mathematical integer
43//! equation alone does not establish these machine-arithmetic obligations.
44//!
45//! A key position must name its value in both patterns. The asked atom stands
46//! under `not`, where `p(_, t)` holds when some key has the value `t`, so
47//! `not p(_, t)` forbids only that no key has it, while the written constraint
48//! forbids a wrong value at every key. A constraint with an anonymous key
49//! position is left as written.
50//!
51//! The rewrite reads the analyzed program, where facts are expanded and
52//! constants resolved, once every statement is compiled, and names the
53//! written constraints to replace by their original statement ID; preparation then
54//! compiles the asked constraints in their place, so nothing is prepared
55//! twice. The key analysis and its readings of facts run under the key work
56//! ceiling and the preparation's remaining term work, and their steps are
57//! charged to the term work; a stop ends the asking, leaves every constraint
58//! not yet asked as written, and is reported. Nothing is claimed for a
59//! constraint outside the two patterns, which is left as written.
60//!
61//! The analyzed program may be a dependency projection
62//! ([`crate::AnalysisBasis`]): pools retained inside local conditions can produce
63//! several pool-free analysis carriers. Distinct carriers count as multiple
64//! producers and cannot establish a single-producer key. Coincident carriers
65//! collapse to the same producer and condition. Independently, a constraint is
66//! eligible for rewriting only when its original owner emits exactly one unique
67//! analyzed carrier; expanded or merged constraints remain as written.

87/// How the key analysis of one preparation ended.
88#[derive(Clone, Copy, Debug, PartialEq, Eq)]
89pub enum KeyAnalysis {
90    /// Every keyed relation was read, and every constraint in one of the two
91    /// patterns asked.
92    Complete,
93    /// The analysis exceeded its work ceiling: every constraint not yet
94    /// asked was left as written, which changes no answer set.
95    Stopped(Stop),
96}

98/// The constraints asked in place of original ones, by their statement IDs,
99/// retaining the analyzed carrier's provenance; and how key analysis ended.
100pub(crate) struct Asked {
101    pub rules: BTreeMap<StatementId, (Provenance, Vec<Rule>)>,
102    pub analysis: KeyAnalysis,
103}

105/// What one written constraint became.

108    Written,

112/// Ask every keyed constraint of the analyzed program. The key analysis and
113/// every reading of facts spend at most `limits.max_key_work` steps and no
114/// more than the term work remaining, and the steps spent are charged to
115/// the term work whether the analysis completed or stopped.
116///
117/// # Errors
118/// Returns the budget refusal when the inspection of a statement exhausts
119/// the term work.
120pub(crate) fn ask_all(
121    analyzed: &SourceProgram,
122    owners: &owners::Owners,
123    limits: &FormulaLimits,
124    budget: &mut Budget,
125    location: ProgramSite,
126) -> Result<Asked, FormulaFailure> {
127    // The shared key-work ceiling bounds the analysis between control polls.
128    budget.poll(location)?;
129    let mut work = KeyWork::new(limits.max_key_work.min(budget.remaining_term_work()));
130    let asked = ask_under(analyzed, owners, &mut work, budget, location);
131    budget.charge(
132        ExpansionResource::TermWork,
133        u128::from(work.steps()),
134        location,
135    )?;
136    asked
137}

139fn ask_under(
140    analyzed: &SourceProgram,
141    owners: &owners::Owners,
142    work: &mut KeyWork,
143    budget: &mut Budget,
144    location: ProgramSite,
145) -> Result<Asked, FormulaFailure> {
146    let mut asked = Asked {
147        rules: BTreeMap::new(),
148        analysis: KeyAnalysis::Complete,
149    };
150    let keys = match zetesis_domain::keys(analyzed, work) {
151        Ok(keys) => keys,
152        Err(stop) => {
153            asked.analysis = KeyAnalysis::Stopped(stop);
154            return Ok(asked);
155        }
156    };
157    if keys.is_empty() {
158        return Ok(asked);
159    }
160    let keys: BTreeMap<&Signature, &KeyedRelation<'_>> =
161        keys.iter().map(|key| (key.signature(), key)).collect();
162    // Every question about facts below is answered from one reading.
163    let facts = match FactIndex::read(analyzed, work) {
164        Ok(facts) => facts,
165        Err(stop) => {
166            asked.analysis = KeyAnalysis::Stopped(stop);
167            return Ok(asked);
168        }
169    };
170    // Expansion and canonical-content collisions have already cleared their
171    // sidecar ownership. Provenance supplies evidence, never rewrite identity.
172    for (index, statement) in analyzed.statements().enumerate() {
173        budget.charge(ExpansionResource::TermWork, 1, location)?;
174        let Some(owner) = owners.at(index) else {
175            continue;
176        };
177        let site = crate::extended::origin(statement, location.with_statement(owner));
178        match ask(statement, &keys, &facts, work, budget, site)? {
179            Outcome::Asked(rules) => {
180                asked
181                    .rules
182                    .insert(owner, (statement.provenance().clone(), rules));
183            }
184            Outcome::Written => {}
185            Outcome::Stopped(stop) => {
186                asked.analysis = KeyAnalysis::Stopped(stop);
187                return Ok(asked);
188            }
189        }
190    }
191    Ok(asked)
192}

194/// A positive atom of the constraint whose value position names a variable
195/// read only there and in the comparison: the one the constraint demands.
196struct Demand<'a> {
197    element: usize,
198    key: &'a KeyedRelation<'a>,
199    terms: &'a [Term],
200    variable: &'a VarName,
201}

203/// The asked constraints for one written constraint, or `None` when it is
204/// outside both patterns.
205fn ask(
206    statement: &WithProvenance<Statement>,
207    keys: &BTreeMap<&Signature, &KeyedRelation<'_>>,
208    facts: &FactIndex<'_>,
209    work: &mut KeyWork,
210    budget: &mut Budget,
211    location: ProgramSite,
212) -> Result<Outcome, FormulaFailure> {
213    let Statement::Rule(rule) = statement.get() else {
214        return Ok(Outcome::Written);
215    };
216    if !matches!(rule.head().get(), Head::Falsum) {
217        return Ok(Outcome::Written);
218    }
219    let body = rule.body().get();
220    let mut elements = Vec::new();
221    let mut comparison = None;
222    let mut occurrences: BTreeMap<&VarName, usize> = BTreeMap::new();
223    for (index, element) in body.elements().enumerate() {
224        budget.charge(ExpansionResource::TermWork, 1, location)?;
225        let BodyElement::Literal(literal) = element.get() else {
226            return Ok(Outcome::Written);
227        };
228        if literal.negation != DefaultNegation::None {
229            return Ok(Outcome::Written);
230        }
231        match &literal.inner {
232            LiteralInner::Atom(atom) => {
233                let Arguments::Single(terms) = &atom.get().arguments else {
234                    return Ok(Outcome::Written);
235                };
236                for term in terms {
237                    count(term, &mut occurrences);
238                }
239                elements.push(literal);
240            }
241            LiteralInner::Comparison(chain) => {
242                let chain = chain.get();
243                let mut steps = chain.steps();
244                let (Some((relation, second)), None) = (steps.next(), steps.next()) else {
245                    return Ok(Outcome::Written);
246                };
247                count(chain.first(), &mut occurrences);
248                count(second, &mut occurrences);
249                if relation == Relation::Neq {
250                    if comparison.replace((index, chain.first(), second)).is_some() {
251                        return Ok(Outcome::Written);
252                    }
253                } else {
254                    elements.push(literal);
255                }
256            }
257            LiteralInner::True | LiteralInner::False => return Ok(Outcome::Written),
258        }
259    }
260    let Some((skipped, left, right)) = comparison else {
261        return Ok(Outcome::Written);
262    };
263    let proof = match safety::Proof::of(body, keys, facts, work) {
264        Ok(Some(proof)) => proof,
265        Ok(None) => return Ok(Outcome::Written),
266        Err(failure) => return applicability_failure(failure, location),
267    };
268    let demands = demands(body, skipped, keys, &occurrences);
269    let asked = match one_value(left, right, &demands) {
270        Some((demand, value)) => vec![(demand, value)],
271        None => match digit_and_carry(left, right, &demands, facts, &proof, work) {
272            Ok(Some(asked)) => asked,
273            Ok(None) => return Ok(Outcome::Written),
274            Err(failure) => return applicability_failure(failure, location),
275        },
276    };
277    let rest: Vec<&Literal> = body
278        .elements()
279        .enumerate()
280        .filter(|(index, _)| {
281            *index != skipped && asked.iter().all(|(demand, _)| demand.element != *index)
282        })
283        .filter_map(|(_, element)| match element.get() {
284            BodyElement::Literal(literal) => Some(literal),
285            _ => None,
286        })
287        .collect();
288    let mut rules = Vec::new();
289    for (demand, value) in &asked {
290        let mut literals: Vec<Literal> = rest.iter().map(|literal| (*literal).clone()).collect();
291        for (demand, _) in &asked {
292            literals.extend(key_body(demand));
293        }
294        let mut terms = demand.terms.to_vec();
295        terms[demand.key.value_position()] = value.clone();
296        literals.push(Literal {
297            negation: DefaultNegation::Not,
298            inner: LiteralInner::Atom(WithProvenance::constructed(Atom {
299                sign: demand.key.signature().sign,
300                name: demand.key.signature().name.clone(),
301                arguments: Arguments::Single(terms),
302            })),
303        });
304        rules.push(Rule::new(
305            Head::Falsum,
306            Body::new(literals.into_iter().map(BodyElement::Literal)),
307        ));
308    }
309    Ok(Outcome::Asked(rules))
310}

312/// Exhausted key work declines rewriting; a failed allocation is a located
313/// resource refusal. Both applicability checks use the same boundary.
314fn applicability_failure(
315    failure: safety::Failure,
316    location: ProgramSite,
317) -> Result<Outcome, FormulaFailure> {
318    match failure {
319        safety::Failure::Work(stop) => Ok(Outcome::Stopped(stop)),
320        safety::Failure::Allocation => Err(FormulaFailure::SupportRelation {
321            error: zetesis_core::relation::Failure::Allocation,
322            location,
323        }),
324    }
325}

327/// Every keyed atom of the body whose value is a variable read only there
328/// and in the comparison: the values the constraint can demand.
329fn demands<'a>(
330    body: &'a Body,
331    skipped: usize,
332    keys: &BTreeMap<&Signature, &'a KeyedRelation<'a>>,
333    occurrences: &BTreeMap<&VarName, usize>,
334) -> Vec<Demand<'a>> {
335    let mut demands = Vec::new();
336    for (index, literal) in body.elements().enumerate() {
337        if index == skipped {
338            continue;
339        }
340        let BodyElement::Literal(Literal {
341            inner: LiteralInner::Atom(atom),
342            ..
343        }) = literal.get()
344        else {
345            continue;
346        };
347        let atom = atom.get();
348        let Arguments::Single(terms) = &atom.arguments else {
349            continue;
350        };
351        let Some(signature) = atom_signature(atom, terms.len()) else {
352            continue;
353        };
354        let Some(key) = keys.get(&signature) else {
355            continue;
356        };
357        let Some(Term::Variable(Variable::Named(variable))) = terms.get(key.value_position())
358        else {
359            continue;
360        };
361        // The asked atom stands under `not`, where an anonymous argument
362        // reads as "for no value at all": the demanded atom is the key's one
363        // atom only when every key position names its value.
364        if occurrences.get(variable) != Some(&2)
365            || terms.iter().enumerate().any(|(position, term)| {
366                position != key.value_position() && (mentions(term, variable) || anonymous(term))
367            })
368        {
369            continue;
370        }
371        demands.push(Demand {
372            element: index,
373            key,
374            terms,
375            variable,
376        });
377    }
378    demands
379}

381/// `Y != t` or `t != Y` with `Y` demanded and `t` free of `Y`.
382fn one_value<'a>(
383    left: &Term,
384    right: &Term,
385    demands: &'a [Demand<'a>],
386) -> Option<(&'a Demand<'a>, Term)> {
387    for (side, other) in [(left, right), (right, left)] {
388        let Term::Variable(Variable::Named(variable)) = side else {
389            continue;
390        };
391        if let Some(demand) = demands.iter().find(|demand| demand.variable == variable)
392            && !mentions(other, variable)
393        {
394            return Some((demand, other.clone()));
395        }
396    }
397    None
398}

400/// `s != Y + c*C` in any order of sides and summands, with `Y` and `C`
401/// demanded, `s` free of both, `Y` a digit in base `c` and `C` a natural
402/// number by the facts of the conditions binding them.
403///
404/// # Errors
405/// Returns a key work stop or a failed reservation for the safety proof.
406fn digit_and_carry<'a>(
407    left: &Term,
408    right: &Term,
409    demands: &'a [Demand<'a>],
410    facts: &FactIndex<'_>,
411    proof: &safety::Proof<'_>,
412    work: &mut KeyWork,
413) -> Result<Option<Vec<(&'a Demand<'a>, Term)>>, safety::Failure> {
414    for (sum, other) in [(left, right), (right, left)] {
415        let Some((digit, base, carry)) = digit_plus_carry(sum, demands) else {
416            continue;
417        };
418        if mentions(other, digit.variable) || mentions(other, carry.variable) {
419            continue;
420        }
421        // Source comparison accepts values of different kinds; the quotient
422        // and remainder introduced here require a numeric dividend.
423        if !proof.numeric(other, work)? {
424            continue;
425        }
426        if !admits_within(facts, digit.key, 0, i64::from(base) - 1, work)?
427            || !admits_within(facts, carry.key, 0, i64::from(i32::MAX), work)?
428        {
429            continue;
430        }
431        let quotient = |operator| Term::BinaryOperation {
432            operator,
433            left: Box::new(other.clone()),
434            right: Box::new(Term::Symbolic(Symbol::Number(base))),
435        };
436        return Ok(Some(vec![
437            (digit, quotient(BinaryOp::Mod)),
438            (carry, quotient(BinaryOp::Div)),
439        ]));
440    }
441    Ok(None)
442}

444/// `Y + c*C`, `c*C + Y`, `Y + C*c` or `C*c + Y` over two distinct demands.
445fn digit_plus_carry<'a>(
446    term: &Term,
447    demands: &'a [Demand<'a>],
448) -> Option<(&'a Demand<'a>, i32, &'a Demand<'a>)> {
449    let Term::BinaryOperation {
450        operator: BinaryOp::Add,
451        left,
452        right,
453    } = term
454    else {
455        return None;
456    };
457    for (digit, product) in [(left, right), (right, left)] {
458        let Term::Variable(Variable::Named(variable)) = &**digit else {
459            continue;
460        };
461        let Some(digit) = demands.iter().find(|demand| demand.variable == variable) else {
462            continue;
463        };
464        let Term::BinaryOperation {
465            operator: BinaryOp::Mul,
466            left,
467            right,
468        } = &**product
469        else {
470            continue;
471        };
472        for (base, carry) in [(left, right), (right, left)] {
473            let Term::Symbolic(Symbol::Number(base)) = &**base else {
474                continue;
475            };
476            let Term::Variable(Variable::Named(variable)) = &**carry else {
477                continue;
478            };
479            let Some(carry) = demands.iter().find(|demand| demand.variable == variable) else {
480                continue;
481            };
482            if *base >= 2 && !std::ptr::eq(digit, carry) {
483                return Some((digit, *base, carry));
484            }
485        }
486    }
487    None
488}

490/// Whether every value the key's condition admits is a number in
491/// `low..=high`, read from the facts of a literal of the condition binding
492/// the value. The value is bound by the condition, so a literal names it;
493/// every one that does bounds it, and one within range suffices. A literal
494/// over a predicate produced by anything but facts bounds nothing.
495///
496/// # Errors
497/// Returns the key work's stop.
498fn admits_within(
499    facts: &FactIndex<'_>,
500    key: &KeyedRelation<'_>,
501    low: i64,
502    high: i64,
503    work: &mut KeyWork,
504) -> Result<bool, Stop> {
505    let positions = key.condition().literals().filter_map(|literal| {
506        let LiteralInner::Atom(atom) = &literal.get().inner else {
507            return None;
508        };
509        let atom = atom.get();
510        let Arguments::Single(terms) = &atom.arguments else {
511            return None;
512        };
513        let position = terms
514            .iter()
515            .position(|term| mentions(term, key.value_variable()))?;
516        Some((atom_signature(atom, terms.len())?, position))
517    });
518    for (signature, position) in positions {
519        if let Some(values) = facts.values(&signature, position, work)?
520            && within(&values, low, high)
521        {
522            return Ok(true);
523        }
524    }
525    Ok(false)
526}
527
528/// Whether every value is a number in `low..=high`.
529fn within(values: &[&Symbol], low: i64, high: i64) -> bool {
530    values.iter().all(|value| {
531        matches!(value, Symbol::Number(number) if (low..=high).contains(&i64::from(*number)))
532    })
533}

535/// The key's body with its key variables replaced by the demand's terms.
536/// The key's analysis admits a body of positive plain atoms with one
537/// argument tuple each, so no other literal occurs here.
538fn key_body(demand: &Demand<'_>) -> Vec<Literal> {
539    let substitution: BTreeMap<&VarName, &Term> = demand
540        .terms
541        .iter()
542        .enumerate()
543        .filter_map(|(position, term)| Some((demand.key.key_variable(position)?, term)))
544        .collect();
545    demand
546        .key
547        .body()
548        .elements()
549        .map(|element| match element.get() {
550            BodyElement::Literal(Literal {
551                negation: DefaultNegation::None,
552                inner: LiteralInner::Atom(atom),
553            }) => {
554                let atom = atom.get();
555                let Arguments::Single(terms) = &atom.arguments else {
556                    unreachable!("a key's body atom has one argument tuple")
557                };
558                Literal {
559                    negation: DefaultNegation::None,
560                    inner: LiteralInner::Atom(WithProvenance::constructed(Atom {
561                        sign: atom.sign,
562                        name: atom.name.clone(),
563                        arguments: Arguments::Single(
564                            terms
565                                .iter()
566                                .map(|term| match term {
567                                    Term::Variable(Variable::Named(name)) => substitution
568                                        .get(name)
569                                        .map_or_else(|| term.clone(), |term| (*term).clone()),
570                                    _ => term.clone(),
571                                })
572                                .collect(),
573                        ),
574                    })),
575                }
576            }
577            _ => unreachable!("a key's body holds only positive plain atoms"),
578        })
579        .collect()
580}

582fn count<'a>(term: &'a Term, occurrences: &mut BTreeMap<&'a VarName, usize>) {
583    for subterm in term.subterms() {
584        if let Term::Variable(Variable::Named(name)) = subterm {
585            *occurrences.entry(name).or_default() += 1;
586        }
587    }
588}

590fn anonymous(term: &Term) -> bool {
591    term.subterms()
592        .any(|subterm| matches!(subterm, Term::Variable(Variable::Anonymous)))
593}
594
595fn mentions(term: &Term, variable: &VarName) -> bool {
596    term.subterms()
597        .any(|subterm| matches!(subterm, Term::Variable(Variable::Named(name)) if name == variable))
