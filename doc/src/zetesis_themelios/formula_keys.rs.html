1//! Constraints over a keyed value, asked as the one atom the key admits.
2//!
3//! A keyed relation holds exactly one value per key ([`zetesis_domain::keys`]).
4//! A constraint that reads that value only to compare it therefore forbids
5//! exactly the answer sets in which the key's one value is not the demanded
6//! one, and can ask for the demanded atom instead of reading every value:
7//! the product of the demanded value with every value the key admits is
8//! never formed. Two patterns are read; each carries its meaning argument.
9//!
10//! *One value.* `:- G, p(k, Y), Y != t.`, with `Y` read nowhere else, `t`
11//! free of `Y` and no anonymous variable in the key `k`, becomes `:- G, b(k), not p(k, t).`, where `b` is the key's
12//! body. Whenever `b(k)` holds, exactly one `p(k, y)` holds; the written
13//! constraint fires iff that `y` differs from `t`, iff `p(k, t)` is absent,
14//! iff the asked constraint fires. Whenever `b(k)` does not hold, no `p(k, _)`
15//! holds and neither constraint fires.
16//!
17//! *A digit and a carry.* `:- G, p(k, Y), q(j, C), s != Y + c*C.`, with `Y`
18//! and `C` read nowhere else, `s` free of both, `c ≥ 2`, every value `p`
19//! admits in `0..c-1` and every value `q` admits a natural number, becomes
20//! `:- G, b(k), b'(j), not p(k, s \ c).` and `:- G, b(k), b'(j), not q(j, s / c).`
21//! For `s ≥ 0` the equation `s = y + c·C` over those ranges has the one
22//! solution `y = s \ c`, `C = s / c`; the written constraint fires iff the
23//! chosen pair is not that solution, iff one of the two asked atoms is
24//! absent. For `s < 0` no pair in range solves it and the written constraint
25//! fires; `s \ c` is then negative or zero with `s / c` negative, so an asked
26//! atom is absent and an asked constraint fires. Division by `c ≥ 2` is
27//! defined, and `s` is evaluated where the written constraint evaluated it.
28//! The values `p` admits are those of its choice's condition, and the
29//! condition's are read from the facts of a literal binding the value when
30//! facts are all that produces it ([`zetesis_domain::FactIndex`], read once
31//! per analysis): what the facts
32//! admit is exactly what the relation admits. A condition produced otherwise
33//! bounds nothing, and the constraint is left as written.
34//!
35//! Both patterns also require a checked-evaluation certificate for every
36//! term of the original constraint. Independent fact bounds must establish
37//! numeric operands and an `i32` range at every arithmetic intermediate;
38//! comparisons supply no such bounds. This includes the retained body, since
39//! replacing a comparison by a negative gate changes which substitutions
40//! are excluded. The digit-and-carry pattern additionally requires `s` to be
41//! numeric. Unproved safety leaves the constraint written, preserving its
42//! reached failures, exclusions and diagnostics. The mathematical integer
43//! equation alone does not establish these machine-arithmetic obligations.
44//!
45//! A key position must name its value in both patterns. The asked atom stands
46//! under `not`, where `p(_, t)` holds when some key has the value `t`, so
47//! `not p(_, t)` forbids only that no key has it, while the written constraint
48//! forbids a wrong value at every key. A constraint with an anonymous key
49//! position is left as written.
50//!
51//! The rewrite reads the analyzed program, where facts are expanded and
52//! constants resolved, once every statement is compiled, and names the
53//! written constraints to replace by their parsed origin; preparation then
54//! compiles the asked constraints in their place, so nothing is prepared
55//! twice. The key analysis and its readings of facts run under the key work
56//! ceiling and the preparation's remaining term work, and their steps are
57//! charged to the term work; a stop ends the asking, leaves every constraint
58//! not yet asked as written, and is reported. Nothing is claimed for a
59//! constraint outside the two patterns, which is left as written.
60//!
61//! The analyzed program may be a dependency projection
62//! ([`crate::AnalysisBasis`]): a statement with a pool that outlives
63//! normalization, such as one inside a condition or an aggregate element,
64//! stands in it as one pool-free copy per alternative, read as several
65//! statements where the program means one. The rewrite is sound over it. A
66//! key is claimed only for a relation with one producer, and every copy of
67//! a projected statement produces what the statement produces, since a pool
68//! never changes an atom's signature and a pooled argument list is unpooled
69//! before the projection, into the elements of its choice or into whole
70//! rules; so a projected statement, of two copies at least, is never a
71//! key's producer, and a projected constraint, several statements under one
72//! origin, is never asked. Copies that coincide come from coinciding
73//! alternatives, which the choice reads as one element.

92/// How the key analysis of one preparation ended.
93#[derive(Clone, Copy, Debug, PartialEq, Eq)]
94pub enum KeyAnalysis {
95    /// Every keyed relation was read, and every constraint in one of the two
96    /// patterns asked.
97    Complete,
98    /// The analysis exceeded its work ceiling: every constraint not yet
99    /// asked was left as written, which changes no answer set.
100    Stopped(Stop),
101}

103/// The constraints asked in place of written ones, by the parsed origin of
104/// the written constraint each set replaces, with that constraint's
105/// provenance; and how the key analysis ended.
106pub(crate) struct Asked {
107    pub rules: BTreeMap<Location, (Provenance, Vec<Rule>)>,
108    pub analysis: KeyAnalysis,
109}

111/// What one written constraint became.

114    Written,

118/// Ask every keyed constraint of the analyzed program. The key analysis and
119/// every reading of facts spend at most `limits.max_key_work` steps and no
120/// more than the term work remaining, and the steps spent are charged to
121/// the term work whether the analysis completed or stopped.
122///
123/// # Errors
124/// Returns the budget refusal when the inspection of a statement exhausts
125/// the term work.
126pub(crate) fn ask_all(
127    analyzed: &SourceProgram,
128    limits: &FormulaLimits,
129    budget: &mut Budget,
130    location: Location,
131) -> Result<Asked, FormulaFailure> {
132    let mut work = KeyWork::new(limits.max_key_work.min(budget.remaining_term_work()));
133    let asked = ask_under(analyzed, &mut work, budget, location);
134    budget.charge(
135        ExpansionResource::TermWork,
136        u128::from(work.steps()),
137        location,
138    )?;
139    asked
140}

142fn ask_under(
143    analyzed: &SourceProgram,
144    work: &mut KeyWork,
145    budget: &mut Budget,
146    location: Location,
147) -> Result<Asked, FormulaFailure> {
148    let mut asked = Asked {
149        rules: BTreeMap::new(),
150        analysis: KeyAnalysis::Complete,
151    };
152    let keys = match zetesis_domain::keys(analyzed, work) {
153        Ok(keys) => keys,
154        Err(stop) => {
155            asked.analysis = KeyAnalysis::Stopped(stop);
156            return Ok(asked);
157        }
158    };
159    if keys.is_empty() {
160        return Ok(asked);
161    }
162    let keys: BTreeMap<&Signature, &KeyedRelation<'_>> =
163        keys.iter().map(|key| (key.signature(), key)).collect();
164    // Every question about facts below is answered from one reading.
165    let facts = match FactIndex::read(analyzed, work) {
166        Ok(facts) => facts,
167        Err(stop) => {
168            asked.analysis = KeyAnalysis::Stopped(stop);
169            return Ok(asked);
170        }
171    };
172    // The analyzed statement of each source statement, by parsed origin; a
173    // source statement normalized into several is left as written.
174    let mut by_origin: BTreeMap<Location, Vec<&WithProvenance<Statement>>> = BTreeMap::new();
175    for carrier in analyzed.statements() {
176        budget.charge(ExpansionResource::TermWork, 1, location)?;
177        if let [origin] = crate::extended::parsed_origins(carrier)[..] {
178            by_origin.entry(origin).or_default().push(carrier);
179        }
180    }
181    for (origin, statements) in by_origin {
182        let [statement] = statements[..] else {
183            continue;
184        };
185        match ask(statement, &keys, &facts, work, budget, location)? {
186            Outcome::Asked(rules) => {
187                asked
188                    .rules
189                    .insert(origin, (statement.provenance().clone(), rules));
190            }
191            Outcome::Written => {}
192            Outcome::Stopped(stop) => {
193                asked.analysis = KeyAnalysis::Stopped(stop);
194                return Ok(asked);
195            }
196        }
197    }
198    Ok(asked)
199}

201/// A positive atom of the constraint whose value position names a variable
202/// read only there and in the comparison: the one the constraint demands.
203struct Demand<'a> {
204    element: usize,
205    key: &'a KeyedRelation<'a>,
206    terms: &'a [Term],
207    variable: &'a VarName,
208}

210/// The asked constraints for one written constraint, or `None` when it is
211/// outside both patterns.
212fn ask(
213    statement: &WithProvenance<Statement>,
214    keys: &BTreeMap<&Signature, &KeyedRelation<'_>>,
215    facts: &FactIndex<'_>,
216    work: &mut KeyWork,
217    budget: &mut Budget,
218    location: Location,
219) -> Result<Outcome, FormulaFailure> {
220    let Statement::Rule(rule) = statement.get() else {
221        return Ok(Outcome::Written);
222    };
223    if !matches!(rule.head().get(), Head::Falsum) {
224        return Ok(Outcome::Written);
225    }
226    let body = rule.body().get();
227    let mut elements = Vec::new();
228    let mut comparison = None;
229    let mut occurrences: BTreeMap<&VarName, usize> = BTreeMap::new();
230    for (index, element) in body.elements().enumerate() {
231        budget.charge(ExpansionResource::TermWork, 1, location)?;
232        let BodyElement::Literal(literal) = element.get() else {
233            return Ok(Outcome::Written);
234        };
235        if literal.negation != DefaultNegation::None {
236            return Ok(Outcome::Written);
237        }
238        match &literal.inner {
239            LiteralInner::Atom(atom) => {
240                let Arguments::Single(terms) = &atom.get().arguments else {
241                    return Ok(Outcome::Written);
242                };
243                for term in terms {
244                    count(term, &mut occurrences);
245                }
246                elements.push(literal);
247            }
248            LiteralInner::Comparison(chain) => {
249                let chain = chain.get();
250                let mut steps = chain.steps();
251                let (Some((relation, second)), None) = (steps.next(), steps.next()) else {
252                    return Ok(Outcome::Written);
253                };
254                count(chain.first(), &mut occurrences);
255                count(second, &mut occurrences);
256                if relation == Relation::Neq {
257                    if comparison.replace((index, chain.first(), second)).is_some() {
258                        return Ok(Outcome::Written);
259                    }
260                } else {
261                    elements.push(literal);
262                }
263            }
264            LiteralInner::True | LiteralInner::False => return Ok(Outcome::Written),
265        }
266    }
267    let Some((skipped, left, right)) = comparison else {
268        return Ok(Outcome::Written);
269    };
270    let proof = match safety::Proof::of(body, keys, facts, work) {
271        Ok(Some(proof)) => proof,
272        Ok(None) => return Ok(Outcome::Written),
273        Err(failure) => return applicability_failure(failure, location),
274    };
275    let demands = demands(body, skipped, keys, &occurrences);
276    let asked = match one_value(left, right, &demands) {
277        Some((demand, value)) => vec![(demand, value)],
278        None => match digit_and_carry(left, right, &demands, facts, &proof, work) {
279            Ok(Some(asked)) => asked,
280            Ok(None) => return Ok(Outcome::Written),
281            Err(failure) => return applicability_failure(failure, location),
282        },
283    };
284    let rest: Vec<&Literal> = body
285        .elements()
286        .enumerate()
287        .filter(|(index, _)| {
288            *index != skipped && asked.iter().all(|(demand, _)| demand.element != *index)
289        })
290        .filter_map(|(_, element)| match element.get() {
291            BodyElement::Literal(literal) => Some(literal),
292            _ => None,
293        })
294        .collect();
295    let mut rules = Vec::new();
296    for (demand, value) in &asked {
297        let mut literals: Vec<Literal> = rest.iter().map(|literal| (*literal).clone()).collect();
298        for (demand, _) in &asked {
299            literals.extend(key_body(demand));
300        }
301        let mut terms = demand.terms.to_vec();
302        terms[demand.key.value_position()] = value.clone();
303        literals.push(Literal {
304            negation: DefaultNegation::Not,
305            inner: LiteralInner::Atom(WithProvenance::constructed(Atom {
306                sign: demand.key.signature().sign,
307                name: demand.key.signature().name.clone(),
308                arguments: Arguments::Single(terms),
309            })),
310        });
311        rules.push(Rule::new(
312            Head::Falsum,
313            Body::new(literals.into_iter().map(BodyElement::Literal)),
314        ));
315    }
316    Ok(Outcome::Asked(rules))
317}

319/// Exhausted key work declines rewriting; a failed allocation is a located
320/// resource refusal. Both applicability checks use the same boundary.
321fn applicability_failure(
322    failure: safety::Failure,
323    location: Location,
324) -> Result<Outcome, FormulaFailure> {
325    match failure {
326        safety::Failure::Work(stop) => Ok(Outcome::Stopped(stop)),
327        safety::Failure::Allocation => Err(FormulaFailure::SupportRelation {
328            error: zetesis_core::relation::Failure::Allocation,
329            location,
330        }),
331    }
332}

334/// Every keyed atom of the body whose value is a variable read only there
335/// and in the comparison: the values the constraint can demand.
336fn demands<'a>(
337    body: &'a Body,
338    skipped: usize,
339    keys: &BTreeMap<&Signature, &'a KeyedRelation<'a>>,
340    occurrences: &BTreeMap<&VarName, usize>,
341) -> Vec<Demand<'a>> {
342    let mut demands = Vec::new();
343    for (index, literal) in body.elements().enumerate() {
344        if index == skipped {
345            continue;
346        }
347        let BodyElement::Literal(Literal {
348            inner: LiteralInner::Atom(atom),
349            ..
350        }) = literal.get()
351        else {
352            continue;
353        };
354        let atom = atom.get();
355        let Arguments::Single(terms) = &atom.arguments else {
356            continue;
357        };
358        let Some(signature) = atom_signature(atom, terms.len()) else {
359            continue;
360        };
361        let Some(key) = keys.get(&signature) else {
362            continue;
363        };
364        let Some(Term::Variable(Variable::Named(variable))) = terms.get(key.value_position())
365        else {
366            continue;
367        };
368        // The asked atom stands under `not`, where an anonymous argument
369        // reads as "for no value at all": the demanded atom is the key's one
370        // atom only when every key position names its value.
371        if occurrences.get(variable) != Some(&2)
372            || terms.iter().enumerate().any(|(position, term)| {
373                position != key.value_position() && (mentions(term, variable) || anonymous(term))
374            })
375        {
376            continue;
377        }
378        demands.push(Demand {
379            element: index,
380            key,
381            terms,
382            variable,
383        });
384    }
385    demands
386}

388/// `Y != t` or `t != Y` with `Y` demanded and `t` free of `Y`.
389fn one_value<'a>(
390    left: &Term,
391    right: &Term,
392    demands: &'a [Demand<'a>],
393) -> Option<(&'a Demand<'a>, Term)> {
394    for (side, other) in [(left, right), (right, left)] {
395        let Term::Variable(Variable::Named(variable)) = side else {
396            continue;
397        };
398        if let Some(demand) = demands.iter().find(|demand| demand.variable == variable)
399            && !mentions(other, variable)
400        {
401            return Some((demand, other.clone()));
402        }
403    }
404    None
405}

407/// `s != Y + c*C` in any order of sides and summands, with `Y` and `C`
408/// demanded, `s` free of both, `Y` a digit in base `c` and `C` a natural
409/// number by the facts of the conditions binding them.
410///
411/// # Errors
412/// Returns a key work stop or a failed reservation for the safety proof.
413fn digit_and_carry<'a>(
414    left: &Term,
415    right: &Term,
416    demands: &'a [Demand<'a>],
417    facts: &FactIndex<'_>,
418    proof: &safety::Proof<'_>,
419    work: &mut KeyWork,
420) -> Result<Option<Vec<(&'a Demand<'a>, Term)>>, safety::Failure> {
421    for (sum, other) in [(left, right), (right, left)] {
422        let Some((digit, base, carry)) = digit_plus_carry(sum, demands) else {
423            continue;
424        };
425        if mentions(other, digit.variable) || mentions(other, carry.variable) {
426            continue;
427        }
428        // Source comparison accepts values of different kinds; the quotient
429        // and remainder introduced here require a numeric dividend.
430        if !proof.numeric(other, work)? {
431            continue;
432        }
433        if !admits_within(facts, digit.key, 0, i64::from(base) - 1, work)?
434            || !admits_within(facts, carry.key, 0, i64::from(i32::MAX), work)?
435        {
436            continue;
437        }
438        let quotient = |operator| Term::BinaryOperation {
439            operator,
440            left: Box::new(other.clone()),
441            right: Box::new(Term::Symbolic(Symbol::Number(base))),
442        };
443        return Ok(Some(vec![
444            (digit, quotient(BinaryOp::Mod)),
445            (carry, quotient(BinaryOp::Div)),
446        ]));
447    }
448    Ok(None)
449}

451/// `Y + c*C`, `c*C + Y`, `Y + C*c` or `C*c + Y` over two distinct demands.
452fn digit_plus_carry<'a>(
453    term: &Term,
454    demands: &'a [Demand<'a>],
455) -> Option<(&'a Demand<'a>, i32, &'a Demand<'a>)> {
456    let Term::BinaryOperation {
457        operator: BinaryOp::Add,
458        left,
459        right,
460    } = term
461    else {
462        return None;
463    };
464    for (digit, product) in [(left, right), (right, left)] {
465        let Term::Variable(Variable::Named(variable)) = &**digit else {
466            continue;
467        };
468        let Some(digit) = demands.iter().find(|demand| demand.variable == variable) else {
469            continue;
470        };
471        let Term::BinaryOperation {
472            operator: BinaryOp::Mul,
473            left,
474            right,
475        } = &**product
476        else {
477            continue;
478        };
479        for (base, carry) in [(left, right), (right, left)] {
480            let Term::Symbolic(Symbol::Number(base)) = &**base else {
481                continue;
482            };
483            let Term::Variable(Variable::Named(variable)) = &**carry else {
484                continue;
485            };
486            let Some(carry) = demands.iter().find(|demand| demand.variable == variable) else {
487                continue;
488            };
489            if *base >= 2 && !std::ptr::eq(digit, carry) {
490                return Some((digit, *base, carry));
491            }
492        }
493    }
494    None
495}

497/// Whether every value the key's condition admits is a number in
498/// `low..=high`, read from the facts of a literal of the condition binding
499/// the value. The value is bound by the condition, so a literal names it;
500/// every one that does bounds it, and one within range suffices. A literal
501/// over a predicate produced by anything but facts bounds nothing.
502///
503/// # Errors
504/// Returns the key work's stop.
505fn admits_within(
506    facts: &FactIndex<'_>,
507    key: &KeyedRelation<'_>,
508    low: i64,
509    high: i64,
510    work: &mut KeyWork,
511) -> Result<bool, Stop> {
512    let positions = key.condition().literals().filter_map(|literal| {
513        let LiteralInner::Atom(atom) = &literal.get().inner else {
514            return None;
515        };
516        let atom = atom.get();
517        let Arguments::Single(terms) = &atom.arguments else {
518            return None;
519        };
520        let position = terms
521            .iter()
522            .position(|term| mentions(term, key.value_variable()))?;
523        Some((atom_signature(atom, terms.len())?, position))
524    });
525    for (signature, position) in positions {
526        if let Some(values) = facts.values(&signature, position, work)?
527            && within(&values, low, high)
528        {
529            return Ok(true);
530        }
531    }
532    Ok(false)
533}

535/// Whether every value is a number in `low..=high`.
536fn within(values: &[&Symbol], low: i64, high: i64) -> bool {
537    values.iter().all(|value| {
538        matches!(value, Symbol::Number(number) if (low..=high).contains(&i64::from(*number)))
539    })
540}

542/// The key's body with its key variables replaced by the demand's terms.
543/// The key's analysis admits a body of positive plain atoms with one
544/// argument tuple each, so no other literal occurs here.
545fn key_body(demand: &Demand<'_>) -> Vec<Literal> {
546    let substitution: BTreeMap<&VarName, &Term> = demand
547        .terms
548        .iter()
549        .enumerate()
550        .filter_map(|(position, term)| Some((demand.key.key_variable(position)?, term)))
551        .collect();
552    demand
553        .key
554        .body()
555        .elements()
556        .map(|element| match element.get() {
557            BodyElement::Literal(Literal {
558                negation: DefaultNegation::None,
559                inner: LiteralInner::Atom(atom),
560            }) => {
561                let atom = atom.get();
562                let Arguments::Single(terms) = &atom.arguments else {
563                    unreachable!("a key's body atom has one argument tuple")
564                };
565                Literal {
566                    negation: DefaultNegation::None,
567                    inner: LiteralInner::Atom(WithProvenance::constructed(Atom {
568                        sign: atom.sign,
569                        name: atom.name.clone(),
570                        arguments: Arguments::Single(
571                            terms
572                                .iter()
573                                .map(|term| match term {
574                                    Term::Variable(Variable::Named(name)) => substitution
575                                        .get(name)
576                                        .map_or_else(|| term.clone(), |term| (*term).clone()),
577                                    _ => term.clone(),
578                                })
579                                .collect(),
580                        ),
581                    })),
582                }
583            }
584            _ => unreachable!("a key's body holds only positive plain atoms"),
585        })
586        .collect()
587}

589fn count<'a>(term: &'a Term, occurrences: &mut BTreeMap<&'a VarName, usize>) {
590    for subterm in term.subterms() {
591        if let Term::Variable(Variable::Named(name)) = subterm {
592            *occurrences.entry(name).or_default() += 1;
593        }
594    }
595}

597fn anonymous(term: &Term) -> bool {
598    term.subterms()
599        .any(|subterm| matches!(subterm, Term::Variable(Variable::Anonymous)))
600}

602fn mentions(term: &Term, variable: &VarName) -> bool {
603    term.subterms()
604        .any(|subterm| matches!(subterm, Term::Variable(Variable::Named(name)) if name == variable))
