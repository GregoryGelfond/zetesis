1//! Integer comparison decisions: a comparison literal with an integer
2//! comparison form, compiled once with the prepared program, is decided on a
3//! row with machine integers.
4//!
5//! The join's decided prefix comparisons, its complete-row filters and the
6//! rejected-cursor checks try this decision first, in append and frozen
7//! computations alike. Factored component joins use the same sites and their
8//! copied literals' forms in append computations. Domain narrowing and
9//! totality preparation keep the general evaluator; covered-projection domains
10//! compare stored results without evaluating expressions. None tries a form.
11//!
12//! On a row the decision checks the form's constant,
13//! `nodes + variable steps` of both operands, against the work ceiling,
14//! polling cancellation first, without counting it. It then attempts the
15//! form: it reads each variable its operands name and evaluates both operands
16//! in node order with the checked scalar operations. Afterwards it counts
17//! what the attempt performed, all within what the check admitted: the units
18//! of the steps it reached, the failing one included, one evaluation per
19//! operand it entered and one node per step it reached. When every read gives
20//! a number and every operation succeeds, the comparison's value is the
21//! relation applied to the order of the two integers, which is the ASP order
22//! restricted to numbers: no term is constructed and no projection is read or
23//! written.
24//!
25//! Any other row declines: a slot that is unbound, unavailable or unreadable, a
26//! value that is not a number, or a failing operation. The caller's general
27//! path then decides the row with its own charges, diagnostics, failure
28//! retention and zero-divisor classification. A literal without a form goes
29//! to the general path directly. Whether the decision decides a row depends
30//! only on the literal and the row's values, so every join takes the same
31//! route on the same literal and values, in capture and in a frozen check
32//! alike.
33//!
34//! The decision's own failure is a work or cancellation refusal at its one
35//! check, located at the comparison's site; the count after the attempt
36//! cannot fail. It allocates nothing.
37

46/// Decide `comparison` on `binding` with its integer comparison form: `Some`
47/// with the comparison's value, or `None` when the literal has no form or the
48/// row declines and the general path must decide it.
49///
50/// # Errors
51/// A work or cancellation refusal of the one check, made before evaluating.
52pub(super) fn decide(
53    comparison: &Comparison,
54    binding: &Binding<'_>,
55    context: Context<'_, &Computation<'_, '_>>,
56) -> Result<Option<bool>, FormulaFailure> {
57    let Ok(form) = comparison.form() else {
58        return Ok(None);
59    };
60    let Context {
61        computation,
62        work:
63            GroundingWork {
64                limits,
65                counters,
66                location,
67            },
68    } = context;
69    counters.check_work(u128::from(form.constant()), limits, location)?;
70    let read = computation.read();
71    let attempt = form.attempt(|slot| {
72        let term = binding.read_with(slot, read, location, || Ok(())).ok()?;
73        match term.descriptor() {
74            ValueNodeRef::Number(number) => Some(number),
75            _ => None,
76        }
77    });
78    debug_assert!(
79        attempt.units <= form.constant(),
80        "an attempt performs at most the constant its check admitted"
81    );
82    for _ in 0..attempt.entered {
83        counters.record(Event::ExpressionEvaluation);
84    }
85    for _ in 0..attempt.steps {
86        counters.record(Event::ExpressionNode);
87    }
88    counters.count_work(u64::from(attempt.units));
89    let Some(order) = attempt.order else {
90        counters.record(Event::IntegerComparisonDeclined);
91        return Ok(None);
92    };
93    counters.record(Event::IntegerComparison);
94    Ok(Some(relation_holds(comparison.relation(), order)))
95}
