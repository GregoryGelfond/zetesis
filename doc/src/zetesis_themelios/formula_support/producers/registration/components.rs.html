1//! The component schedule: producers that wait for components they read.
2//!
3//! A rich producer is traversed in full whenever a predicate it reads gains
4//! rows. When every predicate it reads lies in a dependency component before
5//! the components of its heads, those reads stop changing once their
6//! components reach their fixed point, and a single traversal then derives
7//! every head the per-change traversals would. Such a producer is *deferred*:
8//! it waits for that fixed point and is traversed once, in the round in which
9//! the components it reads reach it, over that round's snapshot. Rich
10//! producers that read their own component, or a later one, keep the
11//! per-change traversal.
12//!
13//! Components come from the dependency graph's dependency-before-dependent
14//! order. A component's dependencies, for this schedule, are the components of
15//! every positive input of a certified producer of one of its predicates and of
16//! every predicate a rich producer of one of its predicates reads, of either
17//! sign. A component is *decidable* when each dependency precedes it or is
18//! itself, and every earlier dependency is decidable; a producer reading an
19//! undecidable component is never deferred.
20//!
21//! After a round's other producers have run, a component has reached its fixed
22//! point when it gained no atom this round, every earlier dependency has
23//! reached its fixed point, and every deferred producer of its predicates has
24//! been traversed. Its producers then ran over final inputs and derived nothing
25//! new, so no later round can derive anything for it. The test runs in
26//! component order, so one pass decides every component; deferred producers
27//! whose reads all passed are traversed, and the test repeats until none is
28//! ready. Each deferred producer is traversed exactly once. When a round
29//! derives nothing, every component not waiting on an untraversed deferred
30//! producer passes, and the deferred producer of the earliest head component
31//! among those still waiting reads only passed components, so completion never
32//! ends with a deferred producer untraversed.
33//!
34//! A rich producer that is not deferred reads its own component, a later one
35//! or one that is not decidable, or names a predicate without a component. It
36//! cannot wait for all it reads, but it can wait for part of it. An assignment
37//! aggregate proposes its values from the tuples its elements yield, and a
38//! tuple from an element whose condition holds certain atoms is required only
39//! once the relations of that condition are complete
40//! (`formula_support::certain`). A proposal made before then counts too few
41//! required tuples and so proposes values no later round and no final family
42//! has: `f(1). {p(N)} :- N = #count{V : p(V); V : f(V)}.` would propose 0
43//! before `f(1)` is supported, `p(0)` would add a tuple, and each round would
44//! then propose one value more, without end. Such a producer is *gated*: when
45//! one of its assignment elements has a tuple key and a condition of positive
46//! atoms and join-decided literals whose atoms all lie in decidable components
47//! before its heads, it is not traversed until the components those elements
48//! read reach their fixed point. It is then traversed in full, as a deferred
49//! producer is, and from the next round on whenever a predicate it reads gains
50//! rows, as any other rich producer. Its head components wait for that first
51//! traversal as they wait for a deferred producer's only one, so the argument
52//! above holds with gated producers among the waiting ones: a gate's
53//! components precede the producer's heads.
54//!
55//! A producer cannot read a default-negated atom before that atom's relation
56//! is complete: a row kept because the atom was absent would stay kept after
57//! the atom was derived, and a certified producer never revisits a row. When
58//! one of a producer's top-level negated flat atoms lies in a decidable
59//! component before its heads, the producer is *held back* for those
60//! components: it is not traversed until they reach their fixed point and is
61//! then traversed in full over that round's snapshot. From the next round on
62//! a certified producer takes its delta variants, whose new rows are exactly
63//! those published since that snapshot, and a rich one is traversed whenever
64//! a predicate it reads gains rows, as a gated producer is; a rich producer
65//! may be gated and held back at once. Every traversal of a held-back
66//! producer therefore reads those negated atoms over complete relations,
67//! which is what lets support completion decide them where their predicate
68//! is certain (`formula_support::certain`). Its head components wait for that
69//! first traversal as they do for a gated producer's, and the components it
70//! waits for precede its heads, so the argument above holds with it among the
71//! waiting producers. A deferred producer reads every one of its atoms over
72//! complete relations, of either sign. The occurrences so read are listed as
73//! *awaited*.
74//!
75//! Waiting for a negated atom pays only where the atom is decided. Support
76//! completion reads a negated atom to decide it and for nothing else, so a
77//! producer none of whose awaited atoms has a certain predicate keeps every
78//! row whatever those atoms' support, in whatever round it is traversed.
79//! The analysis of certain predicates runs before the first round and
80//! *releases* each certified producer held back for such atoms alone
81//! ([`Schedule::release_undecided`]): it is visited from the first round as
82//! a producer the schedule never held. A rich producer stays held: its
83//! traversals are in full, and waiting spares it some.
84//!
85//! A component that gained atoms this round can be complete all the same. It
86//! is *settled* when it is decidable, every other dependency has reached its
87//! fixed point, every waiting producer of its predicates has been traversed,
88//! and it either gained no atom this round or is not among its own
89//! dependencies. Its producers then ran over inputs that are complete and in
90//! the snapshot: an ordinary one has joined every row published before this
91//! round, a waiting one was traversed in full over them, and none reads the
92//! component itself, so what it gained this round feeds no producer of its
93//! own and no later round derives anything for it. A settled component's
94//! atoms are not all in the snapshot, so a producer that joins them must
95//! still wait for the fixed point. A certified producer held back for negated
96//! atoms alone does not join them: it reads each over the snapshot and the
97//! round's pending atoms (`Computation::contains_pattern`), which together
98//! are the complete relation of a settled component. Such a producer is
99//! ready as soon as the components it waits for are settled. The rows it
100//! joins positively may still be pending; it meets them in later rounds
101//! through its delta variants, whose negated atoms are complete by then as
102//! well.
103//!
104//! One test settles a whole chain. It visits the components in order and
105//! meets each waiting producer at its first head, after every component the
106//! producer waits for, and it queues the ready ones in that order. A
107//! component whose waiting producers are all traversed or queued, and which
108//! is not among its own dependencies, is settled for the producers queued
109//! after them: those producers are traversed first, and once they are, the
110//! component has gained all it ever will. So a chain of strata, each negating
111//! the one before, is queued by one test and traversed in one round, in
112//! dependency order.
113//!
114//! A test costs one visit per pending atom, a binary search for each run of
115//! atoms of one predicate, and one visit per component, dependency, waiting
116//! producer and waited read. A round runs it once after its other producers
117//! and once more after each batch it queued. It is skipped once every
118//! deferred, gated and held-back producer was traversed.

137pub(super) enum State {
138    Waiting,
139    Ready,
140    Traversed,
141    /// Held back for atoms none of which is decided, and so let go before

147/// Which deferred, gated and held-back producers wait for which components,
148/// and the scratch the per-round test fills.
149pub(super) struct Schedule<'source> {
150    nodes: Vec<Node<'source>>,
151    decidable: Vec<bool>,
152    dependencies: Vec<usize>,
153    dependency_ranges: Vec<Range<usize>>,
154    producers_of: Vec<usize>,
155    producer_ranges: Vec<Range<usize>>,
156    reads: Vec<usize>,
157    /// Per registered producer: the components it waits for, when it is
158    /// deferred, gated or held back.
159    waits: Vec<Option<Range<usize>>>,
160    /// Per registered producer: whether it is gated or held back, and so
161    /// resumes its ordinary visits after the traversal the schedule gives
162    /// it.
163    resumes: Vec<bool>,
164    /// Per registered producer: whether it waits for negated atoms alone,
165    /// which it reads over the snapshot and the round's pending atoms. It is
166    /// ready once the components it waits for are settled; every other
167    /// waiting producer joins what it waits for and needs them published.
168    cascades: Vec<bool>,
169    /// The assignment elements gated producers wait for, as sorted
170    /// `(aggregate, element)` coordinates.
171    elements: Vec<(usize, usize)>,
172    /// The awaited default-negated body atoms, as sorted `(producer,
173    /// occurrence)` coordinates: every traversal of the producer reads the
174    /// atom's relation complete.
175    negations: Vec<(usize, usize)>,
176    state: Vec<Cell<State>>,
177    changed: RefCell<Vec<bool>>,
178    /// Per component: complete, with every atom in the snapshot.
179    reached: RefCell<Vec<bool>>,
180    /// Per component: complete once this round's pending atoms are counted,
181    /// those its queued producers are about to derive among them.
182    settled: RefCell<Vec<bool>>,
183    /// The producers the last test marked ready, in the order it met them:
184    /// by first head component, so each comes after the producers of the
185    /// components it waits for.
186    ready: RefCell<Vec<usize>>,
187    /// How many of them were taken.
188    taken: Cell<usize>,
189}

191/// Scratch for one preparation: (head, input) and (head, producer) pairs, per
192/// producer its first head and whether every predicate it names has a
193/// component, per component whether all of its producers' predicates do, and
194/// one producer's resolved components.
195#[derive(Default)]
196struct Scratch {
197    edges: Vec<(usize, usize)>,
198    owners: Vec<(usize, usize)>,
199    first_heads: Vec<Option<usize>>,
200    known_producers: Vec<bool>,
201    known: Vec<bool>,
202    inputs: Vec<usize>,
203    heads: Vec<usize>,
204}
205
206impl Scratch {
207    fn bytes(&self) -> usize {
208        (self.edges.capacity() + self.owners.capacity()) * size_of::<(usize, usize)>()
209            + self.first_heads.capacity() * size_of::<Option<usize>>()
210            + self.known_producers.capacity()
211            + self.known.capacity()
212            + (self.inputs.capacity() + self.heads.capacity()) * size_of::<usize>()
213    }
214}

238    /// The schedule of `registration`'s producers, or `None` when none can
239    /// be deferred, gated or held back. Retained vectors are admitted through
240    /// `memory`; the scratch is released before returning.
241    pub(super) fn prepare(
242        registration: &Registration<'source>,
243        prepared: &'source Prepared,
244        view: TemplateComponentsRef<'_>,
245        memory: &mut Memory<'_>,
246        work: (&FormulaLimits, &mut Counters, ProgramSite),
247    ) -> Result<Option<Self>, FormulaFailure> {
248        // The test-only reference traverses every rich producer every round.
249        if super::every_round_traversed() {
250            return Ok(None);
251        }
252        let (limits, counters, location) = work;
253        let nodes = super::super::graph_nodes(prepared, memory, limits, counters, location)?;
254        let count = nodes
255            .iter()
256            .filter_map(|node| node.component)
257            .max()
258            .map_or(0, |last| last + 1);
259        let mut scratch = Scratch::default();
260        let inputs = (registration, nodes.as_slice(), view);
261        resolve_all(
262            inputs,
263            count,
264            &mut scratch,
265            memory,
266            (limits, counters, location),
267        )?;
268        let dependencies = dependencies(&mut scratch, count, memory, (limits, counters, location))?;
269        let Waiting {
270            waits,
271            reads,
272            resumes,
273            cascades,
274            elements,
275            negations,
276        } = classify(
277            inputs,
278            &dependencies.decidable,
279            &mut scratch,
280            memory,
281            (limits, counters, location),
282        )?;
283        let (producers_of, producer_ranges) = if waits.iter().any(Option::is_some) {
284            by_component(
285                &mut scratch.owners,
286                count,
287                memory,
288                (limits, counters, location),
289            )?
290        } else {
291            (Vec::new(), Vec::new())
292        };
293        memory.release(scratch.bytes());
294        drop(scratch);
295        if waits.iter().all(Option::is_none) {
296            return Ok(None);
297        }
298        let mut state = Vec::new();
299        memory.reserve(&mut state, waits.len())?;
300        state.extend(waits.iter().map(|_| Cell::new(State::Waiting)));
301        let mut changed = Vec::new();
302        let mut reached = Vec::new();
303        let mut settled = Vec::new();
304        memory.reserve(&mut changed, count)?;
305        memory.reserve(&mut reached, count)?;
306        memory.reserve(&mut settled, count)?;
307        changed.resize(count, false);
308        reached.resize(count, false);
309        settled.resize(count, false);
310        let mut ready = Vec::new();
311        memory.reserve(&mut ready, waits.iter().flatten().count())?;
312        Ok(Some(Self {
313            nodes,
314            decidable: dependencies.decidable,
315            dependencies: dependencies.list,
316            dependency_ranges: dependencies.ranges,
317            producers_of,
318            producer_ranges,
319            reads,
320            waits,
321            resumes,
322            cascades,
323            elements,
324            negations,
325            state,
326            changed: RefCell::new(changed),
327            reached: RefCell::new(reached),
328            settled: RefCell::new(settled),
329            ready: RefCell::new(ready),
330            taken: Cell::new(0),
331        }))
332    }

334    /// The producer's state, when it is deferred, gated or held back and
335    /// was not released.
336    pub(super) fn state(&self, index: usize) -> Option<State> {
337        self.waits
338            .get(index)
339            .and_then(Option::as_ref)
340            .map(|_| self.state[index].get())
341            .filter(|&state| state != State::Released)
342    }

344    /// Release every certified producer held back for negated atoms none of
345    /// which is decided. `decided` lists the decided atoms as sorted
346    /// `(producer, occurrence)` coordinates. Holding such a producer back
347    /// buys nothing: support completion reads a negated atom only to decide
348    /// it, so the producer keeps every row whatever those atoms' support,
349    /// at whatever round it is traversed. Released before the first round,
350    /// it takes its variants as a producer the schedule never held. Its
351    /// atoms stay listed as awaited: the analysis that asks has run, and
352    /// none of them is decided. One unit per registered producer, with a
353    /// binary search of `decided` for each held one.
354    pub(super) fn release_undecided(
355        &self,
356        decided: &[(usize, usize)],
357        limits: &FormulaLimits,
358        counters: &mut Counters,
359        location: ProgramSite,
360    ) -> Result<(), FormulaFailure> {
361        for (producer, wait) in self.waits.iter().enumerate() {
362            counters.work(limits, location)?;
363            if wait.is_none()
364                || !self.cascades[producer]
365                || self.state[producer].get() != State::Waiting
366            {
367                continue;
368            }
369            let first = decided.partition_point(|&(listed, _)| listed < producer);
370            if decided
371                .get(first)
372                .is_none_or(|&(listed, _)| listed != producer)
373            {
374                self.state[producer].set(State::Released);
375            }
376        }
377        Ok(())
378    }

380    /// Whether the producer at `index` is gated or held back: once the
381    /// schedule traversed it, it is visited as any other producer of its
382    /// kind.
383    pub(super) fn resumes(&self, index: usize) -> bool {
384        self.resumes.get(index).copied().unwrap_or(false)
385    }

387    /// Whether the producer at `index`, in `state`, is a gated or held-back
388    /// producer the schedule already traversed: it is visited as any other
389    /// producer of its kind.
390    pub(super) fn resumed(&self, index: usize, state: State) -> bool {
391        state == State::Traversed && self.resumes(index)
392    }

394    /// Whether a gated producer waits for the element at `position` of the
395    /// assignment aggregate `aggregate`: the components its condition reads
396    /// reached their fixed point before any traversal that reads it.
397    pub(super) fn waits_for(&self, aggregate: usize, position: usize) -> bool {
398        self.elements.binary_search(&(aggregate, position)).is_ok()
399    }

401    /// Whether the schedule was prepared so that every traversal of the
402    /// producer at `producer` reads the relation of the default-negated atom
403    /// at body position `occurrence` complete: the atom is awaited. That
404    /// holds of a producer the schedule still holds or has traversed; the
405    /// atoms of one released since stay listed, and none of them is decided.
406    pub(super) fn awaits(&self, producer: usize, occurrence: usize) -> bool {
407        self.negations
408            .binary_search(&(producer, occurrence))
409            .is_ok()
410    }

412    /// The default-negated atoms the schedule was prepared to await, as
413    /// sorted `(producer, occurrence)` coordinates: those of a producer
414    /// released since are among them.
415    pub(super) fn awaited(&self) -> &[(usize, usize)] {
416        &self.negations
417    }

419    /// Whether a deferred, gated or held-back producer has not yet been
420    /// traversed.
421    pub(super) fn pending(&self) -> bool {
422        self.state.iter().zip(&self.waits).any(|(state, wait)| {
423            wait.is_some() && !matches!(state.get(), State::Traversed | State::Released)
424        })
425    }

427    /// Mark ready every waiting producer whose read components are complete,
428    /// given this round's pending atoms in `delta`: published for a producer
429    /// that joins them, settled for one that only negates their atoms. The
430    /// producers are queued in the order [`Self::take_ready`] returns them,
431    /// and the caller traverses every one before it asks again. Returns
432    /// whether any producer became ready.
433    pub(super) fn mark_ready(
434        &self,
435        delta: &SupportAppend<'_>,
436        limits: &FormulaLimits,
437        counters: &mut Counters,
438        location: ProgramSite,
439    ) -> Result<bool, FormulaFailure> {
440        // Only a producer the schedule holds can become ready; every other
441        // producer's cell stays `Waiting` and is never read.
442        if !self
443            .state
444            .iter()
445            .zip(&self.waits)
446            .any(|(state, wait)| wait.is_some() && state.get() == State::Waiting)
447        {
448            return Ok(false);
449        }
450        let mut changed = self.changed.borrow_mut();
451        changed.fill(false);
452        let mut previous: Option<PredicateRef<'_>> = None;
453        for atom in delta.atoms() {
454            counters.work(limits, location)?;
455            let atom_predicate = atom.predicate();
456            if let Some(previous) = previous
457                && previous.equals_ref_with(atom_predicate, || counters.work(limits, location))?
458            {
459                continue;
460            }
461            previous = Some(atom_predicate);
462            let found = lookup(
463                self.nodes.len(),
464                |index| self.nodes[index].signature,
465                atom_predicate,
466                limits,
467                counters,
468                location,
469            )?;
470            if let Some(component) = found.and_then(|index| self.nodes[index].component) {
471                changed[component] = true;
472            }
473        }
474        let mut reached = self.reached.borrow_mut();
475        let mut settled = self.settled.borrow_mut();
476        let mut queue = self.ready.borrow_mut();
477        debug_assert!(queue.is_empty(), "the last batch was traversed");
478        self.taken.set(0);
479        for component in 0..reached.len() {
480            let dependencies = &self.dependencies[self.dependency_ranges[component].clone()];
481            let producers = &self.producers_of[self.producer_ranges[component].clone()];
482            counters.charge_work(
483                1 + dependencies.len() as u128 + producers.len() as u128,
484                limits,
485                location,
486            )?;
487            // A waiting producer is met first at its first head, and every
488            // component it waits for comes before that one.
489            for &producer in producers {
490                if self.state[producer].get() != State::Waiting {
491                    continue;
492                }
493                let reads = self.waits[producer]
494                    .clone()
495                    .expect("a producer listed under its heads waits");
496                counters.charge_work(1 + reads.len() as u128, limits, location)?;
497                let complete = if self.cascades[producer] {
498                    &*settled
499                } else {
500                    &*reached
501                };
502                if self.reads[reads].iter().all(|&read| complete[read]) {
503                    self.state[producer].set(State::Ready);
504                    queue.push(producer);
505                }
506            }
507            // Every other producer of the component has run over inputs that
508            // are complete and in the snapshot.
509            let fed = self.decidable[component]
510                && dependencies
511                    .iter()
512                    .all(|&other| other == component || reached[other]);
513            // A released producer is an ordinary one: the component's
514            // dependencies cover what it joins.
515            let traversed = producers.iter().all(|&producer| {
516                matches!(
517                    self.state[producer].get(),
518                    State::Traversed | State::Released
519                )
520            });
521            let queued = producers
522                .iter()
523                .all(|&producer| self.state[producer].get() != State::Waiting);
524            let recursive = dependencies.contains(&component);
525            reached[component] = fed && traversed && !changed[component];
526            // What the component gains this round feeds none of its own
527            // producers, whether it has gained it or its queued producers
528            // are about to.
529            settled[component] = fed
530                && if traversed {
531                    !changed[component] || !recursive
532                } else {
533                    queued && !recursive
534                };
535        }
536        Ok(!queue.is_empty())
537    }
538
539    /// The next ready producer, in the order [`Self::mark_ready`] queued
540    /// them, which the caller traverses now.
541    pub(super) fn take_ready(&self) -> Option<usize> {
542        let mut ready = self.ready.borrow_mut();
543        let Some(&index) = ready.get(self.taken.get()) else {
544            ready.clear();
545            return None;
546        };
547        self.taken.set(self.taken.get() + 1);
548        self.state[index].set(State::Traversed);
549        Some(index)
550    }
551}

553/// Resolve every producer: its (head, input) edges, its first head, and
554/// whether every predicate it names has a component.
555fn resolve_all(
556    (registration, nodes, view): (&Registration<'_>, &[Node<'_>], TemplateComponentsRef<'_>),
557    count: usize,
558    scratch: &mut Scratch,
559    memory: &mut Memory<'_>,
560    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
561) -> Result<(), FormulaFailure> {
562    let producers = registration.producers.len();
563    memory.reserve(&mut scratch.first_heads, producers)?;
564    memory.reserve(&mut scratch.known_producers, producers)?;
565    memory.reserve(&mut scratch.known, count)?;
566    scratch.known.resize(count, true);
567    for (index, producer) in registration.producers.iter().enumerate() {
568        counters.work(limits, location)?;
569        let rule = &registration.rules[index];
570        scratch.inputs.clear();
571        scratch.heads.clear();
572        let complete = resolve(
573            registration,
574            producer,
575            rule,
576            nodes,
577            view,
578            (&mut scratch.inputs, &mut scratch.heads, memory),
579            (limits, counters, rule.location),
580        )?;
581        memory.reserve(
582            &mut scratch.edges,
583            scratch.heads.len() * scratch.inputs.len(),
584        )?;
585        for &head in &scratch.heads {
586            scratch.known[head] &= complete;
587            scratch
588                .edges
589                .extend(scratch.inputs.iter().map(|&input| (head, input)));
590        }
591        scratch
592            .first_heads
593            .push(scratch.heads.iter().copied().min());
594        scratch.known_producers.push(complete);
595    }
596    Ok(())
597}

599/// Each component's dependencies, and whether its fixed point is decidable:
600/// every dependency precedes it or is itself, and each earlier one is.
601fn dependencies(
602    scratch: &mut Scratch,
603    count: usize,
604    memory: &mut Memory<'_>,
605    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
606) -> Result<Dependencies, FormulaFailure> {
607    counters.charge_work(scratch.edges.len() as u128 + 1, limits, location)?;
608    scratch.edges.sort_unstable();
609    scratch.edges.dedup();
610    let mut list = Vec::new();
611    let mut ranges = Vec::new();
612    let mut decidable = Vec::new();
613    memory.reserve(&mut list, scratch.edges.len())?;
614    memory.reserve(&mut ranges, count)?;
615    memory.reserve(&mut decidable, count)?;
616    let mut edges = scratch.edges.iter().peekable();
617    for (component, &known) in scratch.known.iter().enumerate() {
618        counters.work(limits, location)?;
619        let start = list.len();
620        let mut earlier = true;
621        while let Some(&(_, other)) = edges.next_if(|&&(head, _)| head == component) {
622            earlier &= other == component || (other < component && decidable[other]);
623            list.push(other);
624        }
625        ranges.push(start..list.len());
626        decidable.push(known && earlier);
627    }
628    Ok(Dependencies {
629        list,
630        ranges,
631        decidable,
632    })
633}

635/// The deferred producers: rich, with every read decidable and earlier than
636/// every head. A rich producer that is not deferred is gated when [`gate`]
637/// finds an assignment element it can wait for, and a producer that is not
638/// deferred is held back when [`hold`] finds a negated atom it can wait for.
639/// Returns each such producer's range of waited components and those
640/// components, whether it resumes its ordinary visits, whether it waits for
641/// negated atoms alone, the gates' elements and the awaited negated atoms;
642/// records each producer's (head, producer) pairs in the scratch.
643fn classify(
644    (registration, nodes, view): (&Registration<'_>, &[Node<'_>], TemplateComponentsRef<'_>),
645    decidable: &[bool],
646    scratch: &mut Scratch,
647    memory: &mut Memory<'_>,
648    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
649) -> Result<Waiting, FormulaFailure> {
650    let mut waits = Vec::new();
651    let mut reads = Vec::new();
652    let mut resumes = Vec::new();
653    let mut cascades = Vec::new();
654    let mut elements = Vec::new();
655    let mut negations = Vec::new();
656    memory.reserve(&mut waits, registration.producers.len())?;
657    memory.reserve(&mut resumes, registration.producers.len())?;
658    memory.reserve(&mut cascades, registration.producers.len())?;
659    for (index, producer) in registration.producers.iter().enumerate() {
660        counters.work(limits, location)?;
661        let rule = &registration.rules[index];
662        let rich = match producer {
663            Producer::Rich(_) => true,
664            // A certified producer waits only for an atom it negates.
665            Producer::Certified(_) if negates(rule, limits, counters)? => false,
666            Producer::Certified(_) | Producer::Constraint => {
667                waits.push(None);
668                resumes.push(false);
669                cascades.push(false);
670                continue;
671            }
672        };
673        scratch.inputs.clear();
674        scratch.heads.clear();
675        resolve(
676            registration,
677            producer,
678            rule,
679            nodes,
680            view,
681            (&mut scratch.inputs, &mut scratch.heads, memory),
682            (limits, counters, rule.location),
683        )?;
684        let first = scratch.first_heads[index];
685        let deferred = rich
686            && scratch.known_producers[index]
687            && first.is_some_and(|first| {
688                scratch
689                    .inputs
690                    .iter()
691                    .all(|&read| read < first && decidable[read])
692            });
693        let start = reads.len();
694        if deferred {
695            memory.reserve(&mut reads, scratch.inputs.len())?;
696            reads.extend_from_slice(&scratch.inputs);
697            // Every read is awaited, the negated atoms among them.
698            for (occurrence, literal) in rule.body.iter().enumerate() {
699                counters.work(limits, rule.location)?;
700                if negated(literal).is_some() {
701                    memory.reserve(&mut negations, 1)?;
702                    negations.push((index, occurrence));
703                }
704            }
705        } else if let Some(first) = first {
706            if rich {
707                gate(
708                    rule,
709                    first,
710                    (nodes, view, decidable),
711                    (&mut reads, &mut elements, memory),
712                    (limits, counters, rule.location),
713                )?;
714            }
715            hold(
716                (index, rule),
717                first,
718                (nodes, view, decidable),
719                (&mut reads, &mut negations, memory),
720                (limits, counters, rule.location),
721            )?;
722        }
723        if !deferred && reads.len() == start {
724            waits.push(None);
725            resumes.push(false);
726            cascades.push(false);
727            continue;
728        }
729        waits.push(Some(start..reads.len()));
730        resumes.push(!deferred);
731        // A certified producer waits only for the atoms it negates.
732        cascades.push(!rich);
733        memory.reserve(&mut scratch.owners, scratch.heads.len())?;
734        scratch
735            .owners
736            .extend(scratch.heads.iter().map(|&head| (head, index)));
737    }
738    // Aggregates are numbered in rule order, so this confirms an order the
739    // elements already have; the negated atoms were appended in order.
740    counters.charge_work(1 + elements.len() as u128, limits, location)?;
741    elements.sort_unstable();
742    debug_assert!(negations.is_sorted());
743    Ok(Waiting {
744        waits,
745        reads,
746        resumes,
747        cascades,
748        elements,
749        negations,
750    })
751}

753/// Whether `rule`'s body holds a default-negated flat atom at its top level.
754/// One unit per literal read, up to the first such atom.
755fn negates(
756    rule: &RuleIr,
757    limits: &FormulaLimits,
758    counters: &mut Counters,
759) -> Result<bool, FormulaFailure> {
760    for literal in &rule.body {
761        counters.work(limits, rule.location)?;
762        if negated(literal).is_some() {
763            return Ok(true);
764        }
765    }
766    Ok(false)
767}
768
769/// The pattern of a default-negated flat body atom, under either negation.
770fn negated(literal: &LiteralIr) -> Option<crate::formula_support::components::Pattern> {
771    match literal {
772        LiteralIr::Atom(DefaultNegation::Not | DefaultNegation::NotNot, atom) => Some(*atom),
773        _ => None,
774    }
775}

777/// The default-negated atoms the rule at `index` can wait for, appended to
778/// `negations` as `(index, occurrence)`, with their components, appended to
779/// `reads`: each top-level negated flat atom in a decidable component before
780/// `first`, the producer's first head. A negated atom in the producer's own
781/// component, or in one that is not decidable, is not awaited and keeps its
782/// literal. One unit per body literal, with each negated atom's resolution.
783fn hold(
784    (index, rule): (usize, &RuleIr),
785    first: usize,
786    (nodes, view, decidable): (&[Node<'_>], TemplateComponentsRef<'_>, &[bool]),
787    (reads, negations, memory): (&mut Vec<usize>, &mut Vec<(usize, usize)>, &mut Memory<'_>),
788    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
789) -> Result<(), FormulaFailure> {
790    for (occurrence, literal) in rule.body.iter().enumerate() {
791        counters.work(limits, location)?;
792        let Some(pattern) = negated(literal) else {
793            continue;
794        };
795        let predicate = pattern.get(view, limits, counters, location)?.predicate();
796        let component = lookup(
797            nodes.len(),
798            |index| nodes[index].signature,
799            predicate,
800            limits,
801            counters,
802            location,
803        )?
804        .and_then(|index| nodes[index].component)
805        .filter(|&component| component < first && decidable[component]);
806        if let Some(component) = component {
807            memory.reserve(reads, 1)?;
808            reads.push(component);
809            memory.reserve(negations, 1)?;
810            negations.push((index, occurrence));
811        }
812    }
813    Ok(())
814}

816/// The assignment elements of `rule` a gated producer waits for, appended to
817/// `elements`, with the components their conditions read, appended to
818/// `reads`. Such an element has a tuple key, is not required by its own
819/// condition, and holds positive atoms and join-decided literals only, each
820/// atom in a decidable component before `first`, the producer's first head.
821/// One unit per body literal, element and condition literal, with each
822/// atom's resolution.
823fn gate(
824    rule: &RuleIr,
825    first: usize,
826    (nodes, view, decidable): (&[Node<'_>], TemplateComponentsRef<'_>, &[bool]),
827    (reads, elements, memory): (&mut Vec<usize>, &mut Vec<(usize, usize)>, &mut Memory<'_>),
828    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
829) -> Result<(), FormulaFailure> {
830    for literal in &rule.body {
831        counters.work(limits, location)?;
832        let LiteralIr::Aggregate(aggregate) = literal else {
833            continue;
834        };
835        if aggregate.binding.is_none() {
836            continue;
837        }
838        for (position, element) in aggregate.elements.iter().enumerate() {
839            counters.work(limits, location)?;
840            if element.required || !matches!(element.key, AggregateKey::Tuple(_)) {
841                continue;
842            }
843            let start = reads.len();
844            let mut waits = true;
845            for literal in &element.condition {
846                counters.work(limits, location)?;
847                waits = match positive(literal) {
848                    Some(pattern) => {
849                        let predicate = pattern.get(view, limits, counters, location)?.predicate();
850                        let component = lookup(
851                            nodes.len(),
852                            |index| nodes[index].signature,
853                            predicate,
854                            limits,
855                            counters,
856                            location,
857                        )?
858                        .and_then(|index| nodes[index].component)
859                        .filter(|&component| component < first && decidable[component]);
860                        if let Some(component) = component {
861                            memory.reserve(reads, 1)?;
862                            reads.push(component);
863                        }
864                        component.is_some()
865                    }
866                    None => decided(literal),
867                };
868                if !waits {
869                    break;
870                }
871            }
872            // An element without an atom is required by its own condition.
873            if waits && reads.len() > start {
874                memory.reserve(elements, 1)?;
875                elements.push((aggregate.id, position));
876            } else {
877                reads.truncate(start);
878            }
879        }
880    }
881    Ok(())
882}

884/// The waiting producers of each component (deferred, gated or held back), as
885/// ranges into one list.
886fn by_component(
887    owners: &mut [(usize, usize)],
888    count: usize,
889    memory: &mut Memory<'_>,
890    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
891) -> Result<(Vec<usize>, Vec<Range<usize>>), FormulaFailure> {
892    counters.charge_work(owners.len() as u128 + 1, limits, location)?;
893    owners.sort_unstable();
894    let mut list = Vec::new();
895    let mut ranges = Vec::new();
896    memory.reserve(&mut list, owners.len())?;
897    memory.reserve(&mut ranges, count)?;
898    let mut entries = owners.iter().peekable();
899    for component in 0..count {
900        counters.work(limits, location)?;
901        let start = list.len();
902        while let Some(&(_, producer)) = entries.next_if(|&&(head, _)| head == component) {
903            if list.last() != Some(&producer) || list.len() == start {
904                list.push(producer);
905            }
906        }
907        ranges.push(start..list.len());
908    }
909    Ok((list, ranges))
910}

912/// A producer's head components into `heads` and the components its
913/// derivations read into `inputs`: a certified producer's positive inputs, a
914/// rich producer's reads. Returns whether every predicate it names has a
915/// component.
916fn resolve(
917    registration: &Registration<'_>,
918    producer: &Producer,
919    rule: &RuleIr,
920    nodes: &[Node<'_>],
921    view: TemplateComponentsRef<'_>,
922    (inputs, heads, memory): (&mut Vec<usize>, &mut Vec<usize>, &mut Memory<'_>),
923    (limits, counters, location): (&FormulaLimits, &mut Counters, ProgramSite),
924) -> Result<bool, FormulaFailure> {
925    let component = |predicate: PredicateRef<'_>,
926                     counters: &mut Counters|
927     -> Result<Option<usize>, FormulaFailure> {
928        Ok(lookup(
929            nodes.len(),
930            |index| nodes[index].signature,
931            predicate,
932            limits,
933            counters,
934            location,
935        )?
936        .and_then(|index| nodes[index].component))
937    };
938    let mut complete = true;
939    let mut record = |found: Option<usize>,
940                      into: &mut Vec<usize>,
941                      memory: &mut Memory<'_>|
942     -> Result<(), FormulaFailure> {
943        match found {
944            Some(found) => {
945                memory.reserve(into, 1)?;
946                into.push(found);
947            }
948            None => complete = false,
949        }
950        Ok(())
951    };
952    match producer {
953        Producer::Constraint => return Ok(true),
954        Producer::Certified(occurrences) => {
955            for &occurrence in &registration.inputs[occurrences.clone()] {
956                let atom = match &rule.body[occurrence] {
957                    LiteralIr::Atom(_, atom) => *atom,
958                    LiteralIr::PatternAtom(pattern) => pattern.atom,
959                    _ => unreachable!("a certified input is a positive occurrence"),
960                };
961                let predicate = atom.get(view, limits, counters, location)?.predicate();
962                record(component(predicate, counters)?, inputs, memory)?;
963            }
964        }
965        Producer::Rich(reads) => {
966            for &read in &registration.reads[reads.clone()] {
967                let read = predicate(read, view, limits, counters, location)?;
968                record(component(read, counters)?, inputs, memory)?;
969            }
970        }
971    }
972    for head in rule_heads(rule) {
973        let predicate = head.get(view, limits, counters, location)?.predicate();
974        record(component(predicate, counters)?, heads, memory)?;
975    }
976    Ok(complete)
977}

979/// Every atom a rule's head can derive: the normal head, each disjunct, each
980/// conditional head and each choice element.
981pub(super) fn rule_heads(
982    rule: &RuleIr,
983) -> impl Iterator<Item = crate::formula_support::components::Pattern> + '_ {
984    let normal = match &rule.head {
985        HeadIr::Normal(head) => *head,
986        _ => None,
987    };
988    let elements = match &rule.head {
989        HeadIr::Choice(choice) => choice.elements.as_slice(),
990        _ => &[],
991    };
992    normal
993        .into_iter()
994        .chain(
995            rule.head
996                .disjuncts()
997                .filter_map(|literal| literal.atom().copied()),
998        )
999        .chain(
1000            elements
1001                .iter()
1002                .filter_map(|element| element.head.atom().copied()),
1003        )
1004}
