1//! Admission of source and canonical logical programs through pinned themelios.
2//! [`prepare_program_formula`] retains its original program through an `Arc` and
3//! enters the shared formula compiler without rendering or reparsing.
4//! The formula APIs compute a bounded possible-positive
5//! relation and ground complete joins into normal, conditional-choice, and finite-aggregate Ferraris
6//! formulas. Lifted minimization templates remain separate and score only supplied
7//! verified stable models. No source route invokes a solver or external engine.
8//!
9//! Source admission retains original bytes and parsed origins on success;
10//! bundle failures retain the complete source catalog. Typed formula input keeps
11//! original statement identity and any actual coordinates, without inventing
12//! source bytes. Independent source,
13//! syntax, scalar expansion, finite substitution, and formula storage limits
14//! refuse rather than return recovered or truncated programs. Finite count/sum
15//! assignment cursors may generate values absent from the source while retaining
16//! exact reduct equality formulas. Scalar equality and interval bindings follow
17//! dependency-ordered plans; evaluated normal heads use fresh value slots and
18//! bounded streamed cursors. Pinned upstream analysis reads a separately bounded
19//! pool-free owned projection; its facts are retained without claiming
20//! its narrower safety reading proves the clingo assignment extension.
21//! Syntax walks and
22//! term normalization are iterative. The formula route preserves recursive
23//! eligibility and uses constraints for choice bounds. Completed theories always
24//! include necessary support guards. These semantically redundant guards remain
25//! double-negated so they do not constrain reduct subsets; they are not a
26//! selectable constructor option.
27//! Source acceptance is not a parser-to-Lean or Rust implementation proof.
28#![forbid(unsafe_code)]

167/// Explicit host admission ceilings. Zero means that no resource of that kind
168/// may be consumed; limits never mean unlimited.
169#[derive(Clone, Copy, Debug)]
170pub struct AdmissionOptions {
171    /// Identity attached to every source location.
172    pub source_id: SourceId,
173    /// Maximum UTF-8 bytes accepted before parsing.
174    pub max_source_bytes: usize,
175    /// Maximum syntax nodes visited before raising.
176    pub max_syntax_nodes: usize,
177    /// Maximum syntax-node nesting, including every nested term.
178    pub max_syntax_depth: usize,
179    /// Maximum source body elements per rule, before set deduplication.
180    pub max_body_elements: usize,
181    /// Formula template, variable, predicate-arity and value ceilings.
182    pub core_limits: AdmissionLimits,
183}
184
185impl Default for AdmissionOptions {
186    fn default() -> Self {
187        Self {
188            source_id: SourceId::new(0),
189            max_source_bytes: 1_048_576,
190            max_syntax_nodes: 262_144,
191            max_syntax_depth: 128,
192            max_body_elements: 1_024,
193            core_limits: AdmissionLimits::default(),
194        }
195    }
196}
