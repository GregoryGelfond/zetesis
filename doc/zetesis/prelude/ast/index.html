Module ast 

Expand description

The typed AST (docs/design/syntax.md §8): cheap wrappers over the red cursors, one per node kind, an enum per grammar class, accessors mirroring the productions’ slots in the productions’ order — syntactic accessors, no semantic opinions. Every wrapper is a view: !Send, borrowed from the model, positional in its equality. This file holds the wrapper macros, the enums, the traits, and the roots; nodes the wrappers, tokens the token wrappers and their values.
