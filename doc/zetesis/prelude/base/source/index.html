Module source 

Expand description

The source-text model (docs/design/base.md §3): text with an identity, from anywhere — this crate does no I/O and never sees a path. Admission is the one well-formedness authority for text; everything downstream rides on a Source and inherits its guarantees.

InvalidUtf8
Bytes that are not valid UTF-8; valid_up_to mirrors the standard library’s error detail (base.md §3.2).
NotCharBoundary
The shared boundary condition (base.md §3.2): an offset inside a multi-byte character. Defined once, at the first door where span meets text; the line module’s position queries wrap the same condition.
Source
One owned source text and its identity. UTF-8 by construction (base.md §3.2): arbitrary bytes meet a typed refusal at admission, and everything past the door is valid UTF-8.
SourceId
An opaque identity for one source text. The embedding host mints it, because the host already has it (base.md §3.1).
SourceSet
A Vec-backed catalog that mints ids sequentially — a host you can use, not this crate seizing minting. Satisfies both laws by construction: it admits under the Source doors and builds each LineIndex eagerly at add — an explicit derivation, not lazy state. Deliberately not a virtual file system, and it never grows toward one: no paths, no watching, no loading (base.md §3.4, §11). Each lookup is O(1) — a bounds-checked index into the entry vector (base.md §9).
TooLarge
Text longer than Source::MAX_LEN bytes (base.md §3.2).

The laws, checkable: verifies completeness per id and coherence by re-deriving the index from the resolved text. Deterministic and total — an empty report is the laws holding over those ids; O(total resolved text). Implementors run it in their own tests (base.md §3.4).
