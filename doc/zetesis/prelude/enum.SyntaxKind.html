Expand description

Every token and node kind of the tree. Tokens first, then nodes; within each, the grammar of record’s order (Appendix A of docs/design/syntax.md is the complete roster with the production each kind realizes). ERROR is one kind naming both the lexical error token and the recovery node — the tree says which it is where it stands. Debug and Display are the SCREAMING_SNAKE name, the spelling dumps and goldens use.

impl SyntaxKind

pub const fn is_trivia(self) -> bool

The kinds that are trivia wherever they stand: WHITESPACE, LINE_COMMENT, BLOCK_COMMENT, SHEBANG_COMMENT. DOC_COMMENT is not among them — its status is positional, and role is the predicate that answers it for a token. Total, O(1).

pub const fn is_comment(self) -> bool

The comment forms: LINE_COMMENT, BLOCK_COMMENT, SHEBANG_COMMENT, DOC_COMMENT. Total, O(1).

pub const fn is_keyword(self) -> bool

The keyword tokens: the #-keywords of grammar §4.5, not, and the script terminator #end. Total, O(1).

pub const fn is_token(self) -> bool

A kind a token may carry: everything declared before the first node kind, ERROR and EOF included. Total, O(1).

pub const fn is_node(self) -> bool

A kind a node may carry: PROGRAM and every kind after it, and ERROR. Total, O(1).
