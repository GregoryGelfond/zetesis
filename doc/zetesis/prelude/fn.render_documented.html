Function render_documented 

pub fn render_documented(
    program: &Program,
    dialect: Dialect,
) -> Result<String, Unspellable>
Expand description

Render a program to concrete syntax under a dialect, each statement preceded by its documentation as %! doc-comment lines (grammar §5.11): the doc annotations its provenance carries, emitted verbatim above the statement they document, one line per \n, in Ord order — for a consumer that writes documented source, the documentation riding along the entries it documents. Unlike render, the output is not the canonical form (§10): it carries provenance the canonical form drops, so it is not the version-stable text. It round-trips — the raise reads the %! lines back into each statement’s documentation. Total and iterative in depth (§13). O(output). The one refusal is Unspellable.
