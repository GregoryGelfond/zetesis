Trait FromSymbol 

pub trait FromSymbol: Sized {
    // Required method

Expand description

Extract a Rust value from a ground symbol, refusing with the symbol that did not match — a value, not a rendered string (§3.4, spec §1.5).

Required Methods§

fn from_symbol(symbol: &Symbol) -> Result<Self, FromSymbolError>

Read this value from a ground symbol, or refuse with the offending symbol.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
