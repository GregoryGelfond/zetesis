zetesis_algebra::reduction

Module sets 

Source
Expand description

Occurrence-stream refinements of intersection and union.

A stream denotes the set of its values, independently of order or repeated occurrences. These operations compute that set value without collecting it; the caller retains its existing canonical storage and fallible publication. They are refinements of AxisFolds.inter and AxisFolds.union, not a new set owner or a claim that a fallible materializer implements pure Reduction.

Representation reads must be faithful, finite and free of allocation or control effects. For ordered union, comparison must additionally be a pure total order consistent with value equality. Rust’s Iterator/Ord bounds do not enforce these premises. No result authenticates semantic membership or coverage. An empty stream is not an empty-family verdict, and this interface neither represents the universal intersection identity nor decides a fold.
