pub struct Meter<'a, Q: Quota + ?Sized = LocalQuota> { /* private fields */ }
Expand description

One operation’s performed work and admitted allowance.

Local charges under Cancellation::metered retain the existing 256-step polling cadence. Self::local leaves control to its caller, while Self::reserved consults a borrowed account only when permits run out. The same count and reservation body serve all three arrangements. Unspent permits are admitted - charged, never a second independent account.

The count retains unread padding on both sides: a paired load cannot combine it with another live value, preserving forwarding of its previous store on aarch64. The meter owns no heap storage. A borrowed account adds stack metadata; it does not change the caller’s charged storage or work receipt.

Refund explicitly at the existing completed-attempt boundary. Drop does not refund: a panicking bounded operation has supplied no actual-work receipt, so its grant remains consumed conservatively by the caller’s account.

pub fn charge_receipt( accepted: &mut u64, count: u128, limit: u64, ) -> Result<(), MeterWorkError>

Admit one whole increment into a caller-owned accepted-work receipt.

The receipt remains the sole stored work counter. This operation checks the current inclusive ceiling even when count is zero. A receipt imported under a lower new ceiling is permitted as input and is refused without modification at this charge boundary, not at construction.

No Meter is constructed. There is no polling, allocation, callback, reservation, refund or retained state. The caller owns control polling, source identity and construction of its typed failure.

§Errors

Returns Overflow if the complete demand cannot fit u128; otherwise returns Limit with the exact demand and limit if admission fails. Both failures leave accepted unchanged. Success records the whole demand, which fits u64 because it does not exceed the supplied ceiling.

§Panics

The final conversion asserts the preceding u64-ceiling check. No input can violate that invariant while this check is preserved.

pub fn check_receipt( recorded: u64, count: u128, limit: u64, ) -> Result<u64, MeterWorkError>

Check a whole work request without changing the caller’s receipt.

Success returns the proposed complete receipt, not work already performed or a reservation. The caller retains its sole recorded count and decides when to publish work. A later partial commit is justified only while the relevant recorded prefix and ceiling are unchanged and the actual work does not exceed this checked request.

This pure check has no polling, allocation, callback, refund or retained state. Zero still checks the current ceiling, including when the recorded prefix was imported under a larger earlier ceiling.

§Errors

Returns Overflow if the complete demand cannot fit u128; otherwise returns Limit with the exact demand and ceiling when it does not fit.

§Panics

The final conversion asserts the preceding u64-ceiling check. No input can violate that invariant while this check is preserved.

pub fn check_wide_receipt( recorded: u128, count: u128, limit: u128, ) -> Result<u128, MeterWorkError>

Check a whole request against an existing wide accepted-work receipt.

Like Self::check_receipt, this pure operation returns only a proposed total. It neither changes the caller’s u128 counter nor establishes that work was performed or reserved. Zero checks the supplied ceiling; an imported prefix above a new ceiling is valid input and is refused. There is no polling, allocation, callback, quota, refund or retained state.

§Errors

Returns Overflow if the complete demand does not fit u128, even when the ceiling is u128::MAX. Otherwise an excess returns Limit with the exact demand and ceiling. Neither operation saturates or commits a count.

pub fn check_count( recorded: usize, amount: usize, limit: usize, ) -> Result<usize, MeterCountError>

Check a whole increment of a caller-owned, machine-sized named count.

Returns the proposed complete count without changing any owner or establishing that the requested event occurred. The caller retains the resource name, source attribution and publication/commit boundary. No Meter is constructed. There is no polling, allocation, callback, reservation or refund. A zero increment still checks the current ceiling, including when a prefix was imported under an earlier larger ceiling.

§Errors

Returns MeterCountError::Overflow when the sum does not fit usize, before considering the ceiling. Otherwise an excess returns the exact proposed count and ceiling in MeterCountError::Limit.

pub fn check_wide_count( recorded: u128, amount: u128, limit: u128, ) -> Result<u128, MeterWideCountError>

Check a complete increment of a caller-owned wide named count.

This is the u128 counterpart of Self::check_count. Counts may name objects, occurrences or cumulative byte charges; this does not observe actual storage or a peak. The caller retains those meanings and the original publication point. The result is only a proposed total. No counter is changed, and no event is established as performed. There is no polling, allocation, callback, reservation or refund. Zero still checks the supplied ceiling, including an imported prefix admitted under an earlier larger ceiling.

§Errors

Returns MeterWideCountError::Overflow when the sum does not fit u128, before checking the ceiling. Otherwise an excess returns the exact proposed count and ceiling in MeterWideCountError::Limit. Neither operation wraps, saturates or commits a count.

pub fn under_reservation<R, T, E>( reservation: R, run: impl FnOnce(u64) -> Result<(T, u64), E>, ) -> Result<(T, u64), Failure<E>>
where R: Reservation, E: Refusal,

Execute once under an admitted whole-kernel reservation and commit its valid work receipt. The callback receives the fixed allowance, including zero; the caller retains its admission and polling policy. This operation adds constant work without allocating, polling or creating another meter.

T may carry a native failed attempt with performed work. Such a receipt is committed just like success, before returning the value and used work. An outer Err(E) supplies no receipt. On that error, an invalid receipt, or unwinding, the guard is dropped without commit under its account’s existing abandonment policy.

§Errors

Returns the callback’s original error as Failure::Refused, without observing control again. Returns Stop::InvalidProgram when reported work exceeds the admitted allowance; that receipt is not committed.

pub fn bounded<T>( &mut self, maximum: u64, operation: impl FnOnce() -> (T, u64), ) -> Result<T, Failure<Q::Error>>

Reserve a complete bounded operation before running it, then count only its reported actual work. The returned value can itself contain a typed failure; that does not discard its performed prefix. Control follows the account’s refill policy; explicit per-operation polls remain the caller’s.

§Errors

A refused top-up or unrepresentable count runs no part of operation. Replenishment may already have returned earlier unused grants. A later refund returns only the resulting still-owned unused balance.

§Panics

The caller must report actual <= maximum. Debug builds assert this precondition, as the original private reservation boundary did.

Source

pub fn refund(&mut self)

Return only known unused permits, preserving the performed receipt. Call after normal completion or refusal, not during unwinding when a bounded operation has not reported its actual work. Repeated calls are harmless and retain the account’s existing zero-refund behavior.

pub fn poll(&self) -> Result<(), Stop>

Observe this local meter’s control view, if it has one. A reserved meter’s account owns its control observations; this method does not obtain permits or add an account poll.

§Errors

Returns cancellation first, otherwise an expired deadline.
