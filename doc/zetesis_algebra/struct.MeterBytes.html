pub struct MeterBytes { /* private fields */ }
Expand description

Named simultaneous capacity, with its peak published into the caller’s existing receipt. This dimension owns only the current byte count; it neither duplicates the peak nor owns the caller’s configured ceiling.

Control observations and work charges remain at the caller’s established boundaries. Reservations include actual vector capacity, not allocator metadata or RSS. Headers and overlapping owners must be observed explicitly.

pub fn check(total: u128, limit: u128) -> Result<(), MeterBytesError>

Check a caller-supplied byte requirement against its inclusive ceiling.

This pure check records no current or peak capacity. The caller retains the distinction between a requested envelope and an actual observation, along with its allocation, publication and control boundaries. Zero fits every ceiling. No addition, conversion, polling or allocation occurs.

§Errors

Returns only MeterBytesError::Limit, containing the exact requirement and ceiling, when the requirement exceeds that ceiling.

Source

pub fn observe_peak( total: u128, limit: u128, peak: &mut u128, ) -> Result<(), MeterBytesError>

Record a caller-supplied byte requirement in its existing peak receipt, then check that requirement against the inclusive ceiling.

The caller determines whether total describes a requested envelope or actual capacity. A refused observation remains in the peak. An earlier peak above a newly lowered ceiling does not itself refuse a smaller current requirement. This operation owns no current counter or other state, and performs no allocation, arithmetic addition or control poll.

§Errors

Returns only MeterBytesError::Limit, containing the exact current requirement and ceiling. The peak is updated before returning it.

pub fn observe_peak_usize( total: usize, limit: usize, peak: &mut usize, ) -> Result<(), MeterBytesError>

Observe a machine-sized capacity in its existing machine-sized peak.

This has the same publication-before-refusal contract as Self::observe_peak, without widening or copying the caller’s receipt. Current capacity, allocation and control observations remain caller-owned.

§Errors

Returns only MeterBytesError::Limit, with the exact current requirement and ceiling widened to u128. The peak is updated before returning it.

Source

pub fn observe_peak_u64( total: u64, limit: u64, peak: &mut u64, ) -> Result<(), MeterBytesError>

Observe a u64 byte requirement in the caller’s existing u64 peak.

Like Self::observe_peak, this publishes the maximum before checking the current requirement. It neither widens nor copies the stored peak; only the error’s exact diagnostic values are widened to u128.

§Errors

Returns only MeterBytesError::Limit. A refused observation remains recorded; an older peak above the ceiling does not refuse a fitting total.

pub fn observe( &mut self, total: u128, limit: u128, peak: &mut u128, ) -> Result<(), MeterBytesError>

Record an actual total and its peak before checking the ceiling. A refused observation is retained. A lower total can represent storage already dropped; it never erases an earlier peak.

§Errors

Returns the complete observed capacity when it exceeds limit.

pub fn reserve<T>( &mut self, count: usize, limit: u128, peak: &mut u128, ) -> Result<Vec<T>, MeterBytesError>

Reserve one empty vector after admitting its requested payload. Requested capacity that is refused before allocation changes neither current bytes nor peak. Actual allocator capacity is observed before its ceiling check; on refusal the vector drops but that attempted observation remains recorded. No control poll or work charge is added.

§Errors

Reports unrepresentable addition, requested or observed excess, or a failed allocation. No vector is returned on any refusal.

Source

pub fn release<T>(&mut self, value: Vec<T>) -> Result<(), MeterBytesError>

Drop a vector, then remove its actual payload from current capacity. The vector must belong to this accounted total. No peak, work or control observation is changed, and there is no automatic accounting on drop.

§Errors

Returns an arithmetic refusal after dropping the vector if its payload exceeds the currently accounted capacity; current bytes stay unchanged.
