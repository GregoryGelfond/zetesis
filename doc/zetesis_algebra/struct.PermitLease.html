Struct PermitLease

Expand description

A query-local incremental grant, replenished by its source adapter.

The two Cells are the sole grant owner; this type is deliberately not Sync. It owns no source reference, poll, lock or allocation. The source wrapper decides when to settle and whether its Drop settles. This owner itself has no automatic Drop settlement: unwinding does not invent a work receipt.

pub fn renew<E>( &self, next: impl FnOnce(PermitSettlement) -> Result<Option<u64>, E>, ) -> Result<bool, E>

Renew an exhausted lease at its source’s existing admission boundary.

Detach the old grant before calling next, supplying a zero receipt when none exists. The source publishes that receipt before attempting a new grant. Some(n) installs both Cells before return; None leaves the lease empty and reports pending. No polling, locking or waiting is added. During next, the callback must not invoke any operation on this same lease, directly or indirectly; it operates only on the source ledger.

§Errors

Returns the source’s exact error with the old grant detached and no replacement installed. No rollback or additional observation occurs.

§Panics

The current grant must be exhausted, and a successful replacement must be positive. Debug builds assert these source-adapter preconditions. An unwinding next leaves the old grant detached, without restoration.
