Expand description

A caller-owned account granting permits to one metered operation. A reserve refusal grants nothing. A successful reserve grants 1..=wanted; zero is treated as a local work refusal. The cumulative grant retained by one meter must fit u64, including already performed work. The account retains its own typed errors.

Provided Methods§

fn replenish( &mut self, unused: &mut u64, minimum: u64, capacity: u64, ) -> Result<(), Failure<Self::Error>>

Supply a complete atomic minimum while retaining exact ownership of unused permits. unused initially names this meter’s outstanding borrow; on every normal return it names exactly the borrow still held, including on refusal. An account may return that borrow before replacing its grant. The caller supplies unused <= capacity and minimum <= capacity. A successful return establishes minimum <= unused <= capacity.

The default retains the incremental reserve/refund sequence. An account with grant-local refunds can override this operation to release unused permits before settling a grant or waiting for its replacement. The operation performs no metered work and creates no second work counter.

§Errors

Returns the exact account refusal or the existing local work/invariant refusal. Earlier partial grants remain represented in unused unless explicitly returned to their owner. An unwinding call supplies no receipt; the meter cannot be reused or refunded after catching such an unwind.
