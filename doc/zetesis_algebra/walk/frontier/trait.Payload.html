Expand description

Allocation metadata of one frontier entry, beyond its inline representation.

The frontier accounts for size_of::<Self>() through deque capacity. Return only allocations owned by this entry, including unused capacity and excluding shared owners, the inline entry/header bytes, temporary storage and allocator metadata. The value must remain stable while the entry is queued. Actual owned allocations fit the host address range; a larger reported value is clamped to usize::MAX, preserving the frontier’s host-counter conversion. This capability supplies no narrowing or membership decision.
