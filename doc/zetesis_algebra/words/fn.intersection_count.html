Expand description

Count the positions present in both word-aligned sets.

Every stored bit participates, so callers must clear any padding outside their logical universe. Words are visited in ascending order. For each word, before runs once immediately before the AND and again immediately before the popcount: exactly two primitive-operation charges per word on success. Each primitive includes its operand loads and result store. Initializing and adding to the accumulator belong to the caller’s ledger; loop control is not charged.

No allocation or retained state occurs. Work is linear in the slice length and auxiliary space is constant. The accumulator counts the intersection of the completed prefix; the length bound ensures that every sum fits.

§Errors

Returns the callback’s first refusal before that primitive operation, with no later operations or callbacks. No partial count is returned. Both input slices remain unchanged, including when popcount is refused after an AND.

§Panics

Panics before any callback if the slice lengths differ or their full bit width exceeds usize::MAX.
