pub fn union_shifted<E>(
    words: &mut [u64],
    source_words: usize,
    shift: usize,
    before: &mut impl FnMut() -> Result<(), E>,
) -> Result<(), E>
Expand description

Add a translated copy of the initialized source prefix to words.

A bit at s adds a bit at s + shift, when that position fits the output slice. Existing output bits remain set. Descending source visits ensure that this operation uses each original bit once, including an in-place carry within one word; bits produced by this call are not shifted again.

before runs immediately before each source-word read. A refusal leaves a partial union, which the caller must discard or otherwise treat as incomplete. No allocation, callback-independent input traversal or retained state occurs. Words whose entire shifted output is outside the slice are not read.

§Errors

Returns the callback’s first refusal, before the refused source read.

§Panics

Panics if source_words exceeds the initialized slice length.
