Expand description

Add translated source bits until one meets the inclusive interval.

This queries only the translated copy of the initialized source prefix, not bits already present in the output. Ok(true) means such a translated bit lies in the interval and output slice. The union may then be partial; the caller must discard it or otherwise treat it as incomplete. Ok(false) means no translated bit meets the interval and the full union is complete, exactly as with union_shifted. An empty interval therefore still performs the full union.

Each admitted source word contributes both of its destination fragments before a hit is returned. No lower source word is read after a hit. The descending source order, single-use bits, lack of allocation and metered source reads have the same contract as union_shifted.

§Errors

Returns the callback’s first refusal before the refused source read. A refusal is not a hit or a completed union; partial output is incomplete.

§Panics

Panics if source_words exceeds the initialized slice length.
