Expand description

Accumulated compute-pass times of completed device batches.

These durations exclude host preparation, submission, command-buffer copies and waiting. Memory access performed inside the compute pass remains included. They are not the duration of the host oracle or of the complete solve. Each completed batch is counted once: measured, unavailable, or unresolved when its interval had not been read when the record was taken. Unavailable measurements remain separate from measured zero-duration passes.

§status: ComputeTimingStatus

Device feature availability, established when its context was created.

§measured_batches: u64

Completed batches with a valid device duration.

§unavailable_batches: u64

Completed batches whose requested device duration was unavailable.

§unresolved_batches: u64

Completed batches whose interval had not been read when this record was taken: at most one per device oracle, the batch an unfinished execution completed last, or a settled one could not read because it stopped or met a busy or unhealthy context. Zero after a settlement that read it.

§flush_submissions: u64

Resolve-only submissions that read a final batch’s interval when its execution settled. Each downloads 16 bytes; no candidate batch is counted.

§elapsed: Option<Duration>

Sum of valid durations; absent until the first valid measurement.

§overflowed: bool

A cumulative count or duration could not be represented. Retained values remain partial evidence; this does not change the solve’s outcome.
