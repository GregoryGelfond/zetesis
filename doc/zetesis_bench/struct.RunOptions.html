Expand description

One benchmark campaign; statistics are always part of its protocol.

Fields§

§root: PathBuf

Existing clean corpus directory from the repository; never downloaded.

§suite: Suite

Maintained workload selection.

§cases: Vec<String>

A case of the suite to measure; repeat for several, in order. Series paths name workload entries, including generated paths, and select every amended cell of that entry. Corpus case paths are corpus-relative. Omitted, the whole suite is measured.

§examples: Option<PathBuf>

Authored examples root for –suite scalability; defaults to examples.

§include_einstein: bool

Include the unchanged Einstein riddle in –suite scalability.

§zetesis: Option<PathBuf>

Native executable; omitted uses the installed zetesis (the one beside this tool, else the first on PATH).

§native_interface: Option<NativeInterface>

Native command interface: solve, the default, or legacy for an older binary’s flat arguments.

§clingo: Option<PathBuf>

The clingo to compare with, which must run. Omitted, the first clingo on PATH is used, and without one the run measures zetesis alone.

§without_clingo: bool

Measure zetesis alone: qualify each workload against its recorded contract and launch no clingo.

§report: Option<PathBuf>

New complete JSON evidence file, including failures and unlaunched positions; omitted, zetesis-bench-<suite>-<UTC time>.json in the current directory. An existing file is never replaced.

§backend: Backend

Execution backend: cpu (the default), gpu, metal or vulkan. A GPU backend is required: its absence is retained as a non-pass.

§grounder: Grounder

Requested materialization policy.

§threads: NonZeroUsize

Native candidate/closure workers; auto uses the host’s available parallelism.

§compare_threads: Vec<NonZeroUsize>

Compare native thread counts, for example 1,2,4; clingo only qualifies.

§compare_grounders: bool

Compare eager and lazy native grounding; clingo only qualifies.

§compare_backends: Vec<Backend>

Compare native backends, for example cpu,gpu; clingo only qualifies.

§oracle: Oracle

Requested reduct procedure for every profile.

§search: Option<Search>

Formula search method for every profile; omitted, the suite’s default.

§formula_joins: Option<FormulaJoins>

Eager-formula join strategy for every profile; omitted, the suite’s default.

§memory: Option<u64>

Native memory allowance in bytes or binary units; omitted, the solver’s default.

§time_limit: Option<NonZeroU64>

Cooperative native deadline in whole seconds for every profile; omitted, none.

§clingo_threads: NonZeroUsize

Unmodified clingo worker setting; no search-heuristic tuning.

§warmups: usize

Untimed warmup rounds, separate from the mandatory qualification.

§repetitions: usize

Timed rounds per solver/case, one through 41.

§memory_runs: usize

Separate fresh-child RSS rounds, zero through 41.

§timeout_seconds: u64

Timeout for each solver child, in seconds.

§campaign_seconds: u64

Total campaign scheduling deadline, in seconds; no replacement launches.

§sample_bytes: usize

Combined stdout/stderr ceiling per invocation.

§native_report_bytes: usize

Native JSON decoder source-byte ceiling, separate from capture.

§capture_bytes: usize

Combined retained captures across the entire campaign.

§report_bytes: usize

Serialized complete evidence ceiling.

§view: ViewOptions

Human or structured presentation.

pub fn plan(&self) -> Result<Plan, Error>

Map command arguments to the reusable bounded plan; no I/O is performed.

The profiles are the product of the compared backends, grounders and thread counts, backends outermost; each axis not compared contributes its single requested value.

§Errors

Refuses options of another suite, case selections, worker counts, profile counts, dimensions or schedules outside maintained bounds.

Source

pub fn reference_policy(plan: &Plan) -> ReferencePolicy

clingo is timed beside one profile, and only qualifies when profiles are compared.

pub fn invocation(&self) -> NativeInvocation

Actual interface selection: the explicit solve command of whichever executable is measured, unless --native-interface legacy requests an older binary’s flat arguments.
