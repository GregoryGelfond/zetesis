Struct JsonRenderer 

Source 
pub struct JsonRenderer<W> { /* private fields */ }
Expand description

Streaming JSON renderer over the same typed views as the human renderer. Retains one encoded record and a bounded table of previously spelled atoms, not a complete WorldView. It does not poll control while emitting the final failure/stop receipt, so cancellation cannot suppress that retained evidence.
