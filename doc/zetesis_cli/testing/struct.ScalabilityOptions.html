Expand description

Complete-family checks of the maintained scalability workloads. A new –report path is required for the complete sealed evidence.

Fields§

§root: PathBuf

Verified correctness catalog used by the three unchanged corpus cases.

§examples: PathBuf

Authored examples root; metadata and source digests are checked.

§include_einstein: bool

Include the unchanged Einstein riddle in the workload selection.

§zetesis: Option<PathBuf>

Modern zetesis executable; omitted uses this installed executable’s solve.

§clingo: PathBuf

External clingo used for one complete qualification per workload.

§threads: Vec<NonZeroUsize>

CPU region thread counts, one through eight profiles, each at most 256.

§memory: Option<u64>

Native memory allowance in bytes or binary units; omitted, the solver’s default.

§time_limit: Option<NonZeroU64>

Cooperative native deadline in whole seconds, separate from the child timeout.

§campaign_seconds: u64

Total campaign scheduling deadline, including all qualification children.

§total_capture_bytes: usize

Combined retained captures across the complete campaign.

§report_bytes: usize

Serialized complete evidence ceiling.

§process: ProcessOptions

Bounded per-child execution.

§view: ViewOptions

Presentation and required complete evidence destination.
