Module interner 

Source
Expand description

One appendable typed atom owner with stable, owner-local dense positions.

A committed prefix may be borrowed during a synchronous source scan while a disjoint appender interns newly encountered identities. New discoveries do not enter that prefix until commit. Neither identity nor commitment asserts truth. Canonical payload occurs once; ordered views and discovery maps hold only IDs. crate::AtomCatalog::new separately preserves arbitrary occurrence order and duplicate positions, without retaining the supplied description addresses.
