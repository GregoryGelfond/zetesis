Struct AtomEntry

pub struct AtomEntry<'owner, 'key> { /* private fields */ }
Expand description

One checked lookup, holding the exclusive append path until insertion/drop. The key is borrowed. Occupied lookup never copies payload or mutation scratch. Its owned prepared-result slot counts in named storage even when occupied; borrowed caller frames remain excluded. The result cannot escape this exclusive append capability or be reused after insertion/refusal.

pub fn insert_with<E>( self, limits: Limits, before: impl FnMut() -> Result<(), E>, ) -> Result<usize, Failure<E>>

Return an existing discovery position or publish a new one.

Import canonical identity before publishing discovery or AVL links. Same-authority terms reuse their IDs; ingress or foreign terms use the checked typed importer. Each visited descriptor, text byte, comparison, reservation and publication operation is admitted before its work. Named canonical payload is part of max_bytes; caller-owned ingress descriptions remain outside this owner. Arc envelope allocation is infallible on stable Rust. Planned metadata writes publish as one indivisible update.

§Errors

Refusal publishes no discovery position or partial AVL links. Complete canonical components and reserved capacity may remain after a later refusal; they assert neither discovery nor truth and count toward storage.

pub fn insert_ref_with<E>( self, limits: Limits, before: impl FnMut() -> Result<(), E>, ) -> Result<AtomRef<'owner>, Failure<E>>

Publish discovery and borrow its canonical atom without exporting it. The returned read excludes further append until it is released. This is the same insertion as Self::insert_with, followed by one pre-admitted discovery-map read.

§Errors

Returns the insertion refusal or the initial read-admission refusal. An internal missing published identity is a typed shape error.
