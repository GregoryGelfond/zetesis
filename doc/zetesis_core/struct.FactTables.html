Struct FactTables 

Source 
pub struct FactTables { /* private fields */ }
Expand description

Source-ordered fact construction descriptions, separate from rule templates. Each block is anchored immediately before a template position. Products keep compact intervals; adjacent rows of one predicate and anchor share column vectors. The program consumes these descriptions and retains one canonical atom store plus occurrence positions, not these owned values.

Caller input is outside AdmissionLimits::max_bytes, as with Template. Builder vector reservations are fallible. A failed push poisons this value; admission then refuses it rather than publishing an accepted prefix.

pub fn push_row( &mut self, before: usize, predicate: Predicate, values: Vec<Value>, ) -> Result<usize, Error>

Append one closed row at before, the count of preceding templates. Returns its original fact-occurrence position. Equal atoms remain distinct occurrences; compatible adjacent rows share one column-major input run. Moves O(arity) owned value handles; growing columns can move their prior handles. Amortized work is O(arity) per row, excluding predicate comparison and allocator behavior. Values are neither canonicalized nor expanded here.

§Errors

Refuses an arity mismatch, decreasing anchor, index overflow, allocation, or an earlier failed push. A refusal poisons this construction owner.

Source

pub fn push_product( &mut self, before: usize, predicate: Predicate, columns: Vec<Vec<FactSegment>>, ) -> Result<Range<usize>, Error>

Append a Cartesian product in last-argument-fastest order. Columns contain their alternatives in source order; one empty column makes an empty product, while a zero-arity product contains the one nullary fact. Returns the original occurrence range for parallel source evidence. Checks O(segments + arity) metadata and retains the supplied columns; interval width and Cartesian products are checked without enumerating scalar values or rows. Program::new performs that admitted enumeration.

§Errors

Same structural and allocation refusals as Self::push_row, plus an overflowing alternative or product count. A refusal poisons this owner.
