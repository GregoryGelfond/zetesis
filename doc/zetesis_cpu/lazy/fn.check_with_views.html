Expand description

Check borrowed candidate views with the same immutable-round protocol as check_with. Cloning the iterator must preserve its length, order and candidate identities. The views borrow their true atoms; this boundary creates no owned seed or temporary view vector. Demanded atom rows use the Program’s canonical vocabulary; round selections own only IDs. The final catalog transfers to shared result models without copying atom payloads.

§Errors

Returns the same failures and retained progress as check_with. Actual occurrence counts inconsistent with the claimed size refuse as Stop::InvalidProgram before an out-of-range world write or publication.
