Source
Expand description

Shared source traversal with independent, ordered CPU world evaluation.

This is the concrete CPU implementation of the immutable-round protocol. Source work is shared; each world has its own evaluation ceiling. A stopped world invalidates the entire batch, including other worlds that completed a chunk. There is no retry, fallback, or partial closure publication.
