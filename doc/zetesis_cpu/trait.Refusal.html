Expand description

An error a metered operation reports, classified so that a requested stop takes precedence over every resource refusal at the operation’s exit (Cancellation::metered).

Required Methods§

Source

fn is_resource_refusal(&self) -> bool

Whether this error refuses a resource: work, storage, a named ceiling, a size the host cannot represent, or an allocation. Errors about the program’s shape, identity or invariants are not resource refusals.
