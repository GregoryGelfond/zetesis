Expand description

Append typed min/max guards over one shared, guard-independent ordinal row.

The complete value dictionary includes #inf and #sup and is sorted using charged ASP term comparisons. Equal dictionary values share a rank; every complete tuple occurrence retains its condition and rank, including repeated condition IDs. Two native inclusive/strict cuts are published per guard. Not-equal remains the inclusive-to-strict implication, and each cut and wrapper retains its own frozen truth gate for arbitrary inner worlds.

The caller coalesces equal complete tuples and establishes row independence from the changing guard. Borrowed term authorities stay unchanged. Preparation checks and reuses nondecreasing input order in O(E + G log E) comparisons; otherwise its existing in-place sort uses O(E log E + G log E). Both use O(E + G) auxiliary cells. Guard cut pairs share one dictionary search. All conditions are validated even with no guards. Work, state, guard and graph ceilings apply to the whole family; refusal rolls back the entire suffix. Scalar extrema retain their separate zero-state compilation contract.

Returns typed input, guard, state, allocation, work, node, operand, arithmetic or control failures, with actual auxiliary capacity on every outcome.
