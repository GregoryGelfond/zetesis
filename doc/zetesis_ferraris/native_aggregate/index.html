Module native_aggregate 

Source
Expand description

Retained finite aggregate operations over already-coalesced whole tuples.

A group retains canonical keys, eligibility node indices and immutable theory identity. Group owns its vocabulary; GroupData retains only metadata and binds to a caller-owned canonical prefix through GroupRef. Admission checks shape and uniqueness; it does not assert that a source program or theory contains this aggregate. Mask reduction is separate from acquisition of actual original/frozen formula truth. Neither operation decides stable-model membership or changes the original theory.
