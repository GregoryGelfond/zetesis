pub struct FormulaParts { /* private fields */ }
Expand description

Raw formula buffers that always travel together.

The cached occurrence total counts every implication/pair edge and every wide-span and threshold-row occurrence, including overlapping/shared ranges. A shared row contributes its width once per threshold reference. It is an arithmetic quantity, not evidence of valid spans, topology or atom IDs. Read-only access cannot invalidate it. Raw constructors transfer their complete buffers without copying; owned mutation is available only through a scoped append transaction. The private cache supports bounded construction; theory admission independently recounts the actual nodes and establishes its own occurrence bound.

pub fn try_clone(&self) -> Result<Self, AdmissionError>

Copy all seven arenas fallibly, preserving sharing and absolute child IDs. The copy is raw storage and carries no admission or original owner identity. Work and temporary payload are linear in all stored cells, including unused cells. Self::copy_work reports the complete logical copy/recount charge. Actual destination capacities may differ from the source capacities.

§Errors

Source

pub fn copy_work(&self) -> u128

Complete logical work for Self::try_clone: one visit per copied cell in all seven arenas, then one visit per node to recount child occurrences. Shared numeric entries are copied once, irrespective of how many nodes reference their row. Unreferenced arena cells still contribute.

This allocation-free measurement is a full-attempt precharge; an early refusal may perform less work. It excludes fixed reservation bookkeeping, allocator work, hardware instructions and topology/numeric admission. It neither checks dimensions nor measures bytes or retained capacity.

pub fn pending_numeric_validation_work(&self) -> u128

Work required to validate an unchecked numeric prefix before its next numeric append: all nodes, contribution rows and entries, and descriptors. Checked immutable prefixes return zero. This only reports pending work; it neither validates storage nor changes its cache. Callers charge it before either numeric family append or a numeric FormulaTransaction::append, whose successful validation caches it.

pub fn from_raw( nodes: Vec<Node>, operands: Vec<usize>, conditions: Vec<usize>, weights: Vec<u64>, rows: Vec<ContributionRow>, thresholds: Vec<ThresholdDescriptor>, ) -> Result<Self, AdmissionError>

Transfer legacy weighted raw storage, converting only its row descriptors.

The supplied contribution spans become weight-domain numeric rows. All other vectors transfer unchanged. Conversion fallibly reserves one row vector in O(rows) work; the supplied spans are released before return. No admission occurs. Use Self::from_numeric_raw for complete storage transfer without conversion or additional allocation.

§Errors

Transfer all seven raw arenas unchanged, without copying or admission.

Declared referenced widths are counted in O(nodes). Missing descriptors or rows contribute zero here and are rejected at admission. All unused cells and descriptors remain owned, validated and dimension bounded.
