Struct FormulaTransaction 

Source 
pub struct FormulaTransaction<'a> { /* private fields */ }
Expand description

An append-only borrow with a private checkpoint for every arena.

Callers can append logical nodes and read the graph, but cannot replace the owner, edit its prefix or inject cross-owner arena spans. Every appended row owns fresh cells; numeric nodes within one family may share that new row. Dropping without commit restores every original arena length, occurrence total and validation cache; reserved capacities survive. Validation discovered inside a rolled-back append is discarded because an unchecked raw prefix can refer to newly appended arena cells. Private offsets cannot be supplied from another owner, from a future length, or reused after completion.

This controls storage, not work/cancellation: enclosing algorithms must charge all visited nodes/operands and any detachment copy before these operations. No failed allocation or limit check publishes a partial node or operand row.

pub fn append( &mut self, source: FormulaView<'_>, max_nodes: usize, max_operands: usize, ) -> Result<Range<usize>, AdmissionError>

Append complete raw storage, preserving shared rows and absolute child IDs.

Internal Boolean-span, numeric-row and numeric-descriptor offsets are relocated into this owner. Each child must precede its destination node; source node positions need not equal those absolute IDs. Atom admission stays with Theory. All seven source arenas, including unused cells, are copied once. Validate and reserve every destination before publishing any cell. On error lengths/frontier are unchanged, but successfully reserved capacity remains. Work covers source nodes, logical edges, numeric rows and their entries, descriptors and copied cells; retained payload is all source cells. This operation does not allocate a second complete source copy or root vector. Numeric growth also validates an unchecked destination numeric prefix once, scanning its nodes, rows and entries, and descriptors before appending. Committed immutable prefixes reuse this cache; rollback restores it.

§Errors

Refuses invalid source storage or destination topology, numeric shape or total overflow, inclusive dimensions or failed reservations.

pub fn push_threshold_family( &mut self, conditions: &[usize], weights: &[u64], bounds: &[i128], max_nodes: usize, max_operands: usize, ) -> Result<Vec<usize>, AdmissionError>

Atomically append one family of bounds sharing one fresh contribution row.

Validates every condition and weight once, before interpreting constant bounds or an empty bound list. No tuple deduplication occurs. Sharing stays inside this call, so nested detach owns all its rows and preserves child IDs. Work and additional payload are O(conditions + bounds); the occurrence counter remains conditions * bounds, covering consumers that scan each node. An unchecked raw numeric prefix first incurs one additional scan of its N nodes, contribution rows and declared entries, and descriptors. This proves suffix growth cannot repair an unresolved prefix reference and invalidate occurrence accounting. The cache is retained on commit and restored on rollback; freshly built prefixes require no repeated scan. Each column and logical occurrences obey max_operands independently; rows, descriptors and nodes each obey max_nodes. Reserved capacity may grow on a failed allocation, but no length or topology frontier changes on refusal. Successful prefix shape validation may remain until transaction rollback.

§Errors

Refuses unequal columns, invalid children, arithmetic overflow, inclusive dimension limits or failed reservations. Empty bounds still validate input.

pub fn push_extremum_cut_family_range( &mut self, row: ExtremumRow<'_>, cuts: &[ExtremumCutRule], max_nodes: usize, max_operands: usize, ) -> Result<Range<usize>, AdmissionError>

Append ordinal cuts sharing one fresh, guard-independent ranked row.

The carrier includes rank zero as the least endpoint and rank_count - 1 as the greatest. Empty minimum and maximum use those greatest and least ranks respectively. Every supplied rank and preceding child is checked, including for constant cuts or an empty cut list. Every requested cut gets one node; neither conditions nor rules are coalesced. The returned range is contiguous. No descriptor references a row in an earlier transaction.

Work and new payload are O(conditions + cuts), plus the one-time pending raw-prefix validation reported by FormulaParts::pending_numeric_validation_work. Logical occurrences are conditions * cuts. Columns and occurrences each obey max_operands; nodes, rows and each descriptor arena obey max_nodes. All reservations precede publication. On refusal lengths and the topology frontier are unchanged; reserved capacities and successful prefix shape validation may remain until this transaction’s rollback.

§Errors

Refuses inconsistent columns, invalid ranks/carrier/cuts/children, checked count overflow, inclusive dimension limits or failed reservations.

pub fn push( &mut self, node: NodeView<'_>, max_nodes: usize, max_operands: usize, ) -> Result<usize, AdmissionError>

Append one logical node, normalizing empty and singleton groups.

A singleton returns its checked child. Empty OR appends falsum; empty AND appends falsum and its self-implication. A pair is inline and a wider group copies its ordered row once to fresh arena cells. Repetition is preserved. All supplied child IDs must precede this call; atom-universe admission is left to Theory::new. If the entire existing prefix has completed topology validation, successful appends extend that frontier: this call checks every child and constructs canonical storage. An unchecked prefix remains unchecked. No structural interning is performed here.

Costs O(1 + arity) work and at most one node plus arity arena cells, except the two-node empty conjunction. Bounds cover total nodes and both total logical occurrences and raw arena length, not just this append’s delta. Numeric nodes retain their full row and bound or cut, including constants. They delegate to their shared-family operation and inherit its one-time unchecked numeric-prefix validation cost. The borrowed input row is additional storage.

§Errors

Refuses an invalid child, exhausted inclusive dimension, checked overflow or failed reservation. Prior transaction appends remain unchanged on this call’s refusal; dropping the transaction rolls those back as well.

pub fn detach(self) -> Result<FormulaSuffix, AdmissionError>

Detach this transaction’s complete appended suffix and restore its prefix.

Takes O(new nodes + new arena cells) work and temporary storage, without scanning or copying the retained prefix. All seven destination reservations precede mutation. The old capacities remain retained after detachment, so enclosing peak accounting must include those plus the returned capacities. Child IDs remain absolute; only Boolean-span, numeric-row and numeric descriptor offsets are rebased to the detached arenas.

§Errors

Refuses failed reservation or an inconsistent internal span. On refusal this consumed transaction rolls back every arena without publishing a suffix. The rollback retains actual capacity growth, as usual.
