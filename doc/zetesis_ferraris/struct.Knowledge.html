Expand description

What a narrowing knows about a region, carried from a region to its children: the knowledge of a region holds in every region inside it (FormulaBounds.known_mono), so a child’s narrowing starts from its parent’s knowledge and learns only what the split decided. A fresh value knows nothing and is seeded in full on first use.

A value is linear in the theory: a bit pair over the nodes and one over the atoms, a counter and witness bit per chain, a count per atom and processed state per shared threshold row; the worklists of a narrowing belong to the walker’s NarrowingScratch. Its counters have one width, chosen when the root value is made. A split that offers one child to another worker clones it, so the clone is the split’s cost. A knowledge belongs to the narrower that made it and to the region it was closed for: narrowing a region with a knowledge from another narrower, theory, producer set or frozen mask, or from a region not enclosing it, is unsound, and nothing checks it. The proposers keep the invariant by carrying each region’s knowledge from its parent and by narrowing with the narrower that made it. A completed possible-foundedness pass is inherited with the knowledge; any newly false projected producer-body node invalidates it. An atom with no positive occurrence in that projection can only remove itself from the upper closure. An absent or foreign projection invalidates on every false atom or node. Unchanged relaxation inputs need no repeat pass; worker scratch can identify an irrelevant node but never establish completion itself.

Support rechecks inherit two monotone producer-row positions per atom, allocated only after a head with more than two producers is reached. Their compact width is bounded by the complete producer count. Failed prefixes stay unavailable in descendants, while surviving endpoints are revalidated; this never replaces complete coverage for zero or sole support. Initial allocation is fallible and charged by the narrowing; cloning includes its owned capacity under the existing infallible clone boundary.

Cloning owns an independent copy. Clone::clone_from overwrites every field, reusing equal-length storage at the same counter width. The six masks occupy disjoint slices of one owned block; copying also replaces its node/atom boundaries, even when the total block length is unchanged. The destination’s previous knowledge contributes no authority; the source’s narrowing preconditions still apply. Changed lengths or widths use fresh storage, with the same infallible allocation boundary as Clone::clone.

pub fn preferred_atom_with_secondary_reserved<Q: Quota + ?Sized>( &self, region: &Region, choices: &ChoiceHeads, secondary: &Self, cancellation: &Cancellation, work: &mut Meter<'_, Q>, ) -> PreferenceAttempt<Failure<Q::Error>>

Select by original choice marks, this subject’s unknown-parent count, then secondary’s count; remaining ties select the lowest atom. Both knowledge values must use the region’s atom identities and be closed for it. This only orders an exhaustive split and changes neither value.

The scan takes O(A / 64 + E) time for A atoms and E eligible atoms, with constant additional space. Eligible atoms are the open choice heads when any remain, otherwise all open atoms. Each primary count is charged once; a secondary count is read at most once, only when a primary tie requires it. An uncontested winner needs no secondary read. Packed mask traversal is not separately charged. Cancellation and quota reservations follow Self::preferred_atom_reserved; every failure retains its exact work prefix and returns no partial preference.

§Errors

Retains cancellation, a quota refusal or a zero-grant work refusal.

§Panics

Panics if an open atom is outside either knowledge’s universe.

pub fn preferred_atom_reserved<Q: Quota + ?Sized>( &self, region: &Region, choices: &ChoiceHeads, cancellation: &Cancellation, work: &mut Meter<'_, Q>, ) -> PreferenceAttempt<Failure<Q::Error>>

Select the open atom to split on. An open atom marked in choices, the heads of the theory’s atomic choice roots, ranks before every unmarked one: deciding the choices first leaves the atoms they derive to propagation and support. Among equally ranked atoms, the one with most unknown parents in this knowledge wins; ties, including all-zero scores, select the lowest atom. Empty choices rank by unknown parents alone. The region, knowledge and choices must use the same atom universe and atom identities; their correspondence is a caller precondition, not checked here. This preference only orders an exhaustive split; it establishes no truth and does not complete propagation.

For A atoms and E eligible open atoms the scan takes O(A / 64 + E) time and constant additional space. Eligible atoms are the open choice heads when any remain, otherwise all open atoms. It charges one count read per eligible atom; packed mask traversal is not separately charged. It polls cancellation before reading and reserves/refunds the same batched permits as Narrower::narrow_known_reserved. Call after composed propagation has reached its joint fixed point, so the selected subject ranks the final region once.

§Errors

The receipt’s result retains a cancellation/deadline stop or the quota’s refusal; a zero grant is Stop::WorkLimit. Every failed attempt retains its charged prefix and changes neither argument.

§Panics

Panics if it reads an open atom outside this knowledge’s universe, violating the caller’s shape precondition.
