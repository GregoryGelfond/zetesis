Struct Narrower

pub struct Narrower { /* private fields */ }
Expand description

The shape of a theory a narrowing walks: each maximal tree of one connective read as one node, a chain, with its operands; the parents of each node that is not inside a chain, an implication or a chain root reading it as an operand; the nodes carrying each atom; and the atoms among each node’s operands. Built once per theory from its nodes. The three immutable incidence maps store ordered rows as offsets into contiguous entry vectors, retaining every occurrence already chosen by chain formation. Chain formation and compaction use linear construction passes, visiting each chain interior once when collecting its leaves.

A node is absorbed into its parent’s chain when it has that one parent, the same connective, and is not a root of the theory; every other conjunction or disjunction is the root of its own chain, of two operands at least. An absorbed node has no knowledge of its own: the chain’s readings are the n-ary readings of its operands (FormulaChains), and a node false under a frozen mask is either an operand, which fails, or an absorbed node whose operands all fail (disjunction) or one of which fails (conjunction), so the operands’ masks already read it.

Source

pub fn try_new(theory: &Theory) -> Result<Self, Stop>

Index the same DAG using checked compact adjacency construction. Each incidence map reads its immutable edge stream twice and uses linear row scans, preserving row order and duplicates. Chain construction walks each final chain once with linear scratch; it never copies intermediate chain prefixes. The logical index receipt is one visit per native node and operand occurrence; construction passes and storage initialization are not additional charged propagation reads. Native rows also have an exact-prefix forest: sorting borrowed row IDs takes O(R log R * K) term comparisons in the worst case for R rows of at most K grouped terms; prefix discovery and checked incidence construction take O(E + R), where E is the number of grouped terms. This derived index keeps at most R - 1 links and does not change the logical index receipt. When unit rows exist, immutable anchor projections retain one entry per eligible row and matching Boolean chain, with sparse reverse chain lookup. Chain minima are read once; their operand order is unchanged. For N nodes, U unit rows, C chains, L chain leaves and A anchors, this adds O(N + R + U log U + L + (R + C + L) log(A + 1)) preparation work, including the per-chain anchored-cone summary, and O(U + C) storage, with fallible reservations. This anchor projection has no row/chain pairs or node-sized offsets. With no unit row it performs no allocation or chain scan. Runtime anchor lookups, posting visits and exact-prefix comparisons consume propagation work; no per-Boolean mutable state is added.

A separate capacity projection retains conjunction/row intersections containing at least two distinct necessary unit contributions. It joins direct conjunction leaves and necessary aliases from original root implications with the existing row incidences. Its preparation work is O(R + C + D + B log(B + 1) + L log(B + 1) + J + sum(Pc log(Pc + 1))), where D counts root discovery visits (including repeated double-negation and target-incidence scans), B the collected aliases, J the projection’s incidence visits, and Pc its entries before deduplication for chain c. Retained storage is O(R + I + T) for row offsets, I retained intersections and T distinct required conditions; a dense incidence join can produce a dense projection. Temporary alias and per-chain projection vectors can exceed the deduplicated payload. Reservations are fallible. There is no per-region capacity cache; its runtime visits consume propagation work. Original-root aliases are never used in frozen-reduct propagation. This constructor has no memory allowance. Callers can budget retained capacity publication using Self::capacity_index_bytes; temporary preparation peaks can precede that publication check.

§Errors

Returns Stop::Allocation for compact-adjacency offset overflow or reservation failure. Chain construction and later knowledge allocation retain their existing infallible behavior; this is not universal OOM recovery. An invalid operand view returns Stop::InvalidProgram. This constructor has no independent cancellation contract.

pub fn extremum_index_bytes(&self) -> u128

Additional retained native-extrema index capacity. Dedicated owners use their actual headers and vector capacities. For shared containers, native Chain slots plus unused capacity and the whole witness-role and anchor projection payloads are conservatively attributed to native cuts; live ordinary Chain slots are excluded. Zero-cut theories report zero. Temporary preparation and per-chain counters already in knowledge accounting are excluded.

pub fn narrow_known( &self, subject: OriginalSubject<'_>, region: &mut Region, knowledge: &mut Knowledge, scratch: &mut NarrowingScratch, limits: RegionLimits, cancellation: &Cancellation, ) -> NarrowingAttempt

Narrow the region to the fixed point of the closure’s rules from what is already known about it, Self::knowledge for the root and the parent’s knowledge for a child, learning only the decisions the knowledge has not seen, and leave the knowledge closed for the region’s children.

knowledge is this narrower’s, closed for a region enclosing this one under the same producers and frozen mask, as Knowledge states; the narrowing cannot tell a foreign knowledge from its own.

The attempt reports the stop when narrowing exceeds its work or propagation ceiling, or control stops it. The region then holds the decisions the closure had learned before the stop, and the knowledge is partly closed: both sound, neither to be reused; the proposers abandon the region.

Frozen knowledge cannot enter this candidate operation.

ⓘ
use zetesis_algebra::Cancellation;
use zetesis_ferraris::{Narrower, NarrowingScratch, OriginalSubject, Region, RegionLimits};
fn wrong_class(index: &Narrower, subject: OriginalSubject<'_>, region: &mut Region) {
    let mut knowledge = index.frozen_knowledge();
    index.narrow_known(subject, region, &mut knowledge, &mut NarrowingScratch::default(),
        RegionLimits::default(), &Cancellation::default());
}

pub fn narrow_frozen_known( &self, subject: FrozenSubject<'_>, region: &mut Region, knowledge: &mut Knowledge<Countermodels>, scratch: &mut NarrowingScratch, limits: RegionLimits, cancellation: &Cancellation, ) -> NarrowingAttempt

Narrow a region of the theory’s frozen reduct under a candidate from what is already known about it, as Self::narrow_known does for the candidate tree: a node false in the subject’s truth, the candidate’s truth of every node, reads as falsum (FerrarisMask), and the rest of the DAG is read unchanged. No support cut applies, since a model of the reduct need not be supported: this narrows the proper-subset query, not the candidate tree. knowledge is this narrower’s, closed for an enclosing region of the same query under the same truth, with the precondition Knowledge states.

Failures and receipts follow Self::narrow_known.

Candidate knowledge cannot enter a reduct query. Fresh frozen knowledge comes from Self::frozen_knowledge, not a relabelled candidate state.

ⓘ
use zetesis_algebra::Cancellation;
use zetesis_ferraris::{FrozenSubject, Narrower, NarrowingScratch, Region, RegionLimits};
fn wrong_class(index: &Narrower, subject: FrozenSubject<'_>, region: &mut Region) {
    let mut knowledge = index.knowledge();
    index.narrow_frozen_known(subject, region, &mut knowledge, &mut NarrowingScratch::default(),
        RegionLimits::default(), &Cancellation::default());
}

pub fn narrow_known_reserved<Q: Quota + ?Sized>( &self, subject: OriginalSubject<'_>, region: &mut Region, knowledge: &mut Knowledge, scratch: &mut NarrowingScratch, cancellation: &Cancellation, work: &mut Meter<'_, Q>, ) -> NarrowingAttempt<Failure<Q::Error>>

Narrow original candidates with work granted in batches by quota (see Quota): the same closure and decisions as Self::narrow_known, with every charged node, parent, producer or open-atom read spending one permit, so a refused grant prevents that read and the receipt counts the permits spent. The quota is consulted at most once every NARROWING_BATCH charged reads, so its control polls are at most that many reads apart; a quota that grants what remains refuses a work limit at the same read as per-read charging. Unspent permits are refunded on every outcome. This operation polls cancellation before any mutation. The preconditions of Self::narrow_known apply, and a failed attempt’s region and knowledge must be abandoned.
