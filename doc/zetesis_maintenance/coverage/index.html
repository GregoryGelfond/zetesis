zetesis_maintenance

Module coverage 

Source
Expand description

Coverage policy and exact physical-test evidence, independent of instrumentation.

The workspace and CPU-only CLI floors remain separate. These functions check observed version strings, authored selections and retained output; Cargo and LLVM execution, freshness, exclusive ownership and ordered status publication remain the orchestration layer’s responsibility.
