Crate zetesis_presentation 

Source
Expand description

Human presentation with explicit capabilities and no environment discovery.

Logical results and measurements belong to their domain libraries. This module renders caller-supplied text without interpreting solver semantics. Tables retain all cell content and use a vertical layout when the columns do not fit. Callers bound the number and size of rows before constructing a view.

Whether the environment disables automatic styling: a nonempty NO_COLOR, or TERM=dumb. The adapter passes the variables’ values as it read them.
terminal_width
Table width for an observed COLUMNS value: a positive width of at most 512, otherwise 80. A terminal-provided width is presentation evidence only; the cap keeps an environment from requesting arbitrarily wide padding.
