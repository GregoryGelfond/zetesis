Source
Expand description

Test support over zetesis-themelios: admission of a source under default or given limits, the native reference the zetesis workspace’s tests compare with clingo (every answer set of a small program, found by checking each candidate against the reduct), preparation and hybrid grounding, source-bundle fixtures, and, by the resource a refusal reports, the limits an admission takes and those of three other operations whose tests span crates (resource_limits states which).

admit admits a source under given formula limits, the rest at their defaults, formula under the default limits throughout and normal on the normal-program route. exhaustive enumerates every subset of an admitted source’s atoms, keeping those the reduct check (zetesis_ferraris::check) accepts, each with its objective’s costs; atoms are spelled as clingo spells them (canonical). normal_answer_sets finds a normal program’s answer sets by exhausting its candidates, each checked against the reduct (zetesis_cpu::check). prepare prepares a source under the default options and limits, prepared when preparation must accept it, and hybrid grounds it for hybrid execution; BundleFixture writes a source bundle into a temporary directory for the tests that load or run one. resource_limits sets those limits by the resource a refusal reports, and reads the formula and expansion limits’ defaults by resource. The crate stands above zetesis-themelios, so only the tests that need that closure compile it. It is not published or installed.
