    },

Expand description

A typed semantic bundle refusal, separate from source-graph loading errors.

Variants§

§

Expansion(ExpansionFailure)

The extended source or independent core admission door refused its stage.

§

RootAlias

A later explicit root has a different lexical identity from the same source’s first root or include occurrence.

Fields

§first: PathBuf

First selected lexical filename.

§repeated: PathBuf

Later original root spelling.

§location: Location

Original source span of the repeated root.

§

IncludeAlias

Different lexical include paths refer to the same canonical source. clingo can parse these separately, which the deduplicated graph does not represent; admission refuses instead of dropping repeated definitions.

Fields

§first: PathBuf

First resolved lexical path in include traversal order.

§repeated: PathBuf

Later resolved lexical path to the same canonical source.

§location: Location

Original include occurrence that revisits the source.

§

IncludeRedirection

A lexical path’s dot-normalized identity differs from the canonical source, for example through a symlink. Relative include semantics under that spelling are not represented by the canonical graph.

Fields

§requested: PathBuf

Original include path resolved from its including lexical path.

§canonical: PathBuf

Canonical source identity retained by the loader.

§location: Location

Original include occurrence.
