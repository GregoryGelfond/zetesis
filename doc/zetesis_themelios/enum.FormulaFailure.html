Expand description

A typed refusal of canonical preparation or finite formula admission; never semantic UNSAT. Fields named location carry a ProgramSite, whose actual source coordinate is optional. Typed-input failures retain the original program in Self::Program; use Self::cause to inspect the underlying refusal without discarding it.
