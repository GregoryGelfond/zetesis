Expand description

Prepare canonical input for the selected purpose under shared runtime control.

The original Arc<Program> is retained unchanged. Original statement indices are assigned before declaration filtering, so every emitted site resolves in that same owner. Structural input limits still inspect every declaration, including declarations excluded by the purpose. Preparation includes finite fact expansion; callers requiring a validation-only lowering boundary use validate_program_formula first.

Control is polled at existing charged expansion and formula-work boundaries, around structural inspection and bounded upstream analysis, and during observation compilation. Upstream analysis has no internal cancellation hook; its already bounded call is one cooperative interval. Control is checked again before a successful preparation or materialization is returned. This is not a hard real-time deadline or an allocator/RSS bound.

§Errors

Retains the original program with every structural, capability, arithmetic, resource or cancellation refusal. No partial preparation is returned.
