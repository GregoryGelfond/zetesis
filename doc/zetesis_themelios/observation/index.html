Module observation 

Source
Expand description

Bounded observation queries over supplied full models, independent of any oracle.

Term output is deduplicated within its own channel. Combining it with selected original atoms retains cross-channel duplicates and never projects model identity. The caller establishes stability separately; these queries create no support.
