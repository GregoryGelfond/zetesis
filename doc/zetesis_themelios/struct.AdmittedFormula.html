pub fn warning_view(&self) -> impl Display + '_

Render warnings with themelios’s human view when source bytes are retained, building one source line index and one diagnostic at a time. Logical input instead names the original statement index when available. Formatter failures stop rendering; an empty collection is empty.

Source

pub fn source_analysis(&self) -> &Analysis

Structural facts about Self::analyzed_program. Consult Self::analysis_basis: a dependency projection does not certify source safety or class membership. Unknown never removes runtime ceilings. If preparation has not needed the complete normalized input, the first full inspection constructs and retains it and its analysis. Later calls borrow that shared result. Preparation’s summary has the same dependency graph and class verdicts; full inspection pays canonical ingestion and analysis work and full-program storage, without an expansion charge.

Source

pub fn source_classes(&self) -> &Classes

Structural classes of the retained source analysis. This view does not require constructing the full analyzed program. Consult Self::analysis_basis before using a verdict as a source property.

pub fn analyzed_program(&self) -> &SourceProgram

Bounded, pool-free analysis input retaining available provenance. Consult Self::analysis_basis before interpreting its structural verdicts. Shares the complete view and its construction cost with Self::source_analysis.

pub fn analysis_basis(&self) -> AnalysisBasis

Meaning of the retained analysis input. Dependency projections do not certify the original source’s safety, class, or execution eligibility.

pub fn formula_origins(&self) -> &[Vec<ProgramSite>]

Original statement sites per theory root, preserving merged source evidence. Necessary support guards collect producer origins and first atom occurrences. A shared condition guard retains their sorted union across all requiring heads; its root identity and position need not correspond to a single atom. Coherence roots retain each opposite ground atom’s first occurrence site, recording a shared site once. These sites need not name every producer.
