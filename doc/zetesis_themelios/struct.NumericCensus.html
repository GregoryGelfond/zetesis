Expand description

Borrowed numeric-domain evidence from prepared canonical producers. Populations in one completed numeric analysis. Rule counts use non-fact compiled occurrences; compact fact rows supply argument seeds, not rules. Counts describe analysis results, never solver work saved or answer sets.
