Module scalability 

Source
Expand description

Maintained authored fixtures and a finite worker-scaling population.

Parametric fixtures use the reviewed scalability manifest; fixed fixtures carry their reviewed source digests and typed display contracts here. Workload identities retain the actual contract and original/derived source hashes. This is authored evidence, not upstream corpus-cleaning provenance or a generated-family proof.
