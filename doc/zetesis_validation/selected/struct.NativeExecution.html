Expand description

Execution requests only; no extra source, constants, stdin or output options. Unspecified solver budgets retain the sealed executable’s defaults.

Fields§

§backend: Backend

Requested execution hardware.

§oracle: Oracle

Requested reduct procedure.

§grounder: Grounder

Requested materialization policy.

§formula_joins: Option<FormulaJoins>

Optional eager-formula join strategy. Omission preserves the sealed executable’s default and permits comparison with versions before this flag.

§search: Option<SearchMethod>

Optional formula search method. Omission preserves the sealed executable’s default and permits comparison with versions before this flag.

§workers: NonZeroUsize

Closure worker request.

§completion_workers: NonZeroUsize

Formula completion worker request.

§batch_size: NonZeroUsize

Native candidate batch ceiling.

§max_completion_scratch_bytes: u64

Logical completion scratch allowance; zero is a valid requested ceiling.

§time_limit_seconds: Option<NonZeroU64>

Cooperative deadline passed as --time-limit, in whole seconds. Absent means no deadline; a deadline changes what the solver polls at every charged unit, so it is part of the profile’s identity.

§max_expansion_work: Option<usize>

Explicit formula expansion-work ceiling. Omission preserves the sealed executable’s default; an override is part of the measured profile.
