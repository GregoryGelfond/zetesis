Enum GpuDeviceSource

pub enum GpuDeviceSource<'a> {
    Selected {
        options: GpuOptions,
        selection: GpuSelection,
        timing: bool,
    },
    Discovered {
        discovery: &'a GpuDiscovery,
        options: GpuOptions,
        timing: bool,
    },
    Context(&'a GpuContext),
}
Expand description

Where a GPU primitive obtains its device: a selection of its own, the same selection over an adapter enumeration a GpuDiscovery began earlier, or an existing context.

A selected or discovered source chooses, among the adapters of the API that the policy admits, the best-ranked one advertising compute shaders and limits the constructing primitive accepts, then requests a device of its own from that adapter. A discovered source selects over the adapters present when its discovery began, so it chooses the adapter and reports the failures a selected source would have then, at the same steps; GpuDiscovery states what that snapshot’s age means. A discovery saves only the adapter enumeration’s wait. A context source selects nothing: the primitive compiles on that exact context, which keeps the timestamp request it was created with.

timing requests compute-pass timestamps for the primitives that measure compute time, the formula and tight oracles; the other primitives request none. Unsupported timestamps leave solving available and are reported by GpuContext::compute_timing.

Selected

Fields

§options: GpuOptions

The hard adapter policy.

§selection: GpuSelection

The API to enumerate; never replaced by another.

§timing: bool

Request compute-pass timestamps.

§

Discovered

Select under options as Self::Selected does for the discovery’s API, over the adapter enumeration discovery began. A discovery serves one primitive: once taken, or when its thread failed, the primitive enumerates as Self::Selected does.

The adapter enumeration begun earlier.

Request compute-pass timestamps.
