Struct GpuFormulaOracle

pub struct GpuFormulaOracle { /* private fields */ }
Expand description

GPU original-truth evaluation and sound frozen-query propagation.

The immutable transport retains native threshold and extremum-cut rows as shared condition/value columns. Portable u32 limbs preserve all admitted weights and bounds without optional device integer capabilities. Original truth is exact; frozen numeric projection uses conservative linear bounds, which can leave more residual work than expanded Boolean formulas.

This is a partial reduct primitive; exact residual search remains necessary. A residual carries the semantic atom region retained by the completed device sweeps. No source grounding, objective scoring, candidate enumeration or CPU oracle fallback occurs here.

pub fn from_profile(profile: &GpuFormulaProfile) -> Result<Self, GpuError>

Start fresh oracle state using a caller-owned profile.

Acquires the context’s nonblocking lease, checks shared health and granted formula capabilities, then retains the exact compilation. No shader assembly, pipeline compilation, theory upload or dispatch occurs. Fresh residency, epoch and batch accounting are independent of every other oracle; this operation has fixed cost and retains one shared owner.

pub const fn reported_compute_time(&self) -> Option<BatchComputeTime>

The compute-pass time of the batch this oracle’s latest call consumed.

Under enabled timing, a submitting call that completes reports the batch completed by the previous submitting call, from that batch’s own interval; its own batch’s interval is read by the next submitting call or by Self::flush_compute_time. A call that fails after submission reports the previous batch unavailable, abandons its own and retires the timer, so the next timed batch starts a fresh one. The flush reports the batch it resolved, and Self::clear_residency reports a discarded unresolved batch unavailable. Under unsupported timing each completing call reports its own batch unavailable; disabled timing reports nothing. None when the latest call consumed no batch: every call clears it at its start, including empty and refused calls. A measured duration is never zero and excludes host preparation, transfers and waits.

pub fn flush_compute_time( &mut self, timeout: Duration, cancellation: &Cancellation, ) -> Result<(), GpuError>

Resolve the unresolved batch’s interval with one resolve-only submission.

Returns at once, with no report, when no batch is unresolved. Otherwise a zero timeout is refused; the context lease is taken, and Busy submits nothing; cancellation and context health are then checked once, and a stop or an unhealthy context submits nothing. Each refusal leaves the batch unresolved and a healthy context reusable. The flush then waits at most timeout for its submission, polling no control. On observed completion the batch is reported, measured or unavailable, and the context stays reusable. A timeout or a mapping, device or scope failure reports it unavailable, retires the timer and invalidates the context, as for any submission whose completion is unknown or faulted. The flush allocates nothing and downloads 16 bytes; batch statistics and submission receipts exclude it.

§Errors

Returns the refusals and failures above.

pub fn propagate_batch( &mut self, theory: &Theory, candidates: &[Interpretation], limits: FormulaLimits, ) -> Result<Vec<FormulaCheck>, GpuError>

Evaluate original roots, freeze M, and cooperatively narrow the proper- subset query. Results retain input order and no partial batch is returned. Clones of one Theory reuse its graph; independent equal theories do not. Exact candidate-count transport is replaced when that count changes. Host candidate words reuse initialized scratch for the same subject/count; replacement releases the old scratch before cold preparation. Actual capacity is charged on every call, and a smaller allowance can replace an oversized optional allocation. Explicit clearing releases this scratch too. A cold subject is prepared in O(nodes + edges + roots + levels) host work, outside the per-candidate device-work limit. One buffer retains fixed headers and complete native operand rows; no binary expansion or per-candidate graph copy is made. Its upload buffers are released after device copies are created. Pure chains retain serial truth; other DAGs distribute independent nodes by dependency level. Narrow levels can incur synchronization cost without useful parallelism; no crossover is assumed.

§Errors

Refuses foreign interpretations, insufficient setup/work/storage limits, u32 address overflow, allocation, device/poll, validation or readback failures. Execution/readback failures invalidate the entire context. Minimum shape, input and Busy refusals preserve residency. Later cold preparation refusal releases the old resident handles and leaves a healthy, cold context without advancing its epoch. Driver retirement is excluded from authored byte limits. A propagation limit is an explicit residual, never a proof of stability. Under fitted sizing, the first call that dispatches a size compiles its pipeline. A failure to compile it is reported before any dispatch and invalidates the context; the size stays uncompiled, and no theory stays resident, because only a freshly prepared theory can need a size first and its cold preparation released the previous one.

Source

pub fn propagate_batch_with_cancellation( &mut self, theory: &Theory, candidates: &[Interpretation], limits: FormulaLimits, cancellation: &Cancellation, ) -> Result<Vec<FormulaCheck>, GpuError>

Propagate with cooperative caller cancellation and deadline observation. Busy admission precedes control; control precedes device health, including empty batches. Further polls follow host packing and bracket waits of at most 50 ms. Host work, driver calls and scope drains are not preempted.

§Errors

Preserves Self::propagate_batch’s failures. An interruption returns its exact stop and no partial checks. Pre-submission control refusal leaves health reusable; an interrupted submitted operation invalidates it. Scope/device faults retain priority. This is not a hard wall-clock deadline.

pub fn propagate_prefix_with_cancellation<'a>( &mut self, theory: &'a Theory, candidates: &'a [Interpretation], limits: FormulaLimits, cancellation: &Cancellation, ) -> Result<CheckedBatch<'a, FormulaCheck>, GpuError>

Check the largest nonempty prefix admitted by the prepared device layout.

The prefix is bounded by both the supplied slice and max_candidates. Cold graph packing occurs once; admission then selects a count using the same storage, address and work checks as the exact batch operation. The receipt borrows exactly the checked prefix and retains input order. An empty slice still observes control and context health before returning. No completed prefix is returned after an interrupted or failed operation.

§Errors

Preserves Self::propagate_batch_with_cancellation’s typed failures. If one candidate cannot fit, returns that refusal without dispatch. Only capacity limits reduce the selected count; allocation and device failures do not select a fallback. The chosen schedule is not changed to enlarge the prefix. Subsequent calls may reuse the prepared subject.

pub fn prepare<'o>( &'o mut self, slate: SlateRef<'_>, offset: usize, limits: FormulaLimits, cancellation: &Cancellation, ) -> Result<PreparedFormulaSubmission<'o>, GpuError>

Prepare the next submission of slate: admit the largest nonempty prefix of its candidates from offset on, as Self::propagate_prefix_with_cancellation admits a prefix, pack it into this oracle’s reused upload storage, and plan it at the next epoch. Nothing is submitted, and the epoch is committed only by the check.

The returned submission holds this oracle’s mutable borrow until a check consumes it, so no other operation on the oracle, and no second preparation, can run between the plan and its check. Dropping it submits nothing and releases the borrow; any retained state its preparation replaced stays released, and the next check prepares again. That can be the host staging, the resident graph on a fresh admission, and the transport when the preparation allocates one. The context’s lease is taken by the check, not here; this polls control and context health before preparing.

§Errors

Refuses an offset that leaves no candidate, and every refusal and failure of Self::propagate_prefix_with_cancellation’s preparation, with its rules for residency.
