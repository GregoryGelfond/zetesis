Struct GpuFormulaProfile 

Source 
pub struct GpuFormulaProfile { /* private fields */ }
Expand description

One finite-formula kernel on one exact device context, shared by every oracle started from it.

A profile retains its validated shader module and the pipeline of each workgroup size compiled for it. A fixed size’s pipeline is compiled when the profile is created; a fitted size’s by the first check, from any oracle sharing the profile, that dispatches that size. Oracles and sessions sharing a profile share its pipelines, so each size is compiled once per profile.

Cloning retains the same shader, pipelines, context and gate implementation in constant time. Independent compilation has a different identity even on the same context. No theory, transport, epoch, search state or batch statistics belong to this owner. Each super::GpuFormulaOracle::from_profile starts those mutable resources afresh; simultaneously live oracles retain separate storage.

Compilation has driver-dependent allocation and duration outside dispatch limits. Keeping a profile alive retains its shader, pipelines and device infrastructure; per-oracle byte limits do not account for that infrastructure or sum all live oracles. This is explicit reuse, with no global cache or concurrent scheduling.

pub fn from_context_with_kernel( context: &GpuContext, projection: GateProjection, options: GpuKernelOptions, ) -> Result<Self, GpuError>

Compile the shader of explicit physical choices on the exact retained context.

The workgroup sizing’s base size is checked against granted limits and the shader validated; a fixed size is compiled now, and a fitted size by the first check that dispatches it. Optional instructions require granted features; otherwise the portable reduction is retained. None of these choices changes the frozen reduct or its work allowance.

§Errors

Reports the construction failures of Self::from_context, including a fixed workgroup size exceeding the device’s granted limits, and a failure to create the shader or compile a fixed size, which invalidates the context. A fitted size’s compilation failure is reported by the first check that needs it.
