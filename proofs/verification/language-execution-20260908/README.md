# Conditional consumer composition

Five new laws in `ConditionalConsumers` compose the already supplied aggregate
equality and activation with a complete finite universal conditional family.
They retain original and arbitrary frozen interpretation truth, completed empty
family vacuity, unrealized-proposal vacuity and the actual value's association
with its selected family under explicit covering-carrier premises.

The pinned clean Lean 4.33.1 build, strict check of every semantic module, and
complete axiom audit pass for 788 laws across 68 modules. All 783 prior theorem
names, statements, source locations and transitive axiom sets remain unchanged;
the prior 67 module sources are byte-identical. The continuity record checks
those identities. Only standard Lean logical axioms occur, as recorded by the
complete audit.

The module accompanies admission of aggregate-dependent outer consumers using
the existing universal conditional compiler. Its premises do not prove that Rust
constructs a complete local family, computes correct bindings, respects resource
bounds, or implements these formulas. Source, Rust and GPU refinement remain
separate obligations. No conditional pruning or candidate-truth specialization
is introduced by this feature.

`commands.json` retains the actual clean build, per-module strict checking and
audit commands. `check-commands.json` retains the proof-record regression and
gate checks. The top-level verification record hashes their logs and preserves
the previous complete record. Task-local orchestration was not added as a new
repository tool or a solver dependency.
